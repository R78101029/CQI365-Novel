## 創作守則（已整合至 agent_guidelines.md）

1. 不急著解釋。讀者不懂的地方，也許若筠也不懂。
2. 不急著療癒。她到冬天還是會煩、會想賣、會覺得算了。
3. 不讓丈夫成為答案。他不完美、帳本混亂、修得醜、也許想過放棄。
4. 不讓女客人成為救贖。她是客人。來了就來了。沒來就沒來。
5. 不讓每個物件回收。有些東西出現一次就夠了。襪子就是襪子。
6. 不替她命名感受。她洗碗洗慢了，不要寫「那是溫柔」。
7. 不讓露台五分鐘看起來重要。它在第三章只是五分鐘。
8. 不把「您好」寫成金句。它是一句普通的招呼。普通是全部的重點。
9. 每章至少一件不推動任何事的事。過期味噌、送錯的便當、修好又壞的紗窗。
10. 寫完回頭讀。如果某段讓你覺得「這裡很文學」，刪掉它。

## 不可解釋清單

| 項目 | 為什麼不解釋 |
|------|-------------|
| 空信封 | 任何解釋都比空信封本身小 |
| 紅土 | 鶴見島有些山徑有紅土，是她的事 |
| 毛姆折頁 | 摺角是一個指向但沒有抵達的箭頭 |
| 她第四次沒來 | 「沒來」比任何原因都重 |
| 丈夫為什麼在島上買房 | 她永遠不會完全理解 |
| 三個打火機 | 出現一次，不再提 |
| 露台五分鐘 | 第三章只是五分鐘 |
| 不知名工具 | 全書「不完整」的物件縮影 |

## 過度解釋替代方案

| 危險句型 | 替代方式 |
|---------|---------|
| 她終於明白…… | 刪掉，只留前面的動作 |
| 原來…… | 刪掉，場景已經說了 |
| 這不是……而是…… | 刪掉解釋句，保留事件 |
| 那一刻，她知道…… | 換成她做的下一件事 |
| 她第一次真正…… | 刪掉「第一次真正」，只寫她做了 |
| 愛不是…… | 永遠不要出現 |
| 放手不是…… | 永遠不要出現 |

## 每季建議無意義生活細節

### 春
- 浴室排水孔卡了不知誰的頭髮
- 過期三個月的電費繳費單（日文的·她看不太懂）
- 牆上便條寫著不明六位數字
- 客人床底留了一本四國遍路旅遊指南

### 夏
- 冰箱深處膨脹的味噌
- 院子裡出現一隻來歷不明的拖鞋
- 洗衣機脫水後往右移五公分
- 郵便局送錯包裹，她用破碎日語解釋了五分鐘
- 客人忘了充電線，放櫃檯一個月

### 秋
- 她第二次來穿的鞋和第一次不一樣
- 石牆上的苔只長了一邊
- 沙發縫裡找到一枚50円硬幣，過幾天不見了
- 田中帶了一瓶清酒來喝半杯就走了

### 冬
- 修好紗窗隔天又破了，不同位置
- 寄來淨水器DM，收件人維新的名字
- 十分鐘的雨停了，地面濕一半
- 貓叼壁虎回來，壁虎跑了，貓看著
- 洗碗時碗滑了沒破，在水槽轉了幾圈

## 人物關係獨立性檢查

| 關係 | 風險 | 修改方向 |
|------|------|---------|
| 鄰居田中 | 太服務主角，沒有自己的煩惱 | 給他船外機老壞、兒子在大阪不回來等獨立生活 |
| 訪客系統 | 每季一個太均勻，每個都帶丈夫碎片 | 打破均勻分佈，讓某季沒有丈夫訊息 |
| 父女訪客 | 「她讓我女兒在海裡站了一個小時」太像金句 | 改成更模糊的回憶 |
| 女客人 | 三次造訪節奏太穩定（3晚/5晚/3晚） | 改為不規律，某次也許只住1晚 |
| 貓 | 慢慢親近的弧線太服務主題 | 冬天也有不理她的時候 |
| 丈夫與民宿 | 仍然偏向「離開她後找到自己」 | 帳本某月寫「もうやめたい」 |
