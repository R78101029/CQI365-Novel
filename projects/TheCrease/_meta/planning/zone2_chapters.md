# Zone 2 章節規劃 — 裂縫中的回聲（Ch 5-10）

> **Zone 2 規則**：每章包含一段簡短的跨時間線插入（200-500字）。主線 4000-6000 字。非對稱感知：A 感知 D、B 感知 C、C 感知 A、D 感知 B。目標：讓讀者開始懷疑時間線之間的關聯。

---

## Ch 5 — 禁書

| 欄位 | 內容 |
|------|------|
| **時間線** | Thread A + D 插入 |
| **主角** | 衛央 |
| **時代** | AD 166 |
| **排序** | 5 |
| **字數目標** | 5000字（主線4800 + D插入200字） |

### 主線場景

1. 衛央的觀測紀錄被太史令的副手質疑——「你記錄的這些閃光，正式星象表上沒有」。

2. 她開始秘密記錄，使用私人竹簡。白天抄寫官方天象記錄，夜間記錄真實觀測。

3. 黨錮之禍正在擴大。名單越來越長。靈台裡的人越來越沉默。

4. 她前輩蔡某的場景：被帶走前對她說「抄一份假的讓他們找到」。

### D插入（~200字）——縫工感知片段

**插入位置**：衛央夜間觀測時的間隙。

**內容**：縫工在修復局進行例行修補時，耳邊出現極微弱的聲音——像是有人在很遠的地方用她不認識的語言低聲背誦數字。她以為是設備共振。記錄在日誌裡標注為「異常聲波」。

## Ch 6 — 座標

| 欄位 | 內容 |
|------|------|
| **時間線** | Thread B + C 插入 |
| **主角** | 陳明哲 |
| **時代** | 1947年2月 |
| **排序** | 6 |
| **字數目標** | 5500字（主線5200 + C插入300字） |

### 主線場景

1. 陳明哲對渾天儀座標的深入分析。236個點的分布——薛丁格方程的邊界條件。

2. 他開始推導「時間穿隧」假說。不是粒子穿隧，是資訊穿隧。

3. 228事件爆發（2月28日）。他聽見遠處的槍聲，沒有出門。繼續在地下室工作。

4. 他的語言困境：用日文思考物理最精確，但他不能在外面說日文了。

### C插入（~300字）——許若昕的實驗室片段

**插入位置**：陳明哲推導方程時的間隙。

**內容**：許若昕的偵測器在一次例行校準中記錄到異常——一組量子簽名，其時間戳指向一個不存在的年份。蘇顯宗問「這是噪音嗎？」許若昕看了很久，說「噪音是隨機的。這個不是。」

## Ch 7 — 自指

| 欄位 | 內容 |
|------|------|
| **時間線** | Thread C + A 插入 |
| **主角** | 許若昕 |
| **時代** | 2055年6月 |
| **排序** | 7 |
| **字數目標** | 5000字（主線4600 + A插入400字） |

### 主線場景

1. 褶式方程的自指性質確認——它描述時間摺疊，也是時間摺疊洩漏的產物。

2. 許若昕向研究組報告，同事分為兩派：「這太瘋狂了」vs「這解釋了所有異常」。

3. 她開始設計「開摺實驗」——人工放大摺痕，觀察資訊洩漏。

4. 東亞科技共同體要求她提交研究數據。她拒絕。

### A插入（~400字）——衛央的觀測片段

**插入位置**：許若昕在實驗設計中遇到直覺跳躍時。

**內容**：衛央在一個特別清澈的夜晚觀測到一次異常閃光，持續時間比之前所有都長。她記錄時，手突然停住——閃光消失的位置，她感覺到一種「被注視」的感覺。不是有人在看她。是天空本身在看她。她在竹簡邊緣畫了一個小小的記號——一個她自己也說不清意義的圖形。

## Ch 8 — 異常區

| 欄位 | 內容 |
|------|------|
| **時間線** | Thread D + B 插入 |
| **主角** | 縫工 |
| **時代** | 2301 |
| **排序** | 8 |
| **字數目標** | 4500字（主線4300 + B插入200字） |

### 主線場景

1. 縫工在例行修補中遇到一個無法修補的褶痕——所有標準協議都失效。

2. 她向上報告。上司說「把它標記為'待觀察'」。她知道「待觀察」的意思是「不要再問」。

3. 走廊上，她遇到七號技師。七號技師對她微笑——那種平靜的、不記得自己失去了什麼的微笑。縫工想到七號技師三年前在公共資訊網路上發布的那篇質疑報告。14分鐘。報告存在了14分鐘。然後七號技師被送去認知校正。現在她回來了，還在上班，還會微笑。但她寫日誌的時候，字跡和以前不一樣了。

4. 她開始私下研究這個異常。修復局的歷史檔案裡，有2055年開摺實驗的原始數據殘片。

5. 她發現官方關於「2055年日內瓦事故」的記錄和原始數據對不上。她想到七號技師。她把發現記在自己的加密日誌裡，沒有發布。

> **「如果」鋪墊 #2**：縫工在日誌中寫到一半——「若原始數據為真……」——她盯著螢幕上那個「若」字，刪掉了它。重新寫：「原始數據為真的情況下……」。這是她的自我審查。讀者第二次看到這個禁忌的具體運作。

### B插入（~200字）——陳明哲的片段

**插入位置**：縫工翻閱歷史檔案時。

**內容**：陳明哲在鹿港的夜晚，獨自在借住的房間裡繼續推導。外面有巡邏的腳步聲。他的手在筆記本上寫下一個符號——然後停住，因為那個符號他不認識。他盯著它看了很久。把它劃掉，繼續。但劃掉的痕跡下面，那個符號清晰可見。

## Ch 9 — 株連

| 欄位 | 內容 |
|------|------|
| **時間線** | Thread A + D 插入 |
| **主角** | 衛央 |
| **時代** | AD 168 |
| **排序** | 9 |
| **字數目標** | 5000字（主線4700 + D插入300字） |

### 主線場景

1. 黨錮之禍加劇。衛央的師父太史令蔡某被列入黨人名單帶走。

2. 蔡某離開前的對話——告訴衛央保護好數據。

3. 衛央做出決定：將所有236個座標鑄刻在青銅渾天儀的底座內壁。選擇這個位置是因為「幾百年內不會有人拆開」。

4. 她開始刻的過程——精確、緩慢、一個點一個點。

### D插入（~300字）——縫工的片段

**插入位置**：衛央刻到中間段時。

**內容**：縫工在觸碰一個特別古老的褶痕邊緣時，手指感到灼痛——不是物理性的灼痛，更像是一種記憶的灼痛。監測設備沒有記錄到任何異常溫度。她把手抽回來。看了看手指。沒有傷。她在日誌裡寫：「體感異常。原因不明。」

## Ch 10 — 清鄉

| 欄位 | 內容 |
|------|------|
| **時間線** | Thread B + C 插入 |
| **主角** | 陳明哲 |
| **時代** | 1947年3月 |
| **排序** | 10 |
| **字數目標** | 5500字（主線5000 + C插入500字） |

### 主線場景

1. 清鄉開始。3月8日國軍登陸基隆。同事一個接一個失蹤。

2. 陳明哲決定逃離台北。連夜帶著渾天儀殘件和筆記本前往鹿港。

3. **回到林秀英身邊**：深夜到家。林秀英開門時沒有問他為什麼這個時候回來，也沒有問他抱著的是什麼。她只是煮了一碗麵。他吃的時候，她在旁邊坐著。他們很久沒有同時安靜地待在一個房間裡了。

4. 在鹿港龍山寺——林秀英帶他去她知道的一個建築結構空隙。她是鹿港人，從小在這座寺裡長大。他將渾天儀和筆記藏入。

5. 他寫下那封給「未來打開摺痕的人」的信。

6. 他對林秀英說：「如果有人來問，你什麼都不知道。」她說：「我本來就什麼都不知道。」——這句話是保護，也是事實。她真的不知道那些方程式是什麼。她只知道丈夫在做很重要的事。

7. 龍山寺的夜晚——他哭了。不是因為害怕死亡，是因為方程式還沒算完。也因為林秀英在旁邊，而他知道他可能回不來了。

### C插入（~500字）——許若昕收到線索的片段

**插入位置**：陳明哲藏筆記的同時。

**內容**：2055年，蘇顯宗回家過節（鹿港），碰巧遇到龍山寺修復工程。他在被拆開的牆體結構中看見一個油布包裹的東西。打開一看：一個青銅殘件和一本泛黃的筆記本。筆記本上的方程式——他認出一些符號。這不可能。他拍了照片發給許若昕。許若昕看到照片後沉默了很久，然後說：「你現在就帶過來。」
