# 摺痕 — Agent 寫作指引

> **核心原則**：情感優先於資訊。物理概念必須服務情感，而非相反。

---

## 1. 氛圍定義 (The Vibe)

**全書關鍵詞**：摺疊、洩漏、安靜的暴力、穿越時間的見證

每條時間線有獨立的氛圍關鍵詞：

| 時間線 | 關鍵詞 |
|-------|--------|
| A（衛央） | 克制、精準、觀測紀錄、寂靜 |
| B（陳明哲） | 知識份子的沉靜、崩裂、語言的流亡 |
| C（許若昕） | 精確、黑色幽默、工具性語言面對無法表述之事 |
| D（縫工） | 疏離、極簡、監測報告與詩之間 |

## 2. 敘事聲音指南（四條時間線必須嚴格區分）

### Thread A｜衛央（公元166年）

```
人稱：第三人稱有限視角（她）
語氣：克制，精準，沒有多餘的情感形容詞
句子長度：短到中。記錄式的節奏。
避免：現代化的心理描寫、過多的比喻
參考質地：像觀測紀錄本身——事實，位置，時間，異常。
```

**範例：**

> 她把第236個點刻下去。工具收好。竹簡鎖進匣子。
> 窗外還是黑的。她不知道今天是什麼日子。她只知道今天是最後一次。

**禁止**：

- 不可使用現代心理學詞彙（如「焦慮」「創傷」）
- 不可使用超過兩行的比喻
- 不可出現第一人稱內心獨白

### Thread B｜陳明哲（1947年）

```
人稱：第三人稱有限視角（他）
語氣：知識份子的沉靜，但有時候會崩裂
句子長度：中。偶爾出現很長的思考流，然後被外部事件打斷。
特殊：他的思考中偶爾夾雜日文詞彙（斜體標注）
避免：過度政治化的表述——他不是政治人物，他是一個科學家
參考質地：像一個同時在思考物理和思考如何活下去的人。
```

**範例：**

> 三樓傳來聲音。不是腳步聲。是搬動桌椅的聲音——那種猶豫的，不確定要拿什麼的聲音。
> 他把筆記翻到最後一頁。還有三個步驟。

**禁止**：

- 不可讓審訊場景變成政治演講
- 不可讓他成為英雄或殉道者
- 日文詞彙使用需克制（每章最多2-3處）

### Thread C｜許若昕（2055年）

```
人稱：第三人稱有限視角（她）
語氣：當代知識份子，直接，有時候帶點黑色幽默
句子長度：混合——科學敘述時短而精準，情感時可以更長
特殊：偶爾出現英文技術術語（斜體），她的內心語言有時中英混雜
避免：過度詩意——她是理工出身的，語言是工具性的
參考質地：像一個習慣用精確語言的人，在面對無法精確表述的事情。
```

**範例：**

> *Unfolding*。她一直不確定這個詞是否準確。
> 打開，讓光進來。或者讓光出去。
> 她不知道裡面是黑暗還是另一種光。

**禁止**：

- 不可過度詩意化
- 英文術語限於真正的物理/技術詞彙

### Thread D｜縫工（2301年）

```
人稱：第三人稱有限視角（她）
語氣：疏離，但不冷淡。像一個習慣了孤獨的人。
句子長度：短。很多省略。
特殊：她的語言裡沒有假設性句型（因為文化禁忌），但在故事後半段（Zone 5 第27章），她開始說「如果」
避免：過多解釋性的世界觀敘述——讓細節自然透露未來的樣子
參考質地：像一個監測報告和詩之間的某種東西。
```

**範例：**

> 泡又擴張了0.003%。
> 她在日誌裡記下數字。沒有別的。
> 窗外是地球。地球表面還有七成是可以踩的地方。
> 今天的任務：監測。明天也是。

**禁止**：

- **嚴禁使用假設性句型**（「如果」「假如」「要是」「萬一」），直到第27章
- 不可過多解釋世界觀——讓讀者從細節推斷
- 不可出現情感形容詞

### 第五種聲音｜褶痕敘事者（馬奎斯聲音）

四條時間線各有自己的聲音。但還有**第五種聲音**——褶痕本身的聲音。

這個敘事者不是任何角色。它是褶式方程的文學化身——一個看見所有時間、知道所有結局的存在。它的語法來自馬奎斯的《百年孤寂》：未來過去式、全知視角、長句流、用日常語氣描述不可能的事。

**褶痕敘事者的梯度（隨 Zone 遞增）：**

| Zone | 褶痕聲音強度 | 使用方式 |
|------|------------|---------|
| Zone 1 (0-20%) | 極微弱 | 僅出現在每章**第一句**。用「未來過去式」開場，然後立刻回到該線的個人聲音。讀者感到一閃而過的全知視角。 |
| Zone 2 (20-40%) | 微弱 | 每章第一句 + 跨線插入的**過渡句**（1-2句）。褶痕聲音在縫隙中閃現。 |
| Zone 3 (40-65%) | 可見 | 開始出現**跨越兩條線的長句**——一個句子同時描述兩個時代的動作。頻率逐漸增加。褶痕在顯影。 |
| Zone 4 (65-85%) | 主調 | 褶痕聲音成為主敘事層。馬奎斯式長句流覆蓋四線切換。個人聲音退為對話和內心碎片。 |
| Zone 5 (85-100%) | 頂點→崩裂 | 長句達到最大擴張——一個句子包含所有四條時間線。然後在 Ch 27-28 **碎裂**：長句→短句→詞→空白。褶痕敘事者和四個角色一起消融。 |

**褶痕敘事者的語法規則：**

1. **未來過去式**：「多年以後，當某人在某處做某事時，她/他將會想起……」——一句話裡同時存在過去、現在、未來。
2. **平淡語氣描述不可能**：不驚訝、不強調。手心無故發熱和吃早餐一樣正常。「一百零八年後，一個他不認識的女人會在讀到他的筆記時，雙手發出完全相同的溫度。」
3. **全知但不解釋**：敘事者知道洩漏的來源，但用**陳述**而非**解釋**的方式提及。不是「因為褶痕洩漏所以手發熱」，而是「手發熱了。一百年後同一隻手也會發熱。」
4. **長句流**：子句層層疊加，主詞跨越時代。「衛央刻下第173個座標的同時——儘管『同時』這個詞在這裡沒有意義——許若昕寫下了一個她無法解釋的步驟。」
5. **這個聲音會死**：在 Zone 5 末尾，褶痕敘事者的聲音和角色一起碎裂。它不是永恆的全知者——它是褶痕的投影，褶痕消融時它也消融。

**禁止事項（褶痕聲音專用）：**
- Zone 1-2：褶痕聲音不可超過每章 2 句（開場句 + 至多 1 句過渡）
- Zone 3：跨線長句每章不超過 3 次
- 褶痕聲音不可使用任何一條時間線的專屬語彙（不用古漢語、不用日文、不用英文技術術語、不用極簡短句）——它有自己的語言質地：流暢、平靜、跨越一切
- 褶痕聲音不可出現在角色的對話或內心獨白中——它只存在於敘事層

## 3. 七項禁止事項（嚴格遵守）

1. **禁止讓任何角色「知道」她們之間的連結**，直到第五區死亡場景
2. **禁止直接解釋情感殘影的來源**——讀者要自己感覺
3. **禁止讓物理解說超過敘事**——方程式和數學是道具，不是目的
4. **禁止讓陳明哲的審訊場景變成政治演講**——他是科學家，不是英雄
5. **禁止讓縫工的語言出現假設性句型**，直到故事後半段她主動打破禁忌（第27章）
6. **禁止四條線的語言質地互相污染**——衛央不會說「2055年的語言」，縫工不會說「166年的語言」。**唯一例外**：褶痕敘事者（第五種聲音）可以穿越所有聲音，但它有自己的獨立語言質地（見第2節「第五種聲音」），不屬於任何一條時間線。
7. **禁止在四死場景之前讓任何兩個角色「真正」對視**——只有殘影，沒有直接接觸

## 4. Zone 格式規則

| 區段 | 章數 | 每章字數 | 切換頻率 | 特殊格式 |
|------|------|---------|---------|---------|
| Zone 1（0-20%） | Ch 1-4 | 3000-5000字 | 無切換，單一時間線 | 各章獨立 |
| Zone 2（20-40%） | Ch 5-10 | 4000-6000字 | 每章一次插入（200-500字） | 主線 + 跨線滲漏段落 |
| Zone 3（40-65%） | Ch 11-17 | 6000-8000字 | 章內雙線並行 | 段落交替，兩條時間線 |
| Zone 4（65-85%） | Ch 18-22 | 6000-8000字 | 一章3-4次切換 | 每段1000-2000字 |
| Zone 5（85-100%） | Ch 23-28 | 2000-6000字（遞減） | 段落→句子級交替 | 最後兩章無標題，不標時間線代號 |

### Zone 5 四死交疊章節的特殊格式指示

```
- 無章節標題（第27-28章）
- 用空白行分隔四條時間線
- 不標注「[衛央]」「[陳明哲]」等——讓讀者自己辨認
- 段落長度從200字壓縮到最後的單句
- 四個時間線不按順序切換，要打亂——這本身就是「摺疊」的視覺感
```

## 4.5 褶痕感官簽名（撰寫洩漏場景必查）

每條褶痕有自己的感官簽名。撰寫任何跨時間線洩漏場景時，必須使用正確的簽名質地：

| 褶痕 | 代號 | 質感關鍵詞 | 辨識線索 |
|------|------|-----------|---------|
| 1947↔2055 | 墨痕 | 精確、手不受控、像抄寫 | 角色的手做了不受控的事 |
| 2055↔2301 | 裂口 | 過量、溢出、太多 | 資料淹沒了人 |
| 166↔1947 | 水漬 | 模糊、既視感、似曾相識 | 「我應該認識這個但我不認識」 |
| 166↔2301 | 體溫 | 存在性溫暖、不孤單 | 沒有來源的「有人在」的感覺 |
| 166↔2055 | 回聲的回聲 | 碎片、只剩數據 | 一個頻率、一個讀不懂的訊號 |
| 1947↔2301 | 餘燼 | 不屬於自己的熱度 | 不知道是悲傷還是愛的餘溫 |

**撰寫原則**：
- 不要命名褶痕（角色不知道有六條褶痕）
- 用感官簽名的質地讓讀者自己辨認
- Zone 5 四死交疊時，六種簽名同時出現——這就是褶痕共振
- 詳細定義見 `_world/world_bible.md` 第1節

## 5. 情感殘影插入格式

跨時間線的情感殘影插入，使用以下 markdown 標記慣例：

```markdown
<!-- RESIDUE: Thread [X] → [Y], ~[N]字 -->

[插入的情感殘影段落，使用被感知者的敘事聲音]

<!-- END RESIDUE -->
```

**撰寫原則：**

- 感知到的是情緒，不是訊息
- 角色永遠不知道那個情緒來自哪裡
- 不要解釋——讓讀者自己感覺到
- 兩個對應的場景盡量在同一章節或相鄰章節呈現（並排，無解釋）

**完整情感殘影對照表見**：`_meta/planning/emotional_residue_tracker.md`

## 6. Agent 工作流程（撰寫任何章節前必須依序確認）

```
Step 1: 確認這是哪條時間線（A/B/C/D）
Step 2: 查閱對應的角色卡（_characters/character_master.md）
Step 3: 確認這個章節在五區段結構的哪個位置（%）
Step 4: 確認這個章節的切換頻率和字數範圍（本文件第4節）
Step 5: 確認這個章節是否包含情感殘影場景（查閱 emotional_residue_tracker.md）
Step 6: 確認敘事聲音（本文件第2節）
Step 7: 確認服務的主題層次（查閱 outline.md）
Step 8: 撰寫前複習禁止事項（本文件第3節）
```
