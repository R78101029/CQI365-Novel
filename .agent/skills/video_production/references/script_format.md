# 小說 → 劇本 規則

## 一集的規格

- 總長 60–90 秒；6–9 個鏡頭；每鏡 8–10 秒
- 中文旁白語速約 4 字/秒 → **10 秒鏡頭的旁白上限 38 字**，寫超過後期一定塞不下
- 每鏡至少留 1.5 秒沒有人聲（讓畫面自己說話）

## 選材：挑情緒線，不挑劇情

一集要能獨立成立。不要試圖把一整章塞進 80 秒。

判準：**這 80 秒有沒有一個轉折？** 沒有轉折的片段再美都是幻燈片。
好的一集通常是「一個誤解被建立 → 一個物件洩漏了真相 → 一句話收在半途」。

## 林雨果風的轉譯鐵律

小說靠克制，影片靠留白。轉譯時最容易犯的錯是「怕觀眾看不懂」。

1. **旁白不解釋情緒。** 不准出現「她很難過」「他終於明白」。情緒交給畫面與停頓。
2. **旁白與畫面不要互相說明。** 旁白說錶，畫面就不要給錶特寫——給她的手。兩條線各說一半，觀眾自己接起來，那個接起來的動作就是感動。
3. **數字取代副詞。**「她看了一整天」不是「她看了很久」。
4. **收在半途。** 最後一鏡不要給答案，不要給和解，不要給結論鏡頭。
5. **每集至少一個不象徵任何事的細節。** 一杯沒喝的咖啡、窗外一台經過的公車。全片都是符號會很累。

## 劇本檔案格式（`01_script.md`）

```markdown
# {書名} 微短劇 EP{NN}：{集名}

- 預估時長 / 鏡頭數 / 旁白角色
- 取材章節：chapters/xx.md 第 N 段

## 出場實體
| ID | 說明 | ref 狀態 |
|---|---|---|
| CHAR-M | 修錶師 | ✅ cast/CHAR-M |
| PROP-WATCH | 那支錶 | ⬜ 待建 |

## S1 {鏡名} (0-10s)
- **出場**：CHAR-F 單人
- **畫面**：（中文，這一鏡看到什麼）
- **動作**：（會動的是什麼）
- **旁白 VO-M**：「……」（28 字）
- **連戲**：接 S0 尾幀 / 無
```

寫完直接可以轉成 `shots.json`，欄位是一對一的。

## Gate

劇本給使用者看時要一併回報：
1. 總秒數與每鏡秒數
2. 哪幾鏡有人臉（= 哪幾鏡的成本風險高）
3. 需要新建哪些 ref 資產
4. 取材自哪一章哪一段（讓使用者能回頭核對有沒有寫歪）
