# 渾天儀傳遞鏈與褶式方程碎片 (Physical Object Chain)

> 追蹤渾天儀（核心物件）在時間中的流轉，以及褶式方程碎片在四人身上的分布。

---

## 一、渾天儀傳遞鏈

### 完整流轉路徑

> **核心原則**：渾天儀的物理流轉不是褶痕的傳遞機制——它是**人類留下的記錄**。資訊的真正傳遞是通過六條褶痕的洩漏。渾天儀傳遞的不是資訊本身，而是「有人在那個時代看見了同樣的東西」這個驗證事實。衛央從天空閃光中「接收」了座標（這是褶痕洩漏），她把座標刻在渾天儀上（這是記錄）。渾天儀流轉到1947年，給了陳明哲一個起點，不是答案。

```
衛央（公元168-169年）
  └─ 將236個座標鑄刻在青銅渾天儀底座內壁
  └─ 位置：洛陽靈台觀測室
  └─ 選擇理由：「幾百年內不會有人拆開的位置」
      │
      ↓  渾天儀輾轉流傳（東漢→唐→宋→明→清）
      │  底座內壁的刻痕始終未被發現
      │
日本學者（1920年代）
  └─ 從洛陽發掘，帶至台北研究
  └─ 位置：台北（學術機構）
      │
      ↓  太平洋戰爭結束（1945），遺忘在台大地下室
      │
陳明哲（1947年2月）
  └─ 在台大地下室整理日治時期遺留文物時發現
  └─ 認出236個座標的分布符合薛丁格方程邊界條件
  └─ 位置：台大物理系地下室
      │
      ↓  二二八事件爆發（1947-02-28），帶往鹿港
      │
陳明哲藏入龍山寺（1947年3月15日）
  └─ 將渾天儀殘件 + 推導筆記 + 一封信 藏入龍山寺建築結構內
  └─ 位置：鹿港龍山寺，牆壁結構空隙內
      │
      ↓  封存108年（1947-2055）
      │
蘇顯宗發現（2055年）
  └─ 蘇顯宗（許若昕的博士生，來自鹿港）
  └─ 在龍山寺修復工程中從拆開的牆體中發現油布包裹
  └─ 內含：渾天儀殘件 + 陳明哲筆記本 + 信
      │
      ↓
許若昕讀到筆記（2055年）
  └─ 蘇顯宗帶回CERN
  └─ 許若昕確認：1947年方程 ≈ 2055年褶式方程模型
  └─ 這不再是理論——摺痕是真的
      │
      ↓  開摺實驗 → 因果混沌泡 → 許若昕死亡
      │  渾天儀實體命運不明（可能留在CERN或被蘇顯宗保存）
      │
縫工（2301年）
  └─ 在褶痕修復局歷史檔案「2055-GVA-ORIG」數據包中找到衛央的星圖
  └─ 許若昕在開摺實驗前將渾天儀236座標作為校準參數輸入LHC系統
  └─ 這些數據保存在因果混沌泡（②號褶痕的傷口）的結構裡
  └─ 縫工看到的是標記為「校準參數：來源不明，疑似古代天文數據」的數字
  └─ 她不知道這些數字來自一個1800年前的青銅器，只知道它們和褶痕結構完美吻合
```

### 渾天儀的物理描述

| 時期 | 狀態 |
|------|------|
| 公元166年（新造時） | 完整的青銅渾天儀，底座無刻痕 |
| 公元168-169年 | 底座內壁被刻入236個座標點 |
| 東漢末-清朝 | 渾天儀可能部分損壞，成為「殘件」，但底座保持完整 |

| 2055年（蘇顯宗發現時） | 被油布包裹，與筆記本和信一同封存在龍山寺牆內 |

## 二、褶式方程碎片分布

陳明哲在死前一刻（Ch 22）算出褶式方程的最終答案。這個答案以碎片形式分散在四個人身上：

### 碎片分布表

| 持有者 | 碎片形態 | 來源機制 | 持有者是否知道 |
|-------|---------|---------|-------------|
| **衛央** | 第236個座標的位置選擇——「莫名地準確」 | 該位置恰好是最終解的一個關鍵參數。衛央不知道為什麼選那裡。 | 否 |
| **陳明哲** | 完整答案（唯一知道全貌的人） | 死前一刻推導完成。帶著答案死去。 | 是（但無法傳遞） |
| **許若昕** | 開摺模型的「直覺跳躍」步驟 | 該步驟來自陳明哲死前算出的答案通過摺痕滲漏到她的直覺。她從未能完整解釋推導過程。 | 否（她只知道自己「直覺跳過了一步」） |
| **縫工** | 縫合路徑計算中「從夢裡想到的」參數 | 該參數來自陳明哲的答案通過摺痕滲漏。 | 否（她以為是夢） |

### 碎片的意義

- 三個碎片 + 陳明哲帶走的完整答案 = 褶式方程的完整解
- 但沒有任何活著的人知道全部
- 答案完整地存在了——在四個人同時死亡的那一刻
- 那個瞬間，永遠地，存在在摺痕裡
- 這就是全書的最終命題：**選擇的意義不在改變結果，在觀測行為本身改變了摺疊的幾何**
