# HalfFinished 專案｜快速指引（Agent 第一個讀）

> **新 session 第一件事**：讀完本檔 → 讀 `_meta/SPEC.md` 全文 → 動手前再瀏覽 `_meta/agent_guidelines.md`。

---

## 30 秒摘要

- **書名**：《半成品》
- **類型**：文學小說 / 當代寫實
- **規格**：19 章（春 4 / 夏 5 / 秋 5 / 冬 5）·彈性篇幅（春夏 7-10K / 秋 5-9K / 冬 3-8K）·全書 12-16 萬字
- **視角**：第三人稱有限·貼近主角意識·全書固定不切換
- **語言**：繁體中文·過去式為主

## 一句話核心

一個律師因為前妻過世·去墾丁處理她留下的半成品民宿。一年過去了。他沒有把民宿修好·也沒有理解前妻·更沒有變成一個完整的人。只是到春天時·他可以站在櫃檯後面對新客人說：「您好。」

**主角**：許平·40 歲·離婚兩年·無子女·勝訴派律師。不是冷漠·是笨——不知道自己在在乎。前妻離婚後搬到墾丁·買老房子改民宿·經營了約一年半（民宿尚未完成）·然後過世·遺囑把民宿留給他。他去「處理一下」·然後沒有離開。

---

## 這本書不是什麼

- ❌ 療癒小說
- ❌ 中年人成長小說
- ❌ 「一個長期負責的人學會停止補位」的主題作文
- ❌ 追憶逝水年華式的抒情散文
- ❌ 禪意小品
- ❌ 民宿老闆的溫暖日常
- ❌ 前妻留給他的救贖故事

**核心不是救贖·不是放手·不是療癒。核心是：讓一個不完整的人暫時待在一個不完整的地方·而不要急著把一切說明白。**

---

## 跟前三部（IRIS / 摺痕 / 惘然）的根本差異

**這部不套用任何前三部的方法論**。

| 前三部習慣 | 本書要求 |
|----------|---------|
| 飽滿、有層次 | **克制、留白、避免寫好** |
| 哲學透過對話/獨白明示 | **完全不明示·只透過結構** |
| 比喻豐富 | **接近零比喻** |
| 情感鋪陳渲染 | **主角不表露·讀者自己感受** |
| 章節間有預告/呼應 | **章節結尾不預告下一章** |
| 每章有明確結構功能 | **降低「每章都有功能」的感覺** |
| 系統性角色追蹤 | **變化不穩定·不線性** |

## 7 個高風險寫錯點（必避）

1. 陽台五分鐘 → **300-500 字內·無內心獨白**
2. 「你先生呢」那一幕 → **輕到讀者幾乎沒注意**
3. 第 14 章她沒來 → **他就是沒追·沒查·沒寫信**
4. 第 18 章陽台回憶 → **「他只是記起來」·不加詮釋**
5. 結尾「您好」（第 19 章）→ **書就停在這兩個字**
6. 前妻的物件 → **物件是她離婚後的東西·他不認識**
7. 「我」字頻率 → **每章寫完統計**（春 8-12 / 夏 6-9 / 秋 4-6 / 冬 2-4·每千字）

## 真正的提醒

> 這本書不是要證明主角成長。不是要證明前妻有意義。不是要證明民宿治癒了他。
