# Zone 1 章節規劃 — 楔子 + 各自的天空（Ch 0-4）

> **Zone 1 規則**：每章單一時間線，禁止跨線切換。3000-5000 中文字。開場順序：B → A → C → D。目標：建立四個獨立世界，累積情感投資。

---

## Ch 0 — 楔子：摺痕

| 欄位 | 內容 |
|------|------|
| **時間線** | 全（碎片） |
| **排序** | 0 |
| **字數目標** | 300-500字 |
| **聲音** | 無特定聲音——四條線的碎片交織，但此刻讀者無法分辨 |

### 場景設計

從 Zone 5 四死交疊場景中抽取的碎片句子。讀者此刻不會懂這些句子的意義，但它們會在潛意識中植入一種「預感」——這四個人的命運已經被寫在了某處。

### 草稿素材

```
她跪著。清晨的風從東邊來。她沒有低頭。

他聽見海浪。

信在她手裡，沒有燒壞。

泡內的光是所有時間的光，疊在一起，變成白色。

有人握住了她們的手。
```

### 設計意圖

- 等同《百年孤獨》開頭「多年以後，面對行刑隊」——先給結局的碎片，再展開起因
- 讀者在 Zone 1 看到渾天儀、靈台、CERN 和修復局時，會帶著一種模糊的不安——知道某些可怕的事情會發生
- 楔子中的每一個句子，都會在 Zone 5 中被完整呈現。讀者到時候會認出它們。

### 格式

- 無章節標題，只用書名「摺痕」作為開頭
- 極短段落，用大量空白行分隔
- 不標注任何角色名字、時間、地點

### 本章禁止

- 不可出現任何角色的名字
- 不可出現任何時間標記（年份、朝代）
- 不可出現任何解釋性文字

## Ch 1 — 渾天儀

| 欄位 | 內容 |
|------|------|
| **時間線** | Thread B |
| **主角** | 陳明哲 |
| **時代** | 1947年2月 |
| **排序** | 1 |
| **字數目標** | 4000字 |
| **聲音** | Thread B（知識分子的沉靜、偶爾浮現日文思維） |

### 場景設計

1. **開場**：台大物理系地下室，1947年2月某個下午。陳明哲在整理日治時期遺留的文物。灰塵、木箱、被遺忘的學術器材。他用日文在腦中分類這些東西。

2. **發現渾天儀**：打開一個標記為「洛陽出土、年代不詳」的木箱，發現青銅渾天儀殘件。底座內壁有刻痕——不是裝飾紋路，是系統性的座標標記。236個點。

3. **初步辨識**：陳明哲認出點的分布模式。他的量子力學訓練讓他看見：這些點的位置符合薛丁格方程的邊界條件——一個描述粒子穿隧效應的數學結構。但這被刻在1800年前的青銅器上。

4. **時代氛圍**：地下室外面的世界——同事們在討論「本省人」與「外省人」的衝突。有人提到菸酒專賣局的事。陳明哲沒有參與討論，他回到方程式前面。

5. **林秀英的存在**：他想到妻子在鹿港等他回家過年。她上次來信問他什麼時候回去。他還沒回信。他想等方程式告一段落再回去——他不知道這個「告一段落」永遠不會來了。

6. **結尾**：他開始在筆記本上推導。手微微發抖——不是因為害怕，是因為興奮。一個不可能的問題正在變成一個可以計算的問題。

### 情感核心

一個知識份子發現不可能之物的震動。物理的美感 vs 外部世界正在崩裂。林秀英的提及讓讀者知道：有人在等他。這讓後面所有的事情都更重。

### 本章禁止

- 不可提及任何跨時間線感知。
- 不可暗示其他角色存在。

## Ch 2 — 天裂

| 欄位 | 內容 |
|------|------|
| **時間線** | Thread A |
| **主角** | 衛央 |
| **時代** | AD 166 |
| **排序** | 2 |
| **字數目標** | 3500字 |
| **聲音** | Thread A（克制、觀測日誌的節奏感） |

### 場景設計

1. **開場**：夜間，洛陽靈台觀測室。衛央以男裝身份值夜班。她的動作精確、安靜——一個習慣了隱藏的人。

2. **異常閃光**：天空出現一道不屬於任何已知天象的閃光。不是流星，不是雷電。位置不對，持續時間不對，顏色不對。她記錄下來：位置、時間、亮度、持續。

3. **靈台內部**：其他書記官在打瞌睡。沒有人看見。或者看見了，選擇不記錄——因為「不存在的天象」記錄下來就會變成政治問題。

4. **黨錮背景**：簡短帶入——最近有幾個士人因「妄議天象」被帶走。靈台裡的空氣變得小心翼翼。

5. **結尾**：衛央把閃光記錄寫在私人竹簡上，不是官方記錄。她鎖好匣子。窗外天快亮了。

### 情感核心

在恐懼的時代，一個人選擇如實記錄真相的安靜勇氣。

### 本章禁止

- 不可使用現代心理學詞彙。
- 衛央的恐懼要通過動作呈現，不是內心獨白。

## Ch 3 — 展開

| 欄位 | 內容 |
|------|------|
| **時間線** | Thread C |
| **主角** | 許若昕 |
| **時代** | 2055年3月 |
| **排序** | 3 |
| **字數目標** | 4500字 |
| **聲音** | Thread C（當代、精準、黑色幽默） |

### 場景設計

1. **開場**：CERN地下實驗室，許若昕在檢視最新的LHC數據。偵測器記錄到一批粒子衰變異常——粒子在衰變前「知道」衰變後的狀態。

2. **褶式方程的雛形**：她在白板上推導。一個同事說「你的模型暗示時間不是基本維度」。她說「我的模型暗示時間是一張被摺起來的紙」。

3. **弟弟的傷痛**：在CERN地面休息區，看見新竹的新聞（戰後重建進度）。她想到弟弟。2043年的爆炸。她沒有哭——她已經不太哭了。但她回到實驗室後，工作效率更高了。

4. **蘇顯宗登場**：來自鹿港的博士生，剛加入她的團隊。安靜、聰明、對許若昕有點畏懼。

5. **自指性質初現**：她發現方程式的一個奇怪特性——它似乎在描述自己。一個描述時間摺疊的方程式，本身可能就是摺疊洩漏出來的資訊。她在筆記本上寫：「*self-referential?*」

6. **結尾**：她站在CERN的地面出入口，抽菸（2055年歐洲已經很少人抽了），看著超過50°C的夏日天空。「如果時間真的是摺起來的，那弟弟的最後一秒——」她沒有想完這個念頭。

### 情感核心

用物理學悼念的人。科學發現背後的私人動機。

### 本章禁止

- 不可過度詩意。
- 技術術語要自然嵌入。

## Ch 4 — 最後的技師

| 欄位 | 內容 |
|------|------|
| **時間線** | Thread D |
| **主角** | 縫工 |
| **時代** | 2301 |
| **排序** | 4 |
| **字數目標** | 3000字 |
| **聲音** | Thread D（疏離、短句、禁止假設語氣） |

### 場景設計

1. **開場**：褶痕修復局，例行監測報告。縫工記錄泡的擴張數據：0.003%。日誌格式。極簡。

2. **世界觀建立**：通過縫工的日常動作自然帶出——軌道城市「恆紀」的生活、窗外的地球（30%被泡覆蓋）、第八代不曾踩上地面的人類。不要用長段落解釋，讓細節自然流出。

3. **修復局**：幾乎空了。自動化系統接管了大部分工作。縫工是最後一個人類技術員。她的上司偶爾出現，例行公事。

4. **文化禁忌**：有人在走廊說了「如果……」，立刻被別人打斷。縫工沒有反應。她很久以前就不說那個詞了。

5. **結尾**：她在監測系統上看見一個微小的異常訊號——不像泡的正常波動。她記錄下來。沒有多想。明天繼續監測。

### 情感核心

極度孤獨的日常。一個被遺忘的人在被遺忘的崗位上做被遺忘的工作。

### 本章禁止

- 嚴禁使用「如果」「假如」「要是」「萬一」。
- 嚴禁情感形容詞。
- 嚴禁長句。
