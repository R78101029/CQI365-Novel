# 語言質地指南｜四季的文字曲線

> 用文字實現哲學的核心技術。
> 四季的文字質地必須有**可以被統計驗證**的差別。
> SPEC.md 第 7 節展開版·寫每章前查對應季節。

---

## 春（第 1-5 章）

| 維度 | 設定 |
|------|------|
| 句長 | 平均每句 **20-30 字** |
| 形容詞密度 | **高**（不過度·但豐富） |
| 建築師腦詞彙 | **大量出現**：結構、承重、防水、施工、動線、容積率、使照、竣工、設計變更、監造、配筋、裂縫、滲水、樑柱、隔間、RC、鋼筋、模板 |
| 「我」字頻率 | **每千字 8-12 次** |
| 段落長度 | **長**（每段 100-200 字） |

### 春天的氣味
- 主角全力運用建築師腦
- 句子有結構感、條理感
- 對話帶有「處理事情」的精準
- 形容詞用在物件與環境（不在情感）
- 她看一切都是結構問題：牆面、管線、動線、防水、承重
- **書寫態度**：彷彿你還在寫施工報告·不是在寫小說

---

## 夏（第 6-10 章）

| 維度 | 設定 |
|------|------|
| 句長 | 平均每句 **15-25 字**（縮短） |
| 形容詞密度 | **下降**·不再用為了寫好 |
| 建築師腦詞彙 | **逐章降低**·夏末（第 10 章）幾乎消失 |
| 「我」字頻率 | **每千字 6-9 次** |
| 段落長度 | **變多樣**（有些 100+·有些 2-3 行） |
| 物件描寫 | **增加**：風扇、冰箱、熱水壺、紗門、落葉、渡輪汽笛 |

### 夏天的氣味
- 開始有實際操作的物理性
- 句子變短·像她變得不再多想
- 建築師腦詞彙漸少·**第 6 章只剩零星·第 10 章幾乎沒有**
- 段落長短不一·像呼吸節奏不規則
- **書寫態度**：你正在做事·不是在思考

---

## 秋（第 11-15 章）

| 維度 | 設定 |
|------|------|
| 句長 | 平均每句 **12-20 字**（更短） |
| 形容詞密度 | **進一步降低** |
| 建築師腦詞彙 | **完全不再用** |
| 「我」字頻率 | **每千字 4-6 次**（明顯下降） |
| 段落長度 | **多數短** |
| 對白比例 | **增加**（尤其第 13 章剝橘子）|
| 句末留白 | **不補足每一個句子該有的資訊** |

### 秋天的氣味
- 句子帶有節奏的呼吸感
- 對白多但不長·常以單詞回應（「啊」「嗯」「是」）
- 句末留白：刻意不寫完·讓讀者自己補
- **書寫態度**：你在聽·不是在說

### 句末留白範例

| 飽寫（禁） | 留白（要） |
|----------|-----------|
| 她把碗放回水槽·覺得有點累。 | 她把碗放回水槽。 |
| 她笑了一下·眼神有點黯淡。 | 她笑了一下。 |
| 雨開始下了·這樣的天氣總是讓人想起什麼。 | 雨開始下了。 |

---

## 冬（第 12-15 章）

| 維度 | 設定 |
|------|------|
| 句長 | 平均每句 **10-18 字**（最短） |
| 形容詞密度 | **極低** |
| 建築師腦詞彙 | **幾乎沒有** |
| 「我」字頻率 | **每千字 2-4 次**（極低） |
| 段落長度 | **短**（許多段落只一兩行） |
| 描寫方式 | **單一物件 + 單一動作**：「她削柚子」「貓在門邊」「海是灰色的」 |
| 最後一章 | 接近**俳句**的節奏 |
| 每章篇幅 | **3,000-8,000 字**（冬季允許短章·第 15 章可短至 2,000-3,000 字） |

### 冬天的氣味
- 短句連發·一句一行·不串
- 形容詞接近消失·動詞主導
- 沒有「我覺得」「我發現」
- **書寫態度**：你存在·但不主張

### 第 15 章的俳句節奏範例

```
新客人來電。

四月。一週兩晚。

她翻訂房本。

字寫得歪。

新客人進門。

「您好。」
```

## 「我」字頻率：人工統計流程

> Agent 無法自動控制這個頻率·**每章寫完必須跑**。

### 步驟

1. 跑全章字數:
   ```bash
   node scripts/chapter-stats.mjs --novel=HalfFinished --verbose
   ```
2. 開該章 .md 檔·**手動數「我」字次數**（用編輯器搜尋計數）
3. 計算頻率：`(我字次數 / 中文字數) × 1000` = 每千字次數
4. 對照本表:

| 季 | 章 | 目標頻率（每千字） |
|----|----|----|
| 春 | 1-5   | 8-12 |
| 夏 | 6-8   | 6-9 |
| 秋 | 9-11  | 4-6 |
| 冬 | 12-15 | 2-4 |

5. **超出區間 → 回章節刪「我」字**·重新計算

### 為何這個指標重要

- 「我」字密度反映**主角作為敘事中心的重量**
- 第三人稱小說裡·「我」字主要出現在對白與引述思想
- 春到冬下降 → **主角在敘事中漸漸退場**
- 對應金剛經「如夢幻泡影」——「我」這個概念本身在淡化

讀者不會明說察覺·但會**身體感覺到**章節節奏的變化。

## 日語滲透曲線

林若筠不學日語。她不買教材、不上課、不刻意記。但她住了一年。語言會自己滲進去。

### 四季進程

| 季 | 章 | 她的理解程度 | 寫法 |
|----|-----|-----------|------|
| 春 | Ch3-5 | **完全聽不懂**。港口的老人講日語·她一頭霧水。買東西靠比手畫腳。すみません 和 ありがとう 是她僅有的兩個詞。 | 日語出現時敘事寫她的困惑：聽不懂、猜不到、沉默。喜劇摩擦 |
| 夏 | Ch6-8 | **能從語境猜意思**。鄰居颱風前來敲門說日語·她聽不清楚每個字·但從情境（天氣、搬東西、語氣、手勢）猜到大意。不是因為學了·是因為處境逼她 | 日語仍不翻譯·但她的行動顯示她聽懂了大意 |
| 秋 | Ch9-11 | **聽懂零星幾個詞·不會說**。偶爾能抓住一兩個詞·但無法回日語。仍然用英文單詞或比手畫腳回應 | 少量日語詞可以不加註釋地出現在敘事中·因為讀者這時跟主角一樣已經聽了半年 |
| 冬 | Ch12-15 | **聽懂日常短句**。「風が来る」（風要來了）、「猫どこ」（貓在哪）、「大丈夫」（沒關係）、「おはよう」（早安）。不是從學習來的·是從住在這裡來的 | 日語短句直接嵌入敘事·不翻譯·不標註。讀者跟主角一起已經「會」了 |

### 關鍵日語詞的出場安排

| 日語 | 意思 | 出場章 | 用法 |
|------|------|--------|------|
| 「すみません」「ありがとう」 | 不好意思／謝謝 | Ch3-4（春） | 她僅有的兩個詞。用得太頻繁·有時用錯場合·鄰居微笑 |
| 「だめ」 | 不行 | Ch6-7（夏） | 鄰居阻止她做某事時說的·她從語氣猜到意思 |
| 「風が来る」 | 風要來了 | Ch12 或 Ch13（冬） | 她聽到了·而且她知道這是什麼意思。不驚訝·不感慨。就是知道了 |
| 「猫どこ」 | 貓在哪 | Ch12 或 Ch13（冬） | 她或鄰居說的·自然的。不標示「她居然會說日語了」 |
| 「大丈夫」 | 沒關係／沒事 | **Ch13 或 Ch14**（冬·最後幾章之一） | 全書日語曲線的收尾。可以是她聽到的·也可以是她自己說的（如果她自己說·寫得極輕·她自己沒意識到她說了日語） |
| 「おはよう」 | 早安 | Ch12-13（冬） | 日常招呼·自然嵌入·不標記 |

### 撰寫紀律

- **不寫「她開始聽懂日語了」這種後設觀察**。她不會意識到自己的語言在變
- **不安排學習場景**（不翻字典、不問鄰居「這個怎麼說」、不練習）
- 日語的滲入跟她的變化一樣：**不是決定·是發生**
- 「大丈夫」出現在最後幾章時·不要強調。它就是一句話。但讀者會知道：她已經不是春天那個人了
