## 角色卡 A｜衛央

```
姓名：衛央
時間線：Thread A
時代：公元166年前後，東漢桓帝年間
地點：洛陽靈台（皇家天文台）
年齡：約24歲
身份：靈台低階書記官（女扮男裝）
```

### 身份的三重危險

1. 女性在靈台——發現即死罪
2. 持有不符官方敘事的天象數據
3. 拒絕將數據交給鄭衡用於政治操作

### 核心性格

她不是英雄，也不是殉道者。她只是一個無法對自己說謊的人。
她的決定永遠是最小可能的行動：「如果我只能做一件事，我要讓它穿過時間。」

### 她做了什麼

- 兩年間秘密記錄236次天空異常閃光
- 發現閃光位置構成一個只有在「摺疊」的平面上才能閉合的幾何結構
- 將完整數據鑄刻在青銅渾儀的底座內壁（一個幾百年內不會有人拆開的位置）
- 拒絕將數據交出，因為她知道「這不是預言，是洩漏過來的事實」

### 她的時代苦難（黨錮之禍）

公元166年，宦官集團將數百名儒家知識份子列為「黨人」，禁錮、下獄、殺。
罪名是「結黨誹謗朝廷」。真實原因是：這些人讀書、有意見、持有不符合官方敘事的知識。

關鍵場景：她的前輩太史令蔡某，因在奏摺如實記錄一次政治上「不應該發生」的日蝕，被列入黨人名單帶走。蔡某最後對她說：「你記的那些閃光，不要讓任何人看見原件。抄一份假的讓他們找到。」

### 死亡

被發現的原因：一個小宦官撿到她遺落的竹簡，字跡不像男人的字。身份暴露，數據被翻出。

行刑地點：清晨，靈台外的空地，面朝東方。

最後的話：主審官問「你藏下那些數字，為的是什麼？」她沒有回答，只看著天空說：「今天沒有異常閃光。」

死亡時感知到：縫工在2301年讀到她的星圖時的「被看見」感。

### 褶式方程的碎片（她的部分）

她刻下的第236個座標，位置「莫名地準確」——她當時不知道為什麼選那裡。那個位置正好是褶式方程最終解的一個關鍵參數。

### 情感殘影方向

- **發送**：她刻下最後一個座標時，感到「有人在非常遠的地方以她聽不見的聲音說了某句話」
- **接收**：偶爾抬頭看星空，感到莫名的「不孤單」（來自縫工在2301年讀取她的星圖時的感動）

### 哲學困境

如果你收到了來自未來的訊息，但你無法證明它是什麼，保存真相的意義是什麼？為誰保存？

### 228結構對應

- **知識即罪狀**：真實天象數據
- **身份即目標**：女性＋拒絕配合官方敘事
- **暴力的結構性**：黨錮的邏輯不需要惡意
- **她的回應**：「藏」而非「說」

## 角色卡 B｜陳明哲

```
姓名：陳明哲
時間線：Thread B
時代：1947年，二二八事件前後
地點：台北 → 鹿港
年齡：約32歲
身份：物理學者（京都帝國大學量子力學出身，戰後返台）
```

### 身份的殖民史層疊

- 1931年：父親送他去日本學校，因為日本學校才有前途
- 1941年：京都帝大讀物理，用日文思考，用日文做夢
- 1945年：回台灣，被叫「日本狗」
- 1947年：被國民政府視為「奴化份子」

他是語言上的難民——沒有一種語言讓他完整地是自己。他的物理學詞彙最精確的部分是日文的。

### 他做了什麼

1947年，在台大地下室整理日治時期遺留文物時，發現那個青銅渾儀殘件（衛央藏下的那個），內壁有236個座標點。
他認出這些點的分布符合薛丁格方程的邊界條件——一個描述粒子穿隧效應的數學結構，被刻在1800年前的青銅器上。
他開始推導，得出結論：「穿隧」的不是粒子，而是資訊本身穿越了時間維度。

### 228的時間線（融入故事）

| 日期 | 陳明哲的位置 | 外部事件 |
|------|------------|---------|
| 2月27日 | 台大地下室，研究渾儀 | 查緝私菸，一死 |
| 2月28日 | 聽見槍聲，沒有出門 | 台北爆發 |
| 3月8日 | 同事失蹤，打包準備 | 國軍登陸基隆 |
| 3月10日 | 連夜逃往鹿港 | 全島清鄉開始 |
| 3月15日 | 藏好東西，寫信 | 鹿港周邊搜查 |
| 3月17日 | 被捕 | — |

### 告密者的設定

鄰居，外省籍小官員，剛從大陸來，聽不懂台語，看見陳明哲夜裡抱著「東西」回來，以為是武器。他不是壞人，只是害怕。被帶走時那個鄰居站在巷口，沒有看他。
（228的結構不需要惡意，只需要恐懼。）

### 審訊場景

審訊官不懂物理，看著方程式問「這是密碼嗎？」
陳明哲說「是方程式。」
「是誰的命令叫你寫這些？」
沉默後：「沒有人的命令。我只是想知道時間是什麼形狀的。」
軍官聽不懂，也不需要懂。名單上有名字，就夠了。

### 死亡

地點：海邊，天剛亮。

死前狀態：一直在默算褶式方程——因為他不知道還能做什麼，他的大腦就是這樣運作的。

死前一刻：他把褶式方程的最後一步算完了。他帶著答案死去。

槍聲。

死亡時感知到：許若昕在2055年讀到他的筆記時的震驚與哀傷，感到「手被握住」。

### 他留下的

1. 渾儀殘件，藏在鹿港龍山寺的建築結構內
2. 推導筆記，藏在同一位置
3. 一封給「未來打開摺痕的人」的信，信的最後一行：

> 「如果你正在讀這封信，代表我的數學是對的。也代表你即將犯一個無法挽回的錯誤。不是因為你的計算有誤，而是因為你和我一樣——太想知道答案了。」

### 褶式方程的碎片（他的部分）

書寫筆記時，他會無意識地寫下自己不認識的符號。那些符號後來被證明是2055年CERN使用的標準化粒子物理符號。他的手在寫未來的語言。
他死前算出的最終答案，以碎片形式分散到其他三人身上。

### 情感殘影方向

- **發送**：藏筆記入牆的最後一刻，手感到「從外部傳來的熱」（來自許若昕讀到筆記時的感動）
- **接收**：書寫時手發抖，感到「被接住」的感覺（來自許若昕在未來等著他的推導）

### 哲學困境

他活在一個歷史的摺痕中。如果你知道未來存在，但你活不到那裡，這個知識是救贖還是酷刑？

### 228結構對應

- **知識即罪狀**：量子力學推導＋日治文物
- **身份即目標**：台灣人＋日本教育的「奴化份子」
- **暴力的結構性**：清鄉的邏輯
- **他的回應**：把真相塞進牆裡

## 角色卡 C｜許若昕

```
姓名：許若昕
時間線：Thread C
時代：2055年
地點：日內瓦CERN + 新竹
年齡：約42歲
身份：台灣理論物理學家，CERN維度拓撲研究組組長
```

### 她弟弟的死（核心傷痛）

2043年，無人機攻擊。不是在戰場，是在新竹的家裡，因為附近有一個被列為「軍事目標」的通訊設施。他死的時候22歲，是清大電機系學生，正在準備期末考。

她的開摺研究有一個沒有寫進論文的動機：如果時間可以摺疊，那個早晨，那個爆炸，那個弟弟的最後一秒——是否還在某個地方存在著？

她不是純粹的科學家。她是一個用物理學在悼念的人。

### 她做了什麼

發現LHC最新升級中，某些粒子衰變模式顯示粒子在衰變前「知道」衰變後的狀態——違反因果律，或更精確地說：因果律不是線性的。

她建立數學模型：時間維度存在自然摺疊，在「摺痕處」，不同時間點的資訊可以通過量子穿隧互相洩漏。

她稱人工放大摺痕的過程為「開摺（Unfolding）」。

她拒絕向「東亞科技共同體」共享數據，獨立執行實驗。

### 蘇顯宗（她的博士生）

來自鹿港的台灣學生。在實驗準備期間，在家鄉龍山寺修復工程中發現陳明哲1947年藏的筆記和渾儀殘件。把一切帶給許若昕。

當她看見1947年的方程式與她2055年的模型幾乎完全相同時：這不再是理論。摺痕是真的。

### 開摺實驗的後果

因果混沌泡誕生，直徑數公尺，緩慢擴張，無法消失。她打開了潘朵拉的盒子。

### 死亡

暗殺者：「第一因守護者」(Guardians of the First Cause) 宗教組織，認為殺死開摺者可以讓時間自我修復。其行動資金部分來自不願被查的政治勢力。

地點：CERN地面出入口，走向停車場時。手裡拿著陳明哲的信。

炸彈在距她三公尺處爆炸。她沒有當場死，躺了約兩分鐘。

最後的想法：
「真的很荒謬。把門打開的人，被門殺了。」
然後她想到陳明哲的信說得對，換一次她還是會做。
然後她想到弟弟，希望他知道她找到了。
然後她死了。信沒有燒壞。

死亡時感知到：衛央刻座標時的平靜，聽見鑿刻聲，看見一個正在刻東西的女人轉過頭對視。

### 褶式方程的碎片（她的部分）

開摺模型有一個她自己稱為「直覺跳躍」的步驟，她從未能完整解釋推導過程——那個步驟來自陳明哲死前算出的答案通過摺痕滲漏到她的直覺裡。

### 情感殘影方向

- **發送**：讀到陳明哲筆記時雙手發熱，感動得哭
- **接收**：實驗前72小時，偵測器記錄到鑿刻聲頻率（來自衛央1800年前刻座標的震動）

### 哲學困境

她打開了潘朵拉的盒子。在因果混沌泡內她第一次「看見」衛央和陳明哲。她是第一個有能力摧毀線性時間的人。這是進步，還是終結？

### 228結構對應

- **知識即罪狀**：開摺實驗數據
- **身份即目標**：台灣人＋拒絕向政治力量交出知識主權
- **暴力的結構性**：政治利益×宗教狂熱，主謀永遠不出現在現場
- **她的回應**：她死了，門已經打開，無法關上

## 角色卡 D｜縫工

```
姓名：無（被稱為「縫工」）
時間線：Thread D
時代：公元2301年
地點：軌道城市「恆紀」
年齡：不明（外貌約35歲）
身份：摺痕修復局最後一位技術員
```

### 官方歷史謊言（2301年的228結構）

官方版本：「2055年日內瓦事故」是「極端民族主義科學家」無視國際監管委員會警告，擅自進行未授權實驗的結果。主要責任人：許若昕（台灣籍）。

真相：警告文件是事後偽造的，用來轉移責任，讓「東亞科技共同體」的失職不被追究。

縫工知道這個真相，因為她接觸到原始2055年實驗數據，和官方版本根本對不上。她投稿質疑的論文被退回，理由是「選題不符合社會和諧原則」。上司說：「你知道就好，不要寫出來。」

這是228在2301年的形態：暴力不需要了，沉默是自我執行的。

### 家族史的空白

她的曾曾曾祖母，台灣人，在某個歷史節點「失去記錄」。官方說是「資料遺失」。

她一直覺得那個空白的形狀，和她在摺痕數據裡看見的某種結構，很像。

（作者備注：那個人就是許若昕的後裔。這個連結可以在第三區隱晦暗示，不需要明說。）

### 她做了什麼

發現縫合摺痕的悖論：需要從泡內取得開摺實驗的原始數據，但泡內沒有線性時間，任何進入者都會被因果混沌摧毀。

她的解方：褶式方程描述的不只是摺疊，也描述觀測者與摺疊的關係。關鍵不在「關閉」摺痕，而在改變人類意識與時間的關係。需要四個觀測點——四個分布在摺痕不同位置的意識，同時做出同一個選擇。

她意識到：衛央、陳明哲、許若昕，和她自己，一直都是那四個點。

### 在進入泡之前

她把所有關於真實2055的研究數據，用沒有人注意到的方式，嵌入摺痕修復局的基礎監測程式碼裡——不是作為可讀文件，而是作為演算法的一部分，會在特定條件下自動浮現。

她想：我不知道誰會看見。但總會有人。（同衛央刻進青銅的邏輯。）

最後的工作日誌（語氣和所有之前的日誌完全一樣）：

> 「2301.09.14 | 技術員末班記錄 | 摺痕共振預計4小時內到達臨界。錨點部署完成。如無意外，修復序列將自動啟動。後續監測請移交AI系統Henji-7。——縫工」

### 死亡（消融）

她走進因果混沌泡——這是她人生中第一次沒有猶豫的動作。

泡內第一秒：視覺開始接收非線性的光，看見不同時代疊加的地球影像——有城市，有森林，有她從未見過的海。她感到一種沒有名字的情緒。後來她理解那是：家的感覺。

她的線性時間在泡內開始溶解。

從外部觀測者角度：她走進去，消失了。

從她自己的角度：她同時經歷了一切。

### 褶式方程的碎片（她的部分）

縫合路徑計算中，用了一個她形容為「從夢裡想到的」參數——那個參數來自陳明哲死前算出的答案通過摺痕滲漏。

### 情感殘影方向

- **發送**：監測系統上辨認出衛央的星圖時，感動得想哭
- **接收**：監測數據中偶爾感知到一種不是她自己的「渴望活著的熱度」（來自陳明哲在龍山寺哭泣的那個夜晚）

### 哲學困境

縫合摺痕意味著讓人類回到線性時間的「幻覺」中——安全但無知。不縫合意味著泡吞噬一切——但泡內的存在是否是一種超越線性因果的新狀態？她最終選擇了第三個選項：讓人類學會在摺痕中生存。

### 228結構對應

- **知識即罪狀**：真實的2055歷史
- **身份即目標**：持有禁忌記憶的技術員
- **暴力的結構性**：認知校正——不殺你的身體，殺你的記憶。社會禁忌自我執行，不需要外部暴力，因為每個人都看過七號技師的下場。
- **她的回應**：把真相藏進系統的骨架裡

## 次要角色

### 蘇顯宗

- **身份**：許若昕在 CERN 的博士生（2055年，約26歲）
- **出身**：鹿港人，清大物理系畢業後赴 CERN 攻讀博士
- **角色功能**：物件傳遞鏈的關鍵中介，連接 Thread B 和 Thread C。他與陳明哲沒有任何直接關係——他是108年後偶然在故鄉龍山寺修復工程中發現陳明哲遺物的人。這個「偶然」本身暗示了褶式方程的運作。
- **關鍵行動**：2055年回鹿港過節，碰巧遇上龍山寺修復工程。在被拆開的牆體結構中發現油布包裹的渾天儀殘件、筆記本和一封信。帶回 CERN 交給許若昕。
- **與許若昕的關係**：表面上是師生。但許若昕對蘇顯宗有一層她自己可能未完全意識到的情感投射——蘇顯宗26歲，聰明、安靜、來自台灣，和她弟弟死時的年紀（22歲）相近。她對蘇顯宗的保護本能超過了一般導師對學生的關懷。蘇顯宗感覺到了這一點，但從未提起。
- **許若昕死後**：蘇顯宗是渾天儀殘件和陳明哲筆記本的最後保管者。他也是唯一知道許若昕完整研究的活人。他的後續命運在小說中未明說。

> **作者備注**：蘇顯宗不是「被安排的傳承者」，他是被摺痕選中的巧合。這比刻意的傳承更符合本書主題——真理不需要英雄，只需要一個在對的時間出現的人。

- **小宦官**：撿到衛央竹簡、發現字跡異常的人

### Thread B 次要角色

  - 鹿港人，小學教師，29歲
  - 1944年在鹿港嫁給陳明哲（當時他剛從京都回台）
  - 她聽不懂物理，但她知道丈夫「在做很重要的事」。她從不問那些方程式是什麼。
  - 1947年2月：陳明哲在台北研究渾天儀時，她在鹿港等他回家過年。他沒有回來。
  - 3月10日：陳明哲連夜逃回鹿港。她看見他抱著東西進門，沒有問。幫他找到龍山寺的藏匿點。
  - 3月15日：陳明哲藏好東西後回到家。他想對她說些什麼，但只說了「如果有人來問，你什麼都不知道。」她說「我本來就什麼都不知道。」
  - 3月17日後：陳明哲被帶走，再沒有回來。她一生沒有再嫁。沒有人告訴她丈夫死在哪裡。
  - **敘事功能**：她是228中「等待的人」——不知道發生了什麼，只知道有人沒有回來。她的存在讓陳明哲的死從「一個科學家的犧牲」變成「一個丈夫的消失」。讀者透過她感受到：暴力不只殺死了一個人，也殺死了一個家。
  - **出場章節**：Ch 1（提及，陳明哲想到她在鹿港等他）、Ch 10（他回到鹿港時見到她）、Ch 20（藏東西時她的協助）
- **外省籍鄰居**：告密者，不是壞人，只是害怕。聽不懂台語，以為陳明哲深夜攜帶的是武器。被帶走時站在巷口，沒有看他。
- **審訊官**：不懂物理，把方程式當密碼。「這是密碼嗎？」「是方程式。」

### Thread D 次要角色

- **縫工的上司**：「你知道就好，不要寫出來」。他不是壞人——他也知道真相，但他選擇了活著。
- **七號技師（被認知校正的前同事）**：
  - 修復局前技術員，比縫工早三年進入修復局
  - 也發現了2055年官方歷史與原始數據的矛盾
  - 不同於縫工的沉默，她選擇了公開——向「恆紀」的公共資訊網路發布了一份質疑報告
  - 報告在14分鐘內被撤下。三天後，她被送去「認知校正中心」進行「摺痕焦慮症治療」
  - 「認知校正」的本質：選擇性記憶抹除。不是殺你，而是讓你忘記你曾經知道什麼。手術後，你還是你，你還在上班，你還會笑——但你不再記得那些數字為什麼不對。
  - 校正後的七號技師回到修復局繼續工作。她每天和縫工擦肩而過。她的眼神是平靜的——那種只有不記得自己失去了什麼的人才有的平靜。
  - **敘事功能**：七號技師是2301年228結構的具體化。暴力的進化形態——你甚至不需要被殺，你的記憶就是你的墳墓。縫工每天看到她，就是每天看到一個活著的警告：「這就是說出來的代價。」
  - **對縫工的影響**：縫工選擇沉默，不是因為她不勇敢，而是因為她看到了勇敢的代價。她最終選擇了第三條路——不說出來，也不沉默，而是把真相藏進代碼裡。
  - **出場章節**：Ch 4（走廊擦肩而過）、Ch 8（縫工查檔案時想到她）、Ch 18-19（更多互動，讓「認知校正」的恐怖具體化）
