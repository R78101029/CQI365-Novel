# 墨雨

雨連下了三天。

不是三天沒停。是三天沒有小過。基隆的雨有幾種等級——毛毛的、正常的、不正常的。這三天是不正常的。窗外的聲音從「有人在敲鼓」變成「有人把鼓翻過來用水灌」。鐵皮屋頂的共振從嗡變成轟。我在書房裡坐著，能感覺到空氣在震。

我幾乎沒出過書房。

桌上堆了三個泡麵碗，一個疊一個。最上面那個還有半碗湯，筷子斜插在裡面。中間那個空了，碗裡乾了一層油。最下面那個碗裡的湯已經完全乾了，留了一圈鹹的結晶，灰白色的，像岸邊退潮後的鹽線。

咖啡杯裡的殘液發酸了。我能聞到——一種比正常咖啡味更尖的東西。我把杯子推到桌角。推的時候碰到了那支鈍掉的鉛筆，鉛筆滾了一下，停在便條紙旁邊。便條紙還是空白的。

書房裡的空氣比前兩天悶。窗戶沒開——雨太大了，開了水會飄進來。飄進來的不只是水，是基隆的潮氣，帶著海的鹹和山的黴。我能聞到自己的味道。T恤兩天沒換了。

第二天晚上樓下的排水孔堵了。我聽到水在管子裡的聲音變了，從流變成灌，中間夾著氣泡爆開的悶響。我沒有下去看。那不是我的管子，也不是我的樓層。但那個聲音在夜裡持續了大概四十分鐘，然後自己好了。

第三天早上我看窗外，巷子裡積了水，大概到腳踝。對面那戶人家的門檻用木板擋起來了，木板底下塞了毛巾。有人在裡面走動，影子經過窗戶兩次。

我沒有出去。我不需要出去。泡麵還有六包。

第二天有人按了電鈴。

我在打字。電鈴響的時候我的手停了，跟門外有腳步聲那次一樣，停在半空中。

響了兩次。間隔大概五秒。

然後是敲門。三下。不重。

我坐著沒有動。

過了一會，門縫底下塞進來一張紙。我聽到紙在磁磚上滑的聲音，很輕，然後是腳步聲往樓梯的方向走。

我等了大概兩分鐘才起來。

紙是一張水電維修的傳單。彩色的，A5，上面印了電話號碼和一隻卡通水管工。整棟樓每一戶大概都塞了一張。

我把它撿起來。看了正面和背面。背面是空白的。

我把它放在鞋櫃上面。沒有丟。

回書房的路上我發現一件事：從電鈴響到我起身，中間隔了兩分鐘，而那兩分鐘裡我一直在想的是「等他走了再出去」。

不是「誰在門外」。是「等他走了」。

我坐回椅子上，把手放回鍵盤。

繼續。

《白露》的字數——四千八百。我昨晚寫到凌晨兩點。今天從下午六點開始。繼續。

※

我打字的速度變快了。

不是因為靈感。靈感是一個我不太相信的詞。我相信的是慣性——打了三天字，手指的肌肉記住了鍵盤的間距，落指的遲疑變少了。也許這就是所謂的靈感。肌肉的靈感。

但快的原因不只是慣性。是腦子裡的聲音。

雨聲裡面有別的。不是什麼超自然的東西——是記憶。記憶有時候會伏在日常的聲音底下，像水底的石頭，你以為是平的河面，腳踩下去才知道下面有東西。

「再五分鐘就好。」

我自己的聲音。三年前的。隔著一扇門說的。門的那一邊有人在等。門的這一邊我在寫。我說了那句話。然後我繼續寫。

我不確定今晚是真的聽到了還是記憶在播放。大概是記憶。但記憶播放的品質太好了——音量、音色、那句話末尾的氣息聲，都跟三年前一樣。

那句話的末尾我說得比較輕。「就好」兩個字幾乎沒有出聲，只是嘴唇動了。我知道這件事，是因為我現在聽得到。

差別不重要。重要的是：打字的時候如果不夠快，那個聲音就會蓋過我正在寫的句子。

所以我打得快一點。

打到某個速度以上，會有一件事發生：我不再是在選字，字自己來。這個狀態每個寫的人都知道，也都知道它不可靠——它出來的東西有一半要刪。但在這三天裡我不在乎它可不可靠。我在乎的是這個狀態裡沒有空隙。沒有空隙那句話就進不來。

右手中指也出現了墨漬。比食指的淡一點，大概是淺灰而不是黑。兩根手指並在一起看，像抓了什麼黑色的東西。我沒有去洗。洗了也洗不掉。第一天我還試過。第二天不試了。

中指那塊的形狀跟食指不一樣。食指的是一塊，邊緣有分岔。中指的是一條，沿著指節的橫紋走，像是紋路本身變黑了。

天花板角落有一小塊水漬。灰白色的。形狀不規則。不是新的——公寓老了，防水做得不好，三樓尤其。但我以前沒注意到。今天注意到了。大概是因為我打字的時候偶爾會抬頭，看天花板。以前我抬頭看的是窗外。現在窗外只有雨，什麼都看不見，所以我看天花板。

※

> 他坐在桌前。

> 筆在手上。紙在桌上。雨在窗外。她在門外。他全部知道。他知道她在哭。不是嚎的那種。是聲音壓在喉嚨裡，偶爾漏出來一點的那種——像水從閥門沒關緊的水管裡滲出來，一滴一滴的，控制不住但也不會氾濫。

> 他知道她需要他。

> 這件事沒有任何模糊的空間。他不是那種聽不懂訊號的人。他能從一個人放下杯子的力道判斷那天過得怎麼樣，能從呼吸的長短聽出來對方要不要說話。這些年他把這種能力用來寫小說。他在紙上寫過三十幾個人物，每一個的情緒他都拿捏得剛好。

> 他的手在紙上。筆在手上。筆尖壓著紙面，墨水在筆尖和紙之間形成一個小小的液面，張力撐著，只要他一動，就會落下，變成字。

> 他說：「我先把這段寫完。」

> 他相信他說的。他真的以為只要寫完這一段——三百字，也許四百字——他就會放下筆，站起來，走到門口。他甚至在腦子裡預演了整個路徑：椅子往後推，站起來，三步到門口，右手伸出去，握住門把，金屬是涼的，轉，門開了，走廊的光進來，她的輪廓在逆光裡，看不清臉，但他知道是她，他走過去——

> 預演到這裡就斷了。走過去之後要做什麼，他沒有預演。這是後來他想很久才發現的：他把開門那一段想得非常仔細，仔細到能感覺到門把的溫度，但門開之後的部分是空白的。他不知道要說什麼。他從來沒有為那句話準備過。

> 也許就是因為那裡是空白的，所以他沒有站起來。人不會走進一個空白的房間，即使房間裡有人在等。

> 他能感覺到門把的觸感。涼的。能聽到門軸轉動的聲音。能聞到走廊裡的雨水味。每一個細節都那麼清楚。

> 但他沒有站起來。

> 他在紙上寫了第一行。然後第二行。第二行比第一行順。第三行比第二行快。到第四行的時候他的手在動，但他的注意力已經不在門外了。不是忘了。是它被推到了後面。像一個最小化的視窗，圖示在螢幕角落，他知道它在，但他正在處理前景的東西。

> 這是他這一生最擅長的事。不是寫作——是把一件事推到後面。他從十幾歲就會了。考試前一天把家裡的爭吵推到後面，喪禮結束後把眼淚推到後面，愛人生病的那半年把恐慌推到後面。推到後面的東西不會消失，但會安靜，而安靜就夠了，安靜就可以繼續做手上的事。

> 他一直以為這是一種紀律。

> 他在寫的那一段，是兩個人在車上。

> 車停在一條路的邊上，引擎沒熄，雨刷在動。開車的那個人要說一件事，說了會改變後面所有的事，不說就可以繼續開回去，把今天過完。副駕駛座的人不知道有事情要說，正在看窗外，數對面過來的車。

> 他卡在這一段十一天。問題不在情節——他知道那個人最後會不會說，他從一開始就知道。問題在於怎麼把「還沒說出口」這件事寫出來，寫得讓讀者感覺到重量，而不是感覺到作者在拖延。

> 那天晚上他想到了一個辦法：讓開車的人先伸手去關雨刷。雨刷關了，視線就模糊了，模糊之後兩個人都不會轉頭看對方，話就比較容易說出來。這是一個好辦法。他寫下這一句的時候手很順。

> 他寫了三百字。他預估的是三百字，實際上是四百二十字，因為關掉雨刷之後他發現還要處理雨聲——雨刷停了，雨打在擋風玻璃上的聲音就變成連續的，那個聲音需要寫進去。

> 寫完他讀了一遍。改了兩個字。又讀了一遍。

> 這一段是他那半年寫得最好的東西。他自己知道。有些段落寫完的時候你會知道它站得住，不需要別人告訴你。

> 他放下筆。

> 抬頭的時候他發現雨小了。窗外的田在暗處，看不清楚，但聲音變了——從悶悶的密集變成一顆一顆分得開的。

> 他把那四百二十字讀了一遍。

> 讀到關掉雨刷那一句的時候他停了。這一句是整段的樞紐，他很滿意。他甚至在心裡把它記下來，準備之後跟人提起——那種寫的人才知道的小勝利，不能拿出來說，但可以自己收著。

> 他讀完，把筆蓋蓋上。

> 他打算站起來。這一次是真的打算——手已經撐在桌沿上了，重心往前移了一點。

> 然後他想到一件事：這一段既然通了，下一段大概也會通。趁著手還熱，再寫一段，寫完一起出去。

> 他把筆蓋打開。

> 門外沒有聲音。

> 他以為只要寫完這一段。

> 他沒有站起來。

我停了一下。喝了一口涼掉的水。繼續。

※

>> 門的另一邊。

>> 走廊。牆面是米白色的。靠天花板的位置有一條水漬，暗的，延伸了大半面牆，像一條乾掉的河床被釘在牆上。雨從窗框的角落滲進來——窗框跟牆之間的矽利康老化了，裂了，水從縫隙裡擠出來，沿著牆面往下流。到了踢腳板的位置匯成一條細線，在磁磚的接縫裡流。

>> 她站在門口。

>> 沒有動。她的重量平均分佈在兩隻腳上。鞋子——室內拖鞋，灰色的布面——濕了。不是她從外面進來的時候濕的。是走廊地板上的水浸上來的。拖鞋的布面在吸水。

>> 她的手放在門板上。左手。五根手指。指腹壓著木頭的表面。壓得不重。她能感覺到門板的紋路——直的，偶爾有一個小結，手指滑過去的時候有一個微小的凸起。

>> 她聽到了裡面的聲音。鍵盤。噠噠噠。節奏不均勻。有時候快——連續的噠噠噠噠像一陣短雨。有時候停——三秒，五秒，七秒。然後又開始。

>> 她數了。每一次停頓她都在等。等他站起來。椅子在地板上磨一聲。腳步聲走到門口。門把轉。門開。

>> 一百次呼吸。她等了一百次呼吸。沒有椅子聲。

>> 一百次的時候她想的是：他在忙。這是一個好想法，是一個成年人會有的想法。她自己也有過忙到聽不見門鈴的時候。忙不是罪。她把重量從左腳換到右腳。

>> 兩百次。沒有腳步。

>> 兩百次的時候那個好想法變薄了。不是壞掉，是變薄——像一張被反覆折的紙，還在，但折線的地方已經快要斷了。她開始想第二個問題：如果我現在敲門，他會不會覺得我在逼他。

>> 這個問題她想了大概四十次呼吸。答案她其實知道。她知道他不會生氣，他從來不生氣，他會停下來，開門，用一種溫和的、正在忍耐的語氣問她怎麼了。而那個語氣會讓她更說不出話。

>> 所以不敲比較好。她這樣決定的時候，身體往門板靠了一點。

>> 三百次。

>> 三百次以後她不再數了。不是放棄，是數字失去了功能。數到三百的時候她發現自己數的不是時間，是次數——她一直在數的是「他還沒有出來」這件事發生了幾次。三百次同樣的事。數字只是把同一件事重複了三百遍。

>> 她把手從門板上拿下來。手掌上有木頭的紋路壓出來的痕。淺的。紅的。她攤開手看了一眼。手指的關節有一點僵——壓得太久了。

>> 她蹲下來。慢慢地。膝蓋先碰到地板。磁磚是冷的。冷從膝蓋骨往上走，走到大腿，走到腰。她把另一隻膝蓋也放下來。跪著。然後雙手撐在地板上。然後把額頭靠在門板上。

>> 這個姿勢不舒服。她維持著。不舒服在這個時候是有用的——它把注意力從胸口移到膝蓋，膝蓋的痛是具體的，具體的東西比較好處理。

>> 門板的木頭比她的額頭涼。她能感覺到兩者之間的溫差。她的熱在往門板裡走。門板在吸她的溫度。

>> 她閉上眼。

>> 鍵盤聲沒有停。

>> 她想起一件事。很多年前他們剛認識，她問他寫作是什麼感覺。他想了一下說，像潛水，下去以後外面的聲音都變成一種悶悶的低頻，你知道有人在岸上，但那個知道跟不知道差不多。

>> 當時她覺得這個回答很好。她甚至記了下來。

>> 她記在一本小本子上，後來那本子不見了。她只記得自己記過，不記得記在哪裡，也不記得當時為什麼覺得這句話值得記。

>> 現在她蹲在門外，額頭貼著木頭，聽著那個「悶悶的低頻」的另外一邊。

>> 岸上的人也有一件事要做：等。等的人不會潛水。等的人只能站在岸上，看水面，判斷底下的人還要多久。

>> 判斷的方法是看氣泡。氣泡還在冒，就表示人還在。

>> 鍵盤聲就是氣泡。

>> 她把耳朵貼上去——這是她今天第一次改變姿勢的目的不是為了舒服。木頭很硬，耳廓被壓扁了，聲音變得更清楚也更遠，像從一個管子裡傳過來。

>> 噠噠。停。噠。停。噠噠噠噠。

>> 還在冒。

>> 她把耳朵移開，換另一邊。同樣的聲音。

>> 她想過一件她從來沒對任何人說過的事：如果有一天氣泡停了，她要怎麼辦。是要下水，還是要繼續在岸上等。

>> 她一直以為這個問題會在很久以後才需要回答。

>> 她等了五分鐘。門沒有開。

我打完這一段。呼吸淺了。我意識到自己在打字的時候整個人前傾了，胸口壓在桌沿上。我坐直了一點。深吸一口氣。吸到一半——停了。胸口有東西。不是疼。是壓。像一塊什麼在胸骨後面。

我用手掌壓了一下胸口。硬的。壓不進去。

繼續。

※

>>> 更深處。

>>> 她的額頭在門板上。門板的木紋在她的額頭上壓出了痕。她看不到那個痕。她也不需要看。她知道它在。

>>> 雨聲。門另一邊的鍵盤聲。她自己的呼吸。三種聲音疊在一起。但在這一層裡，三種聲音已經分不開了。雨聲的間隙裡有鍵盤的節奏。鍵盤的停頓裡有她的呼吸。呼吸的尾端有雨的回聲。

>>> 所有聲音都是同一種聲音。所有等待都是同一種等待。

>>> 這一層沒有走廊。有門，但門的兩邊都是門。她往後退，背碰到的是門。她伸手，摸到的是門。門把在她左邊也在她右邊，兩個門把的高度一樣，涼度一樣，轉起來的阻力也一樣。她轉了其中一個。開了。門後面是一條走廊，走廊盡頭是一扇門，門是關的，門板底部有一塊漆剝了。

>>> 她走過去。七步。她走過幾千次的那條走廊，長度沒有變。

>>> 她把手放在門板上。

>>> 這一次她敲了。

>>> 三下。指節碰木頭的聲音，在這一層裡聽起來不對——太乾，太短，像敲在一塊比木頭更硬的東西上。她等。

>>> 裡面的鍵盤聲停了。

>>> 停了大概兩秒。然後又開始。

>>> 她再敲。五下。裡面的鍵盤聲沒有停。

>>> 她敲第三次的時候手已經不是在敲了，是在拍，整個手掌，聲音變悶，門板在她的手下面微微震。裡面的鍵盤聲蓋過來，噠噠噠噠噠，沒有停頓，快得不正常，快到不可能是有人在打字，那是別的東西在模仿打字。

>>> 她停手。手掌貼在門上。

>>> 門變薄了。她能感覺到。三公分變成兩公分，兩公分變成一公分，最後薄到她能透過木頭感覺到另一邊的溫度——另一邊是溫的，有人在，體溫的溫度。

>>> 她把手往前推。門沒有開，但她的手陷進去了一點，像推進一層很稠的東西。她把整條手臂推進去。她的手在門的裡面。她能碰到——

>>> 門。

>>> 門——

>>> 他——她——

>>> 五分——

>>> 寫完——

>>> 再五——

>>> 門——

>>> 文字碎了。主詞不見了。動詞在重複。不是因為寫的人忘了怎麼寫。是因為語言到了某個深度就不再是完整的了。像水壓把容器壓扁了。句子被壓成詞。詞被壓成字。字被壓成筆畫。筆畫被壓成墨。

>>> 「再五分鐘。」

>>> 五分鐘是多久。三百秒。一千八百個心跳。一生裡的一萬分之一。

>>> 不夠用的。

>>> 永遠不夠用。

>>> 手還在門裡面。抽不出來。也沒有更進去。就停在那裡，一半在外面一半在裡面，像一根插進水面的筷子，從上面看是折斷的。

>>> 門在吸。慢的。一公分一公分。手腕進去了。前臂進去了。門板的位置沒有變，變的是她——她在被收進去，像水被紙吸走，沒有聲音，也沒有抵抗的地方可以抵抗。

>>> 她想這樣也好。裡面有他。裡面是溫的。

>>> 進去了才發現裡面不是房間。裡面是門的裡面。木頭的裡面。年輪、纖維、三十年前那棵樹站著的地方、鋸子切下去的那一秒。她在這些東西中間，跟它們一樣是門的一部分。

>>> 從門的裡面聽，兩邊的聲音一樣大。鍵盤在左邊。雨在右邊。哪一邊是他哪一邊是她，分不出來，因為門的裡面沒有邊。

>>> 她敲。從裡面敲。

>>> 兩邊都聽得到。兩邊都沒有人開。

>>> 她——

>>> 門——

>>> 敲——

>>> 誰在敲。

>>> 沒有人在敲。門在響。門自己在響。三十年前那棵樹在響。

>>> 五分鐘。三百秒。一千八百個心跳——她的還是他的，這一層裡分不出來，兩個心跳疊在一起變成一個，比較快的那個蓋過比較慢的那個，最後只剩一個節奏，而那個節奏是鍵盤。

>>> 噠。

>>> 噠。

>>> 噠噠。

※

我打到第三層的時候，感覺到什麼東西落在我的右手上。

停下來。看。

右手食指的指節上。一滴。黑色的。液體。

我把手舉起來，讓指節在螢幕光下面看清楚。那一滴大概一粒米大。黑的。比水稠一點。表面有一點反光。

我抬頭看天花板。

天花板角落那塊水漬——灰白色的。乾的。跟白天看到的一樣。天花板其他地方也是乾的。沒有滴水的源頭。沒有裂縫。沒有任何可能漏的地方。

我站起來，把椅子往後推，站到桌上——不，我沒有。我想了一下要不要站上去看，然後沒有。桌子承不承得住是一個問題，但不是主要的問題。主要的問題是我知道上去也不會看到什麼。

我低頭再看手指。那一滴還在。它沒有流動——停在指節的曲面上，張力撐住了，像一顆非常小的半球。

我用左手食指碰了一下。指腹沾了一點。黑的。我搓了搓。質感——不像水。比水稠。比油清。沒有味道。我湊近聞了一下。什麼都沒有。

我把兩根手指分開。中間拉出一條很細的絲，大概一公分，然後斷了。斷的兩端各自縮回指腹上。

我在褲子上擦了一下。牛仔褲的布面上多了一個小黑點。大概直徑三毫米。

我看了天花板最後一眼。

乾的。

我把手放回鍵盤。繼續寫。手指落在鍵帽上的時候，食指那塊墨漬碰到了 F 鍵的表面。我看了一眼。鍵帽上沒有留痕。墨在皮膚裡，不在表面。

※

> 他以為只差五分鐘。他關上了門。

這是我今晚寫的最後一行。

不是計畫好的。不是大綱上安排在這裡的句子。是我的手指自己打出來的。打完之後我看著螢幕上那十四個字，覺得它們佔了太大的空間。好像整個螢幕只剩下這一行。其他的字都退到背景去了。

他以為只差五分鐘。他關上了門。

我在《白露》裡寫了這句話。同一句話，三個不同的版本，散落在三層裡：

第一層寫的是：「他以為只要寫完這一段。他沒有站起來。」

第二層寫的是：「她等了五分鐘。門沒有開。」

第三層寫的是碎片。五分。門。關。

三種說法。一件事。

我把這三行並在一起看了一會。它們的長度不一樣，語氣不一樣，主詞不一樣——第一層的主詞是他，第二層是她，第三層沒有主詞。但它們是同一句話。從三個角度拍同一個東西，拍出來的照片不一樣，東西沒有變。

我存了檔。看了字數。七千八百。今晚寫了三千。三天加起來《白露》有七千八百字了。

我沒有回頭讀。我怕讀了會停。不是怕寫得不好。是怕它太對了。怕我打開第一層的第一段，看到那個「他」坐在桌前的樣子，會看到自己。我不想看到自己。我想看到一個虛構的角色。我想要他跟我不一樣——他的桌子比我大，他的窗外有田，他用紙和筆。他跟我不一樣。

但他關了門。跟我一樣。

※

我站起來。

走到窗邊。窗玻璃上全是水。外面的巷子看不清楚了。路燈的光被雨水散射成一團橘色的暈，像一個失焦的太陽沉在一米以外的地方。

我把額頭靠在窗玻璃上。玻璃是涼的。不像門板那種木頭的涼。是更硬的涼。更沒有溫度的涼。

額頭貼上去的地方起了霧。我移開，霧的形狀留在玻璃上，一塊模糊的橢圓，中間比較濃。它縮小，邊緣先不見，然後中間，大概十五秒就沒有了。

我又靠了一次。這次是為了看那塊霧。它出現，然後消失，跟剛才一樣的速度。

我在窗玻璃上站了多久——不知道。大概一分鐘。大概三分鐘。

然後我回到桌前。

螢幕亮著。游標在最後一個句號後面閃。

桌面上，泡麵碗旁邊。黃色的油漬從碗邊延伸到桌面。乾了。調味包只撕了一半，另一半還連在包裝上，油從撕口處沿著塑膠往外流了一小段就凝固了。

油漬。黃的。和手指上的墨漬。黑的。在桌面上隔了大約十五公分。兩種東西。兩種顏色。桌面是淺木色的。黃和黑都很明顯。

我用袖子擦了油漬。

擦不掉。乾掉的油要用濕的東西。我去廚房拿了抹布，回來擦，擦掉了大部分，桌面留下一圈比周圍亮一點的地方——擦過的地方比沒擦過的乾淨，所以反而更明顯。

我把抹布拿去洗。回來的時候又看了一眼那一圈。

墨漬沒擦。

※

胸口還是緊的。

不是心臟的位置。更中間。更深。不在肋骨能碰到的地方。像有什麼東西卡在胸骨後面——不是固體，不是液體，是一種壓力。從裡面往外推，但推不出來。

我用手掌壓了一下胸骨。硬的。壓不進去。

深呼吸。吸到一半——胸口的壓頂住了。吸不滿。我呼出來。慢的。嘴唇微張。氣流從齒縫出去的時候有一點嘶聲。

我試了第二次。這次我先把氣全部吐乾淨，吐到肺裡沒有東西，然後再吸。吸進去的量比剛才多，但還是在同一個地方停住。那個地方很固定。每一次都是同一個深度。

我站著。雙手垂在身側。左手乾淨的。右手兩根手指是黑的。

窗外的雨沒有要停的意思。

我回到桌前。沒有關筆電。螢幕的光照在我臉上。桌面上那些字——七千八百個字——在螢幕的白色背景上排列著，黑的，小的，像一群不會動的蟲。

游標閃了。

閃了。

我看了一下時間。凌晨一點五十三分。

明天繼續。或者今天。凌晨一點五十三分算今天。

我沒有關螢幕。我離開書房的時候把門關上了。門鎖扣。咔。

走廊是暗的。

第三步，地板響了。第八步，沒響。連下三天雨，木頭吸飽了水，脹起來就不響了。

廚房。水龍頭。滴。四秒。滴。

我站了一會。

冰箱上那隻塑膠鴨子的磁鐵掉了一半，菜單的一角垂下來。我把它壓回去。磁力不夠，它又垂下來。我沒有再壓。

然後走回書房。門外。

站在門外。

手沒有碰門把。

大概站了十秒。

然後推開門。進去。坐下。

螢幕還亮著。
