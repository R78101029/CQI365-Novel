# 情感殘影追蹤表 (Emotional Residue Tracker)

> Agent 撰寫「滲漏場景」時必須查閱此表。每一組殘影標記放置章節和完成狀態。

## 撰寫原則

1. 感知到的是**情緒**，不是訊息
2. 角色**永遠不知道**那個情緒來自哪裡
3. **不要解釋**——讓讀者自己感覺到
4. 兩個對應的場景盡量在**同一章節或相鄰章節**呈現（並排，無解釋）

## 雙向配對說明

殘影 #1 和 #7 是**雙向的**：
- 衛央刻座標時感到「被碰了一下」(#1) ← 來自縫工辨認星圖時的感動
- 縫工辨認星圖時「想哭」(#7) ← 來自衛央刻座標時的感受
- 建議放在同一章（Ch 17）的 A段和 D段

殘影 #3 和 #5 是**雙向的**：
- 陳明哲藏筆記時「手心發熱」(#3) ← 來自許若昕讀到筆記時的感動
- 許若昕讀筆記時「雙手極熱」(#5) ← 來自陳明哲藏筆記時的感受
- **建議 #3 和 #5 都放在 Ch 13（交接章）的 B段和 C段**——在同一章的雙線並行中交替呈現。讀者會在同一個閱讀時段內同時感受到兩端的溫度。這是全書最動人的殘影設計，必須在空間上貼近。

## 感知方向圖（Zone 2 不對稱感知）

```
A（衛央）─── 感知 ──→ D（縫工）
     ↑                      │
     │                      │
     │                      ↓
C（許若昕）←── 感知 ── B（陳明哲）
```

注意：Zone 2 的「感知方向」和「情感殘影方向」不完全相同。
- Zone 2 感知 = 哪條插入線出現在哪個主線章節
- 情感殘影 = 跨時間的情緒滲漏（可在任何 Zone 出現）
