# 今世三個女孩 & 配角（草案 v0.1）

> **鐵律**：三個女孩每一個都是完整的人。她們有自己的人生、自己的理由、自己離開或被離開的方式。她們不是「讓男主發現自己還愛前妻」的工具。
> 每一個女孩都要讓他看見一件「前世他在以寧身上沒看見、或理所當然接受」的事。

---

## 女孩一｜林采萱（暫名）·學姊（Ch 4）

| 項目 | 內容 |
|---|---|
| 時間 | 2000-2001 |
| 身分 | 資工系大三學姊，系學會。爽朗、計畫很多 |
| 她的路 | 她要去美國讀研究所，很早就決定了，不會為任何人改 |
| 怎麼結束 | 她出國。很平和。她說：「你好像早就知道會這樣。」 |
| 讓他看見的 | 一個女人不為任何人留下，是可以的。他第一次想：以寧呢？ |

---

## 女孩二｜陳佳穎（暫名）·外系同學（Ch 6）

| 項目 | 內容 |
|---|---|
| 時間 | 2002 |
| 身分 | 外文系。在 BBS 認識。敏感、會觀察人 |
| 她的路 | 她想當翻譯，家裡要她考公職 |
| 怎麼結束 | 她提分手。她說：「你心裡有一個人。」他沒辦法解釋那是誰 |
| 讓他看見的 | 他談戀愛的方式像一個 45 歲的丈夫：周到、準時、可靠——但不在場 |

> 本章是全書最痛的對話之一。她說對了，而他無法回答，因為那個人這一世不認識他。

## 女孩三｜許雅婷（暫名）·同事（Ch 9）

| 項目 | 內容 |
|---|---|
| 時間 | 2004 |
| 身分 | 同公司的 QA 工程師。比他大兩歲，單親家庭長大 |
| 她的路 | 她想穩定、想結婚。她是三個女孩裡最可能「成」的 |
| 怎麼結束 | 他差一點求婚。在戒指櫃前他說不出口。是他提分手 |
| 讓他看見的 | 她說「我可以辭職顧家」的時候，語氣和前世的以寧一模一樣。他第一次聽懂那句話的重量 |
