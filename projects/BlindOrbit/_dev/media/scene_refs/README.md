### 風格一致性備註

- 所有場景使用**冷色調為主**的調色盤（藍灰、軍綠、混凝土灰），僅在火焰和爆炸時使用暖色
- 人物表現強調**疲憊、壓力、孤立感**——沒有英雄式的光環或姿態
- 光線偏好：自然光（黃金時刻、陰天、黎明）或功能性人工照明（螢光燈、螢幕光）
- 避免過度風格化——目標是**戰地攝影 / 紀錄片**的真實感
- 每個場景都應傳達小說的核心主題：**科技失靈後，人類如何在黑暗中找到方向**
