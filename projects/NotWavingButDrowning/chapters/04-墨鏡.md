# 墨鏡

我去浴室洗臉。

水龍頭轉到冷水那邊。水出來的時候我的手縮了一下——比預期的冷。基隆的水管埋在牆裡面，靠外牆那一側，溫度跟室外差不多。四月的凌晨大概十五度。水是十五度的。

我捧了水潑在臉上。一次。兩次。第三次的時候鼻子嗆了一下——吸到水了。我閉著眼睛摸到毛巾架。毛巾是乾的。我擦了臉。

抬頭看鏡子。

臉沒什麼不對。是我的臉。兩頰瘦了一點——最近吃泡麵比較多，鹽分高但熱量不夠。眼下有青色。不是眼圈——是血管透出來的顏色，皮膚薄了就會看到。嘴唇偏乾。三十五歲。看起來像四十。我已經習慣了。

但我盯著看了五秒。

鏡子裡的我——那個表情。不是我以為的表情。我以為我在看鏡子的時候臉上是專注的——就像工作的時候重讀自己的段落，皺眉，分析。但鏡子裡的那個人不是在專注。那個表情——嘴角是平的，眉頭沒有皺，但眼睛周圍的肌肉有一種繃。不是緊張的繃。是忍的繃。忍什麼我不知道。

我抬手摸了一下右臉頰。

鏡子裡的我——慢了。

我的手已經碰到臉了。指尖壓在顴骨上。我能感覺到自己的皮膚。

但鏡子裡——手還在半空中。還沒碰到臉。手指伸著。離臉大概五公分。

我停住了。盯著鏡子。

鏡子裡的手——慢慢靠近。碰到了臉。跟我的手同步了。

大概差了一秒。也許兩秒。也許不到一秒。我不確定。

我動了一下右手的食指。鏡子裡的也動了。同步。我眨了一下眼。鏡子裡的也眨了。同步。我轉頭看右邊。鏡子裡的也轉。同步。

我做了一個測試。我把右手舉到胸口，然後很快放下。快到我自己都看不清中間的過程。鏡子裡的手也一樣快。看不出差別。

慢的是慢動作。快的沒有問題。這件事我沒有繼續想下去。

也許是我太累了。連續四天睡不到四小時。凌晨的光線不好。浴室的燈泡是白光的，功率不高，照在磁磚上反射回來的光不均勻，有些角度會有延遲感——不是真的延遲，是視覺的錯覺。

大概是這樣。

我看了一下自己的手。右手。食指和中指的墨漬。昨天是兩根手指。今天——無名指也有了。三根。墨的顏色從食指到無名指遞減——食指最深，黑色；中指灰黑；無名指淺灰，像鉛筆末擦過的。

三根手指並排的時候看得出一個方向。從食指往小指的方向，顏色在退。像是有什麼東西從食指開始，正在往外走。

走出浴室之前我做了一件事。

我把浴室的燈關掉，站在暗裡。

窗戶有一點光——不是月光，基隆看不到月亮，是對面公寓的樓梯間燈。那點光從氣窗進來，落在鏡子上，鏡面反射出一個很淡的方形。

我在暗裡看鏡子。看得到輪廓。一個人形，肩膀的線，頭的形狀。

我抬手。

輪廓的手抬起來。

我看不出快慢。暗的時候看不出延遲，因為看不清楚細節，只看得到大的動作，而大的動作沒有時差。

我在暗裡站了大概三十秒。

然後把燈打開。

鏡子裡的我在燈亮的那一瞬間就在那裡了。沒有慢半拍出現。

我轉身離開了浴室。沒有再回頭看鏡子。

浴室的肥皂。我剛才洗手的時候它裂了。用太久了，中間塌了一道溝，水沿著溝流的時候把兩邊泡軟了，拿起來一壓就碎成兩半。大的那半我放回皂盒。小的那半放在皂盒邊緣。它在那裡待著。大概會一直待著。

肥皂是她買的。一次買六塊，同一個牌子，白色的，沒有味道。她說有味道的肥皂洗完手，手上就會有那個味道，而她不喜歡自己身上出現不是自己選的東西。

六塊我用了三年。這是第五塊。第六塊還在洗手台下面的櫃子裡，沒有拆。

用完之後要買什麼牌子，這件事我沒有想過。

※

回到書房。

坐下。打開筆電。《白露》的檔案。七千八百字。游標在最後一行後面。

我從最後一行往上看了三行。然後把游標移到新的一行。開始打。

打了兩段。關於《白露》裡那個男人的房間——他的書桌上有什麼，他的窗外有什麼，他的日常是什麼。我在幫他建立世界。一個作家幫虛構角色建立世界的方式跟上帝不一樣——上帝是從無到有，作家是從自己到有。我把自己的桌子搬過去，改了尺寸。把自己的窗戶搬過去，換了景色。把自己的門搬過去——

門。

我在小說裡寫了：「桌上有一封信。」

寫完這行字我停了。

低頭看自己的桌面。

信在那裡。

夾鏈袋裡的信。透明的夾鏈袋。裡面那張皺巴巴的 A4 紙。

它在桌面上。在泡麵碗旁邊。在筆電的左邊。

我記得放回抽屜了。前天。我記得用兩隻手扶正那個歪掉的抽屜，推到底。我記得滑軌的澀。

但它在桌上。

我看了它大概十秒。

我拉開抽屜看。抽屜裡有迴紋針、不會出水的原子筆、健保卡的紙套、那顆四孔的鈕扣。沒有夾鏈袋。

也許是我昨天半夜又拿出來了——睡前。在沙發上。也許我不記得。也許我夢遊了。我沒有夢遊的紀錄，但一個人不會知道自己夢遊，除非有人告訴他。三年來沒有人可以告訴我任何事。

也許——不重要。它在那裡。

我把夾鏈袋拿起來。

※

拉開拉鏈。慢的。拉鏈的兩排齒一顆一顆地分開。聲音在安靜的書房裡很清楚。

我把紙抽出來。兩根手指夾著紙的邊緣——手指的墨漬壓在紙的白色邊框上，留了一小塊灰印。

我把它放在桌面上，用手掌很輕地壓平。紙不會平了。被水泡過再乾的紙有自己的形狀，你壓下去它會跟著，手一放又回來。摸起來像很薄的樹皮。

紙面在螢幕光下面。歪了頭看——能看到字跡的凹痕。她用筆壓得很深。藍色墨水。原子筆。她寫字的力道一直很重，寫完一面紙翻過來，背面都能摸到字的痕跡。

我用手指從左到右摸過去。指腹碰到那些凹痕，一道一道的，像盲人在讀。但我讀不出來。凹痕告訴我這裡有字，不告訴我是什麼字。

我試過拍照放大。第一年試的。手機貼上去，開閃光，開手電筒，從側面打光讓凹痕的影子跑出來。放大之後藍色的暈變成一片一片的顆粒，凹痕變成明暗的線條。我盯著那些線條看，看到我能從裡面讀出任何我想讀的東西——那是最糟的部分。第三個晚上我讀出了一整句話，一句我知道她不會寫的話。我把照片刪了。

之後我沒有再試過任何技術性的辦法。

第一行。「如果你讀到這封信的時候」——讀過了。清楚的。她大概在室內寫了開頭，然後出門，或者站在門口的雨棚下，或者就是淋著雨。上面的部分淋到的少，下面的多。

第二行。開頭：「我等了」。後面的字被水溶掉了。藍色的墨暈開，像一朵扁平的花在紙上綻放然後枯萎。「我等了」——什麼？等了多久？等了他開門？等了他回頭？等了他說一句不是「再五分鐘」的話？

「我等了」後面那個字的第一筆還在。一個短的橫。橫的右端往下勾了一點。可能是「很」的第一筆，可能是「三」，可能是「五」。三年來我把所有可能的字在腦子裡試過。每一個都通。這就是問題——每一個都通的時候，等於沒有一個通。

第三行。完全不能讀。只有淡藍色的痕。

第四行。

這一行比其他行都清楚。字跡很深。她寫得很用力——原子筆幾乎要把紙面劃破。墨水比其他行濃。也許是因為她在這一行停了很久，筆尖在紙上壓了很長時間，墨水滲透了纖維。即使被雨水泡過，這一行的字還是能辨認。

「不是你的錯」

四個字。

我讀了。讀了第二遍。嘴唇沒有動。眼睛在四個字上面移動。不是你的錯。

不是我的錯。

我不知道她寫這句話的時候是什麼意思。是真的覺得不是我的錯？還是在安慰我？還是在先把這個問題處理掉，這樣她才能說她接下來要說的話？不是你的錯——然後呢？

還有第四種可能。這一種我很少讓自己想到：她寫得那麼用力，是因為她自己也不完全相信。用力可以是強調，也可以是壓住。

四個字裡「錯」字最深，紙背幾乎凸起來。我用指腹從背面摸過那個字。凸的。摸得到最後一捺。

再往下。第五行和第六行中間——有兩個字比較清楚：「請不要」。後面看不清。請不要什麼？不要追？不要等？不要怪自己？不要忘記？不要去找她？不要打她的電話？不要——什麼？

「請」這個字她用了敬語。我們之間沒有人用敬語。七年裡她沒有對我說過一次「請」。這一個字比整封信的其他部分都遠。

最後幾行。完全不能讀。藍色的墨變成一片。像水彩。像有人把一杯水倒在一幅還沒乾的畫上。紙的右下角破了一小塊——三角形的缺口。大概是那天夜裡我從門口撿起來的時候，濕紙黏在磁磚上，我拉的時候扯破了。

那一塊我沒有找到。我當時應該低頭找的。我沒有。我拿著信站在門口，站了不知道多久，然後我進屋，把信放在桌上，然後我做了一件事——我打開筆電，看了一眼《白露》以外的那個檔案，那個我卡了十一天的短篇。我把它關掉了。

那是我三年來最後一次打開自己的檔案，直到這個星期。

我把紙翻過來看背面。

背面沒有字。但有痕——她壓得太重，所有的筆畫都在背面凸出來，反的。整張紙的背面是一片凸起的地形。

我以前試過從背面讀。反的字，只要拿到鏡子前面就會變成正的。我試過。鏡子裡看到的是一片模糊的凸起，因為凸起沒有顏色，只有高低，而高低在鏡子裡不會變成字。

那個晚上我在浴室站了很久，舉著那張紙。鏡子裡是一個男人舉著一張紙。

我把紙放回夾鏈袋。拉鏈。密封。

放在桌上。這次沒有放回抽屜。

我的手在抖。不是冷——書房的溫度沒變。不是餓——我兩小時前吃了泡麵。手背上有一根青筋在跳。我能看到它在皮膚下面動。一下一下的。跟心跳同步。

我把手放在桌面上。十根手指攤開。壓住。桌面的木頭是實的。冷的——不是浴室的那種冷，是書桌的冷，淺一些。

等了十幾秒。

不抖了。

信裡寫著什麼。他沒有讀完。

※

>> 他在桌上找到了一封信。

>> 不是意外找到的。信一直在那裡。在桌面的左邊，壓在一本翻開的書下面。書是她的——法文的，他看不懂。封面是白色的，書名是細的黑字。他把書移開。信在下面。

>> 信封。白色的。沒有地址。沒有收件人。只有一個字：他的名字。她的字跡。

>> 他把信封翻過來。封口沒有封。他把信紙抽出來。

>> 展開。

>> 信是完整的。沒有水漬。字跡清楚。每一行都能讀。藍色的墨水。整齊的。她的字不大，行距很均勻，像是在有橫線的紙上寫的，但這張紙是空白的。她自己控制的間距。

>> 三頁。他數了。三張紙，正反面都寫了，所以是六面。

>> 他把三頁攤在桌上，並排。燈光從左邊來，紙的右邊有一點陰影。他看著這六面字，想的是：這麼多。她寫了這麼多。

>> 一個決定要走的人不會寫這麼多。寫三頁的人是還在說話的人。三頁是一個還想被回答的長度。

>> 他坐下來。把第一頁拿起來。

>> 他開始讀。

>> 「親愛的——」

>>> 信的內容變成了另一個故事的開頭。

>>> 「親愛的，」信裡寫。「你讀到這封信的時候，我大概已經不在了。不是死了。是不在你的世界裡了。這兩件事不一樣。死是被帶走。不在是自己走的。」

>>> 「我想從一件小事開始說。你記不記得——」

>>> 信裡的文字繼續。但不是普通的信了。信裡出現了一張桌子。桌上有紙。有筆。有一杯冷掉的咖啡。有一盞檯燈。有一個人坐在桌前——

>>> 信裡面有一個人在寫信。

>>> 那個人寫的信裡，第一句也是「親愛的」。第二句也是「你讀到這封信的時候」。第三句開始說一件小事，說到「你記不記得」就停了，因為那張紙上出現了一張桌子，桌上有紙，有筆，有一杯冷掉的咖啡。

>>> 信裡面的信裡面也有一個人在寫信。

>>> 他往下讀。第一頁的背面，第二頁的正面。每一面都是同一封信的開頭。每一面都在「你記不記得」那裡轉向，轉進下一張桌子。

>>> 六面。他讀完六面，讀到的是六個開頭。

>>> 那件小事他一次都沒有讀到。

>>> 他把六面重新排了一次。他想，也許順序錯了。也許正確的順序裡，第二頁會接著第一頁說下去，「你記不記得」後面會有東西。

>>> 他試了六種排法。每一種的第一面都是開頭，每一種的最後一面也是開頭。順序不影響結果，因為六個開頭無論怎麼排都是六個開頭。

>>> 他把紙翻過來看背面的透光。三頁的紙質一樣，厚度一樣，同一疊裡撕下來的。她坐下來的時候是打算寫完的。

>>> 他做了最後一件事。他從第一頁的第一行開始，用手指壓著，一個字一個字往下讀，讀得比剛才慢十倍，慢到每一個字都是單獨的。他想抓住那個轉折的位置——那個從「她在說話」變成「一張桌子出現」的接縫。

>>> 接縫不在字上。他讀到「你記不記得」的「得」字，下一個字就已經在另一邊了。中間沒有過渡。像走在平地上，一腳踩下去發現地面在另一個高度。

>>> 他把六面收攏，疊好，放回信封。信封口沒有封，他也沒有封。

>>> 他把信封放在桌子的左上角。那是他放已經處理完的東西的位置。

>>> 然後他坐在那裡，兩隻手放在桌面上，什麼都沒有做。他不能說信是假的——那是她的字。他不能說信沒有內容——六面都是字。他只是拿到了一封他讀不完的信，而讀不完的原因不是水，不是時間，不是任何可以怪罪的東西。

>>> 他抬頭看門。門是關著的。

>>> 這一次他站起來了。他走到門口，三步，右手伸出去，握住門把。金屬是涼的。

>>> 他轉了。

>>> 門開了。門外是走廊。走廊盡頭是客廳。客廳的窗簾沒拉。

>>> 什麼都沒有。

>>> 他站在門框裡，一隻手還在門把上。他等了大概十秒，等一個他自己也說不清楚的東西。然後他把門帶上，回到桌前，坐下。

>>> 他以為只差五分鐘。他關上了門。

>>> 寫的人停下來。手指離開鍵盤。

我感覺到一陣暈眩。不是生理的——我不頭暈，不噁心，血壓大概正常。是結構上的暈眩。像站在兩面平行鏡子之間，看到自己的影像無限重複，越來越小，越來越遠，但每一個都是自己。

我在寫一個角色。那個角色找到了一封信。信裡有一個人在寫信。信裡的信裡有一個人在寫信。信裡的信裡的信裡——

我在寫一個寫信的人，他寫的信裡有一個讀信的人，讀到的信裡有一個寫信的人，寫的是同一封信。

我本來要給他一封完整的信。那是我坐下來要做的事——我要讓小說裡的那個男人拿到我沒有拿到的東西。字跡清楚。每一行都能讀。他可以讀完，可以知道她要說什麼，可以在讀完之後做點什麼，或者不做，但至少他知道。

我寫到第三頁的時候，那封信自己開始複製。

不是我決定的。我打的時候手是順的，順到我沒有注意到自己在寫什麼，等我停下來看螢幕，那六面已經是六個開頭了。

我搓了一下臉。手掌壓了一下眼睛。看到黑暗裡有一些光斑。

繼續寫。

>>>

>>>> 門後面有影子。

>>>> 影子不動。影子的形狀——是一個人。站著的。兩隻手垂在身側。頭微微低了。

>>>> 信。門。雨。五分鐘。

>>>> 這些詞不再是句子的一部分了。它們是獨立的。漂浮在頁面上。像是被水泡過的紙上殘留的字。每一個詞都離得開開的。中間是空白。空白的面積比字的面積大。

>>>> 影子沒有臉。影子沒有聲音。影子只是在門後面站著。門是木頭的。門上有一塊漆剝了。離地九十公分。

>>>> 影子的手——如果影子有手的話——大概碰過那個位置。

>>>> 光從哪裡來。這一層沒有燈。沒有窗。但影子要成立就要有光，所以有光，來源不重要。也許影子自己在發光，只是發的是暗。

>>>> 影子往前一步。門沒有擋住它。它從門裡面穿過來，形狀沒有變。

>>>> 現在影子在門的這一邊。跟他同一邊。

>>>> 他沒有回頭。他知道它在他背後大概兩公尺的地方。他知道它不會再往前。它站了三年了，它已經學會站著。

>>>> 影子在他背後，所以他的影子在他前面。桌面上有一個他的影子，趴著的，跟著他的手動。兩個影子，一個站的一個趴的，中間隔著一個人。

>>>> 他寫字。桌上的影子跟著寫。

>>>> 背後的影子沒有動。

>>>> 過了一段時間——這一層沒有時鐘，也沒有窗，所以時間只能用寫了多少字來算——他發現桌上的影子寫的東西跟他不一樣。他的筆停了，影子的筆還在動。他看著那個影子繼續寫了三行，然後才停下來，跟他一樣停在句號後面。

>>>> 他看不到影子寫的是什麼。影子寫的字沒有形狀，只有動作。

>>>> 他想回頭。這個念頭出現了，很具體，脖子的肌肉甚至已經準備了。

>>>> 他沒有回頭。

>>>> 不是因為害怕。是因為回頭要花時間，而他還有一段沒寫完。

>>>> 影子在他背後待了很久。這一層沒有時間，所以「很久」的意思是：久到他不再把注意力分給它。

>>>> 後來影子動了。

>>>> 它繞過他，走到桌子的另一邊，在他對面停下。那張椅子在那裡——他搬進來就一直空著的那張，椅面上有一層薄灰。

>>>> 影子沒有坐下。它站在椅子後面，兩隻手搭在椅背上。

>>>> 他抬頭了。這一次他抬頭了，因為影子在他的視線範圍裡，不需要回頭。

>>>> 影子沒有臉。但它有一個朝向——它朝著他。

>>>> 他等了。他不知道要等什麼。他把筆放下，兩隻手放在桌面上，攤開，掌心朝上——這是一個他從來沒有做過的動作，他不知道自己為什麼要做。

>>>> 影子沒有動。

>>>> 過了一段時間，他把手收回來，拿起筆。

>>>> 影子還站在那裡。

>>>> 他繼續寫。寫的時候他能感覺到對面有東西朝著他。這件事沒有讓他寫不下去。他寫得很順。

>>>> 這是最壞的部分：影子來了，站在他對面，而他還是寫得很順。

※

我寫到這裡的時候去了一趟浴室。洗臉。

水龍頭。冷水。捧水潑臉。一次。毛巾。擦。

抬頭。

鏡子。

鏡子裡的我。毛巾在手裡。手垂在身側。

我已經放下毛巾了。我確定。我的手在身側。毛巾掛回架上了。

但鏡子裡——

毛巾還舉著。手還在臉旁邊。還在擦。

我盯著。

鏡子裡的我——慢慢地把毛巾放下。掛回架上。手垂到身側。

同步了。

這次差了大概兩秒。上次——兩個小時前，同一面鏡子——是一秒。也許不到一秒。這次是兩秒。我數了。數得很清楚。一。二。同步。

我動了一下右手。鏡子裡的跟著動。同步。

我又試了一次那個快動作。手舉到胸口，很快放下。鏡子裡的手也很快。沒有延遲。

只有慢的東西會慢。只有我不趕時間的時候，它才落後。

我轉身。走出浴室。

沒有回頭看。

走廊。書房的門。我看了一眼。

門是開的。

我記得關了。進浴室之前。我走出書房的時候把門關上了。咔。鎖扣的聲音我記得。

門開著。角度大概四十五度。書房裡的燈照到走廊的地板上——一道梯形的光。螢幕的光在更裡面，偏藍的。

我站在門口。看著裡面。書桌。椅子。螢幕。咖啡杯。泡麵碗。信。

信還在桌上。夾鏈袋。透明的。裡面的紙折了兩折。

我沒有馬上進去。我站在門框外面，看著那道梯形的光落在走廊地板上的邊界。光的邊緣不是直的，因為門板不是完全平的。

三年來我每天關這扇門。三年，一天至少四次，大概是四千多次。四千多次同一個動作，手的高度、施力、放開的時機，全部一樣。這種事情不會出錯。

門開著。

我走進去。

把門關上。

咔。

坐下來。

螢幕上的字。游標在閃。

我看了一下字數。一萬零兩百。今晚寫了兩千四百。

信裡寫著什麼。他沒有讀完。我也沒有。

不是因為讀不到。是因為讀到的那些已經夠了。「不是你的錯」。四個字。足夠讓我坐在這裡一整夜想它是什麼意思。

夠了。

我存了檔。
