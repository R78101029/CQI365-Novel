# 林若筠

角色設定的正本在 [`_dev/characters/protagonist.md`](../../characters/protagonist.md)。
這一份只處理**視覺**：她在畫面上長什麼樣、穿什麼、不能出現什麼。
心理、動機、撰寫紀律不重複寫在這裡，改了那邊不必改這邊。

## 為什麼 `forbid.performance` 這麼嚴

角色設定明訂「內心獨白極少」「身體是唯一的情緒出口，但她不解讀自己的身體」，
而且「**絕不**讓她想通什麼」。影片模型的預設行為是加戲——流淚、嘴唇顫抖、
搖頭、深呼吸——那會把她改寫成另一個人。

她的變化是幾毫米的事，不是反應。

## 參考圖的優先順序

**手部參考圖優先於臉。** EP01 十三鏡裡她的手入鏡三次（疊圖、按防水膠、翻帳本），
正面臉零次——s02 逆光、s04 剪影、s11 四分之三側且中性。

這本書的鏡頭語言本來就是「身體代言情緒」，手比臉重要。

## 美學參考

不寫演員名。用光質與質地描述：

- 自然光為主，不打美光。窗光、簷下的反射光、單顆燈泡
- 皮膚有毛孔與細紋，不修
- 對比不拉高，陰影不壓死
- 參考的是紀實攝影的克制，不是人像攝影的討好
