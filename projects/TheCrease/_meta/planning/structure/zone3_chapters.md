# Zone 3 章節規劃 — 紙上的方程式（Ch 11-17）

> **Zone 3 規則**：章內雙線平行。6000-8000 字。兩條時間線在章節內交替呈現。核心事件：蘇顯宗將1947年筆記本帶給許若昕。目標：讀者確認這些是同一個數學物件。

| 項目 | 內容 |

| **時代** | AD 168 / 2055 |
| **排序** | 11 |
| **字數目標** | 7000字 |

### 線A（衛央）場景

- 衛央完成了所有236次閃光的觀測記錄。她在最後一次記錄中發現：這些閃光的位置，在平面星圖上無法閉合，但如果將平面「摺疊」，它們構成一個完美的幾何結構。
- 她不知道「摺疊」意味著什麼，但她知道這些數據是真的。

### 線C（許若昕）場景

- 許若昕完成褶式方程的完整推導。模型預測了兩種資訊洩漏：數學的和情感的。
- 她在推導的最後一步遇到困難——一個「直覺跳躍」，她無法完整解釋為什麼自己知道那個步驟是對的。

### 平行主題

兩個女性在不同時代，完成了同一件事的不同面向——記錄真相。

### 情感殘影

本章可放置許若昕的「鑿刻聲」（來自衛央，見 emotional_residue_tracker）。

## Ch 13 — 交接 **（核心章節）**

| 項目 | 內容 |
|------|------|
| **線** | B + C（蘇顯宗 / 許若昕） |
| **時代** | 1947 → 2055 |
| **排序** | 13 |
| **字數目標** | 7500字 |

### B線（1947年——陳明哲藏筆記的最後時刻）

> **注意**：蘇顯宗與陳明哲沒有任何直接關係。陳明哲將東西藏進龍山寺牆壁，108年後蘇顯宗在修復工程中偶然發現。這個「偶然」是褶式方程的運作方式。

- 陳明哲在龍山寺將最後一塊磚放回牆壁的場景。林秀英在旁邊幫他遞石灰。
- 他的手觸碰牆壁的最後一刻——**情感殘影 #3：手心發熱，被握住，像有人在另一端等著**。他不知道那是什麼，以為是石灰的溫度。
- 他在心中默念：「總會有人找到。」
- 他轉頭看林秀英。她的表情是平靜的——那種不問但全都知道的平靜。

### C線（2055年——蘇顯宗帶回筆記）

- 蘇顯宗帶著渾天儀殘件和筆記本回到CERN。他提到：「我阿嬤說她小時候就住在龍山寺隔壁。」許若昕沒有在意這句話。但讀者如果記得 Ch 10 裡林秀英就住在龍山寺旁邊，會自己把線索拼起來。（**血脈暗示，不明說**）
- 許若昕注意到他的表情不太一樣——像弟弟以前考試考得很好但不敢炫耀時的那種表情。她搖了一下頭，把這個念頭趕走。
- 許若昕打開筆記本。1947年的手寫方程式——和她2055年的褶式方程模型幾乎完全相同。
- **情感殘影 #5：她的反應——雙手極熱，感動得哭。** 她不知道這股熱是從哪裡來的。（來自陳明哲108年前藏筆記時的「被接住」感。）
- 她讀到陳明哲的信。「如果你正在讀這封信，代表我的數學是對的。也代表你即將犯一個無法挽回的錯誤。」
- 她的回應（帶黑色幽默）：「他說得對。但我還是會做。」
- 這不再是理論。摺痕是真的。時間確實是摺疊的。

### 情感殘影（本章最關鍵）

**殘影 #3 和 #5 必須在本章的 B段和 C段交替呈現**——讀者在同一個閱讀時段內，同時感受到陳明哲藏筆記時手心的熱，和許若昕讀筆記時雙手的熱。兩端的溫度在一章之內互相呼應。這是全書最動人的殘影設計。

> 撰寫要求：B段寫到「手心發熱」時，不要解釋。C段寫到「雙手極熱」時，也不要解釋。讓讀者自己把兩個溫度連起來。

### 線A（衛央）場景

- 衛央在某次夜間觀測中看到最強烈的天裂——閃光中她看見了什麼。不是清楚的影像，更像是一個形狀、一種存在感。一個正在注視她的人。
- 她不知道那是誰。但她感到：不孤單。

### 線D（縫工）場景

- 縫工在處理那個無法修補的褶痕時，監測設備記錄到古漢語的聲波頻率——不可能出現在2301年的聲波。
- 她不認識那個語言。但她聽了很久。
- 她在日誌裡沒有記錄這件事。這是她第一次在日誌裡省略了什麼。

### 平行主題

「同一高維結構的投影」首次被讀者感知——兩個分隔2135年的人在同一刻感知到彼此。

## Ch 15 — 實驗

| 項目 | 內容 |
|------|------|
| **線** | C + D（許若昕 / 縫工） |
| **時代** | 2055-09 / 2301 |
| **排序** | 15 |
| **字數目標** | 7000字 |

### 線C（許若昕）場景

- 許若昕準備並執行「開摺實驗」。
- 實驗前72小時：偵測器記錄到鑿刻聲頻率。（**情感殘影：來自衛央1800年前刻座標的震動**）
- 實驗執行：LHC加速，褶痕被人工放大。
- 結果：因果混沌泡誕生。直徑數公尺。緩慢擴張。無法消失。潘朵拉的盒子被打開了。

### 線D（縫工）場景

- 縫工在修復局的歷史數據中，目睹「開摺實驗」的原始記錄——泡誕生的瞬間。
- 她看到的是結果——246年後，那個「直徑數公尺」的泡已經覆蓋了地球30%。
- 她想：這就是起點。

### 平行主題

因與果同時呈現。許若昕創造了泡，縫工生活在泡的後果中。

### 線B

### 線C

許若昕在因果混沌泡邊緣，第一次「看見」了什麼——泡內的非線性光中，有兩個影子。一個在刻東西，一個在寫東西。她不知道她看見了衛央和陳明哲。

### 線D

縫工在修復局的監測系統上，辨認出一組古老的座標排列——和衛央1800年前刻的星圖完全吻合。她感動得想哭。不知道為什麼。（**情感殘影**）

Zone 3 的高潮。讀者此刻應該完全確認：四條線是同一個數學物件的四個面向。
