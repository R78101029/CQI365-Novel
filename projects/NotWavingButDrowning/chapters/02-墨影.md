# 墨影

白天出了一趟門。

巷口的便利商店。從公寓門口走過去大概三分鐘。雨小了但沒停，像有人把水龍頭轉到最小還是關不完。我穿了拖鞋，那雙灰色的塑膠拖鞋，鞋底磨平了，踩在濕的柏油上幾乎沒有摩擦。

巷子很窄，兩台機車並排就過不去了。牆邊停了七八台，其中一台已經停了兩年，坐墊裂開，海綿露出來被雨泡成深色，輪胎扁的，鍊條上結了一層鏽。它的車牌還在。我每次經過都會看一眼，不是為了確認什麼，只是眼睛會往那邊去。

轉角有一戶人家在門口曬東西。曬不乾的，這種天氣。三件襯衫掛在鐵窗上，滴著水，底下的地面有三攤深色的圓。曬衣服的人不在。

買了兩包泡麵和一罐即溶咖啡。結帳的時候店員問我要不要袋子。我說好。她掃了條碼，看了我一眼。大概是看到我的拖鞋——濕的，鞋底沾了一片黃色的落葉，貼在那裡，我沒注意到。她把東西裝進袋子。我拿了。走了。

門口的自動門開關了兩次才關上，中間卡了一下，感應器可能對到雨。走出去的時候身後傳來那個進門的音樂，短的，四個音。

回到公寓樓梯間的時候我低頭看鞋。落葉還在。我用另一隻腳踩了一下，葉子掉了，留了一個溼的輪廓。

樓梯間沒有燈。白天靠窗戶的光。三樓的窗戶裂了一條，用膠帶貼著，膠帶變黃了。我已經看了三年。

膠帶是管理員貼的。他一年來兩次，收管理費。第二次來的時候我問過那扇窗什麼時候換。他說在排。

信箱在一樓。我沒有開。鑰匙在口袋裡，我摸到了，沒有拿出來。裡面應該有帳單和幾張廣告。這個月開過一次，上個月大概也開過。我不記得。

第一年我每天開。

不是為了帳單。是因為信箱是一個可能會有東西進來的地方，而那一年我需要一個這樣的地方。手機不算——手機我隨時看得到，看得到就不會累積期待。信箱不一樣，信箱一天只能開一次，開之前有一段可以想像的時間。

我開了三百多次。裡面是廣告、帳單、選舉公報、鄰居放錯的掛號通知單。

第二年變成一週兩三次。第三年就是想到才開。

改變不是決定的。是有一天我走過信箱，發現自己沒有伸手。

※

晚上九點。書房。

打開筆電。《白露》的檔案還在。兩千一百字。游標在最後一個句號後面。

我從最後一行看起。「他沒有劃掉這一行。」

我看了那句話。看了大概五秒。然後把游標移到下一行。開始打。

書房的燈還是暖黃的。咖啡杯我洗了——下午的時候洗的，用清水沖了三遍，杯緣的痕淡了但沒有完全消掉。我又泡了一杯。新的即溶咖啡。味道比上一罐淡。

窗外的雨跟昨晚差不多。不大不小。鐵皮屋頂的聲音。我已經聽了三年，不會再注意了——除非它停。它很少停。

我打了兩段。三百字左右。關於《白露》裡那個男人的桌子。他的桌子比我的大。他的房間比我的大。他的窗外不是巷子——是一片田。我給他一片田。雨落在田上的聲音跟落在鐵皮上不一樣。更悶。更遠。

我在給一個虛構的人一個比我好的房間。這件事我意識到了。但沒有改。小說本來就是把自己搬到一個不一樣的房間裡。

寫到第四段的時候我停下來查了一個東西。稻田在冬天要不要放水。我不知道。我在網路上看了三分鐘，看到一個農會的頁面，講到二期稻作收割後的整地。我把那個頁面關掉。我沒有把查到的東西寫進去。

我只是需要知道那片田是對的。給一個不存在的人一片田，田也要是對的。

※

門外有腳步聲。

我停下來。手指離開鍵盤。停在半空中。

公寓老了。木造地板，三十年以上。熱脹冷縮加上基隆的濕氣，地板會自己發出聲音。白天比較少。晚上比較多。溫差的關係，大概。我住了三年，聽過各種聲音——嘎吱、咔、吱，偶爾像有人走過。大部分時候我不會注意。

但這一次不一樣。

腳步聲是有節奏的。左、右、左、右。不快。像是有人在走廊裡走。從客廳那個方向走過來。越來越近。

停了。

就在門外。

我盯著門。門板底部那塊油漆剝落。門跟地板之間有大概一公分的縫隙。我看那個縫隙。沒有光——走廊的燈沒開。沒有影子——如果有人站在門外，腳應該擋住路燈從客廳窗戶透進來的光。但什麼都沒有。

沒有敲門。

我等了。不是刻意等。是動不了。手指在半空中。鍵盤上最後打的那個鍵是空白鍵。螢幕上多了一個空格。

我數了。心裡數的，不出聲。一、二、三⋯⋯

數到十二的時候我發現自己在憋氣。我把氣吐出來，很慢，從嘴角出去，怕聲音。吐完之後吸氣，也慢。這件事佔掉了我大概四個數，所以我不確定我數到的是十六還是十八。

數到二十的時候，我想到一件事：如果我現在站起來走過去把門打開，會發生兩件事的其中一件。門外有人，或者門外沒有人。

我不知道哪一件比較糟。

三年前我知道門外有人。我沒有開。現在我不知道門外有沒有人，我還是沒有開。這兩件事的形狀太像了，像到我坐在椅子上的時候，背後的椅背忽然變得很明確——我能感覺到它壓在我肩胛骨中間的那條線上。

大概到三十的時候，腳步聲又開始了。往走廊那邊。左、右、左、右。越來越遠。越來越輕。然後沒有了。

我把手放回鍵盤。手是冷的。兩隻手都是。我搓了一下。指節的墨漬在兩隻手掌心之間磨了一下。

繼續寫。

※

> 他也聽到了。

> 不是腳步。是別的。比腳步更輕。混在雨聲裡面。如果不注意就會以為是風在門縫裡擠過去的聲音。嘶——嘶——不均勻的。像呼吸。

> 但他知道不是風。風不會那樣呼吸。風不會在呼氣的末端帶一個很小的、碎掉的音——像是想說什麼，但嘴唇沒有張開，聲音就碎在齒縫裡了。

> 他放下筆。

> 看著門。門是木頭的。偏黃的白漆。門板底部有一塊油漆剝了——跟他的門一模一樣。一模一樣的位置。一模一樣的大小。他盯著那塊剝落看了很久。木紋的顏色。淡的。像曬過的骨頭。

> 這扇門他從來沒有仔細看過。門是用來關的，不是用來看的。人一天要經過門幾十次，沒有人會停下來看門。現在他看了，發現門比他以為的複雜——木板不是一整片，是四片拼的，接縫在漆底下微微浮起來；門把的銅色在被手握的那一圈磨掉了，露出底下更黃的金屬；門框跟牆之間有一條矽膠，接近門檻的地方發黑了。

> 一扇門有這麼多東西可以看。這件事讓他有點難受，因為它意味著他在看門，而不是在開門。

> 門底的縫隙裡滲進來一滴水。透明的。沿著磁磚的邊緣往他的方向流。很慢。水的前端弧線在燈光下有一點亮。

> 他看著那滴水。水移動了大概五公分就停了，被磁磚縫裡的什麼擋住。停在那裡以後，它就只是一滴水了——不再有方向，也不再讓人期待它會走到哪裡。

> 他沒有站起來。

> 他看著那滴水流到桌腳旁邊。停了。水面上映了他的檯燈，倒過來的，像一個很小的火焰沉在地板裡。

> 他把筆拿起來，在紙上寫：「門外有人。」

> 寫完他看著這四個字。太少了。門外有人——這句話裡沒有那個人。任何人都可以是門外的那個人。郵差、鄰居、風。他要寫的是她，可是他寫出來的是一個位置。

> 他在下面補了一行：「她在門外。」

> 一個字的差別。這一行有她了，但也只有她——沒有她在做什麼，沒有她多久沒說話，沒有她的手放在哪裡。他知道那些細節在他腦子裡，他甚至能感覺到它們的形狀，像口袋裡有東西但拿不出來。

> 他又寫了一行：「她在門外，她——」

> 停在破折號上。

> 破折號後面應該接一個動詞。他把筆尖懸在那裡，等那個動詞出現。等了很久。筆尖的墨聚成一小點，重量到了，落下去，在紙上暈開一個藍色的圓，把破折號的尾巴吃掉了一半。

> 他沒有換一張紙。他在那個藍點旁邊繼續寫，繞過它，像繞過路上的一個坑。

> 寫出來的是：「她在門外，她沒有敲門。」

> 這是對的。他知道這是對的，因為寫完之後他的手指鬆了，握筆的力道降下來，指節不再發白。真話寫出來的時候身體會知道，比腦子早。

> 他把這一行讀了兩遍。然後在後面加了一個句號，雖然本來就有一個。兩個句號並排。他劃掉多的那個。

> 接下來的一個小時他寫得很慢。

> 慢不是因為卡住。是因為他在寫的東西他不想寫完——寫完之後就要面對下一段，而下一段是她離開門口。他還沒有準備好讓她離開門口。只要她還站在那裡，這篇東西就還有一個沒有發生的可能性。

> 所以他把她留在門外。他寫她的手，寫她的膝蓋，寫走廊牆上那條水漬的形狀，寫磁磚接縫裡的黑。他寫了一千多字，全部都在同一個位置，沒有任何人移動。

> 他知道這樣寫是不對的。一千字裡沒有一個動作往前推，讀起來會像作者在拖。他知道，然後他繼續寫。

> 檯燈的燈泡有一點閃。他抬頭看了一下，燈泡在燈罩裡面，看不到燈絲。閃了兩次就穩了。

> 窗外的雨小了一點。他沒有察覺到這件事，是後來停筆的時候才發現的——雨聲變了，變得可以聽見一顆一顆。

> 他放下筆，看著紙上那一千多字。

> 她還在門外。他把她留在那裡一個小時了。

我打到這裡停了。

把手從鍵盤上拿開。放在膝蓋上。螢幕上的字。「他沒有站起來。」

我看了那句話。看了很久。

這是我寫的。這個「他」是我造出來的角色。他坐在一個虛構的房間裡，聽到門外有人在哭，他沒有站起來。

我也沒有。

我把手放回鍵盤。繼續往下打。

※

>> 門後面的世界。

>> 走廊。牆壁的漆是米白色的，靠天花板的位置有一條水漬延伸了大半面牆。雨從窗框的邊緣滲進來，沿著牆面往下流，在踢腳板的位置匯成一條細線。地板是磁磚，白色的，縫隙發黑了。

>> 這條走廊很短。從客廳到書房門口，七步。她走過幾千次。有時候端著杯子，有時候拿著書，有時候什麼都沒拿，只是從一個房間到另一個房間。走廊是家裡最不被記得的地方，因為沒有人在走廊裡停下來。

>> 今天她停下來了。

>> 她站在那裡。

>> 她沒有傘。雨水從她的頭髮流到肩膀。頭髮是濕的，顏色比平常深，貼在臉頰上。額頭上有幾縷。水珠從髮尾滴下來，落在她的鎖骨上，沿著脖子往下。她穿著那件深藍色的絲巾繞在脖子上——溼了，顏色變成更深的藍，貼著皮膚，她沒有解開。

>> 絲巾的邊緣有一小段脫線。她一直想修，一直沒修。線頭現在垂在濕布料外面，比乾的時候長，因為濕的東西會拉長。

>> 她的手指在門板上。右手。指腹壓著木頭的表面。壓得不重。大概是一個蘋果的重量。她能感覺到門另一邊有人——不是聽到，是感覺到。空氣的振動。或者只是她知道他在。

>> 她想敲。手指彎了。指節收了一半。

>> 沒有敲。

>> 敲門是一件會得到答案的事。答案有兩種，其中一種她今天承受不了。不敲的話，門後面就永遠是那個她需要的版本——他在，他只是沒聽見，他如果聽見了一定會開。

>> 這個想法讓她的手停在半空中，維持了大概三秒。三秒之後她把手放回門板上，掌心整個貼上去。

>> 她站了五分鐘。她數了。每次呼吸數一秒。不是刻意數的——是她的身體在計時。呼吸的節奏。吸、吐、吸、吐。到第一百次的時候她把另一隻手也放在門板上。兩隻手。十根手指。都在門板上。

>> 她聽到了裡面的聲音。鍵盤。噠噠噠噠。速度不快。中間有停頓。停了幾秒。又開始。噠噠噠。

>> 他在打字。

>> 她認得這個節奏。這是他寫得順的時候的節奏——短的爆發，然後停下來看一眼，然後又是短的爆發。他寫不順的時候是另一種，單鍵，慢，中間有很長的空白。

>> 順。他今天寫得順。

>> 她把手從門板上拿下來。手掌上有木頭的紋路壓出的痕。淺的。紅的。她看了一眼。

>> 然後她蹲下來。慢慢地。膝蓋碰到地板。磁磚是冷的。冷從膝蓋骨往上走。她把額頭靠在門板上。

>> 門板的木頭溫度比她的額頭低。她能感覺到溫度的差。大概兩三度。她的體溫在從額頭流進門板。門板在吸收她。

>> 她閉上眼。雨聲。鍵盤聲。她自己的呼吸。跟他在門另一邊聽到的一樣嗎。大概不一樣。他聽到的鍵盤比較大聲。她聽到的雨比較大聲。他們各自聽著自己那一邊的世界。

>> 她的手往下滑，離開門板，停在門板底部——那塊漆剝落的位置。指腹碰到的地方，漆的邊緣是脆的，摸起來有一點刮手。她用指甲很輕地刮了一下。掉了一小片，落在磁磚上，比一顆米還小。

>> 她沒有看那一片漆。她閉著眼睛。

>> 門沒有開。

>> 她站起來的時候扶了一下牆。跪太久，右腿從膝蓋以下是麻的，她把重量放上去，腿沒有接住，她往牆邊倒了半步。牆是涼的。

>> 她等麻退掉。大概四十秒。這四十秒她看著門。

>> 然後她走了。往客廳的方向。七步。走到第四步的時候她停了一下——不是回頭，是停。腳沒有轉，肩膀沒有轉，只是停了。

>> 停了大概兩秒。

>> 繼續走。

>> 客廳的燈沒開。她沒有開。她走到餐桌旁邊，拉開椅子，坐下。

>> 桌上有一疊紙。是他印壞的稿子，單面，背面空白。他習慣把印壞的留下來當草稿紙，一疊放在桌角，用一個馬克杯壓著。

>> 她抽了一張。翻到空白的那一面。

>> 筆在筆筒裡。她拿了最上面那支。藍色的原子筆。

>> 她在紙上寫了第一行。

>> 寫完之後她看了那一行很久，久到筆尖的墨在紙上滲開了一個點。她把筆移開。

>> 她沒有劃掉。她繼續往下寫。

>> 廚房那邊的窗戶沒關緊，雨的聲音從那條縫進來。她寫的時候聽著那個聲音。中間她停過三次，每一次都是把筆放下，兩隻手放在紙的兩邊，然後再拿起來。

>> 寫完她把紙折了兩折。

>> 折的時候她的手很穩。折線壓得很實，用指甲從左到右刮過去一次。

>> 她把馬克杯放回原位。椅子推回桌子底下。

>> 書房的門還是關著。門縫底下有光。

>> 她沒有再走過去。

>> 門沒有開。

我打完第二層的最後一行，手指停在鍵盤上。

Enter。

我沒有按。手指在 Enter 鍵上面。按下去就是新的一行。新的一行意味著故事繼續。她還在門外。他還在門裡面。按了 Enter，她會怎樣？她會站起來嗎？她會走嗎？她會敲門嗎？

我不知道。因為三年前的那個晚上，我沒有打開門去看。

我按了 Enter。然後存了檔。沒有寫下一行。

※

我站起來。去廚房。

煮咖啡。用摩卡壺——她留下的。鋁的。八角形。底座有一點鏽。三年沒有換膠圈，膠圈硬了，蒸氣從邊緣漏。我每次用都漏一點。不影響。咖啡還是會上來。只是比較慢。

水在壺裡加熱。嘶——的聲音。然後咕嚕。咖啡從上壺冒出來。黑的。

我站在流理台前面等。

然後聞到了。

薰衣草。

淡的。但很確定。不是咖啡的味道。不是雨水的味道。不是公寓的黴味。是薰衣草。洗髮精的味道。她用的那種。Yves Rocher。紫色的瓶子。我從大學認識她開始就知道這個味道。

我站在那裡。沒有動。嗅了一下空氣。味道在。確定在。不是想像出來的——想像的味道不會有這種存在感。想像的味道是模糊的。這個是清楚的。有方向。從浴室那邊來的。

我看了浴室方向。浴室的門關著。門底下沒有光。

我走過去。推開門。拉了燈的拉繩。燈亮了。

浴室很小。一個馬桶，一個洗手台，一個淋浴間。洗手台是乾的。蓮蓬頭也是。地板上沒有水漬。鏡子上沒有蒸氣。

沒有人。

我打開淋浴間的門，沒有理由，就是打開了。裡面也是乾的。排水孔的蓋子歪了一點，我用腳把它踩正。角落有一塊肥皂，用剩的，中間塌了一道溝。

洗手台底下的櫃子我沒有開。那裡面有三年前剩下的東西。我知道有什麼——一瓶沒用完的卸妝油、兩個備用的牙刷頭、一包棉花棒。我沒有丟。我也沒有開。

味道——還在嗎。我站在浴室門口聞了一下。淡了。再聞。沒有了。

我關了浴室的燈。走回廚房。咖啡煮好了。壺裡的蒸氣聲停了。

我倒了一杯。黑的。沒加糖。

她也不加糖。這個我記得。她喝咖啡的樣子我也記得。她喝的時候會把杯子舉到嘴唇的高度，但不馬上喝——先聞。聞一下。然後才喝。

我喝了一口。沒有聞。

我試了。第二口之前我把杯子舉到嘴唇的高度停住，鼻子先過去。

聞到的是咖啡。就是咖啡。焦的、酸的、有一點土。即溶的比手沖差，這個我分得出來。

沒有別的。沒有比較好喝。

她說聞的時候咖啡是最好喝的，喝下去以後就只是液體了。我一直以為那是一個講究的人在講究。現在我照著做了一次，發現它不是講究——它是一個關於順序的說法。先聞的人是在延後。她把最好的那一段拉長，因為她知道下一段會比較差。

我喝完了。放下杯子。

杯底碰到流理台的聲音。

※

回到書房。

坐下來之前我看了一眼書桌右邊的抽屜。

手放在抽屜的把手上。金屬的。涼的。

我拉開了。動作很慢。抽屜的滑軌有一點澀，左邊比右邊重，拉的時候歪了一點。我用兩隻手扶正。

裡面。一個夾鏈袋。透明的。

抽屜裡除了夾鏈袋還有幾樣東西。一盒迴紋針，開過的，倒了一半在抽屜底。一支不會出水的原子筆。一張健保卡的紙套。一顆鈕扣，深色的，四孔，不知道從哪件衣服上掉的。這些東西我從來沒有整理過，它們只是被放進來，然後留下來。

袋裡是一張紙。A4。折了兩折。紙已經皺了。不是正常的皺——是被水泡過然後晾乾的那種。紙面凹凸不平，像一片微縮的地形圖。邊緣捲起來，有些地方脆了，碰一下會碎。

我沒有把它拿出來。我隔著袋子看。

字跡。藍色墨水。被水溶成淡藍色的暈。有些地方完全看不到原來寫了什麼——只剩一片顏色，深淺不均，像水彩。有些地方能辨認幾個筆畫：一撇、一橫、半個口字旁。拼不出來。

紙的上半部比下半部清楚。這件事我很久以前就注意到了。她應該是把信放在門口的地上，或者信箱下面的架子上。那天的雨是斜的，從東邊來。信的上緣有東西擋著，可能是門檻，可能是雨遮的邊。所以上面淋得少。

我知道這件事。知道了三年。它沒有讓我讀到更多。

第一行比其他行清楚一點。

「如果你讀到這封信的時候」

我讀了。七個字。後面的被水溶成一片。第二行只能辨認一個「我」和一個看不清的字——也許是「已」，也許是「以」。第三行完全不能讀。

「如果你讀到這封信的時候」——這是一個條件句。條件句的後面應該有結果。結果被水拿走了。

我把夾鏈袋闔上。拉鏈的兩邊對齊。用拇指和食指捏著拉鏈頭，從左往右拉。拉到底。密封的聲音。

放回抽屜。抽屜推回去的時候又歪了。我用兩手扶正。推到底。

門外有人。他沒有開門。

※

我試著把那天晚上按順序排一次。

我從八點開始。八點多我在書房，寫一個短篇的第二稿，卡在中段一個場景——兩個人在車上，其中一個要說一件事，我不知道怎麼讓他說。那個場景我改了十一天。

九點左右她進了一次書房。她說了什麼。我記得她進來，記得門開的角度，記得她站在書桌左邊大概一公尺的地方。她說的話我不記得。

不是模糊。是空的。那個位置什麼都沒有。我可以把整個房間畫出來——桌上有什麼、螢幕開了幾個視窗、我當時打到第幾行——但她說的話沒有。

我記得的是我當時在想什麼。我在想那個車上的場景，如果讓其中一個人先下車，話就不用說了。我一邊聽她講話一邊在想這個。所以那句話進了我的耳朵，但沒有進到別的地方。它經過我，就像廣播經過一個沒有在聽的人。

後來她出去了。門她關的還是我關的，我不確定。

十點多門外有聲音。這個我記得。我記得我沒有停手。

十一點多我說了那句話。「我先把這段寫完，再好好談。」隔著門說的。我記得我說完之後還打了一個字，那個字是「他」。

三年來我一直以為我的問題是那五分鐘。不是。我的問題是九點那一段。她把話說出來了，我在場，我的耳朵是開的——然後那句話就不見了。

我不知道她說了什麼。我永遠不會知道。這件事不是門造成的。門是後來的事。

我把手放在桌面上。木頭的。實的。手心壓住桌面的時候可以感覺到自己的脈搏，在掌根那一塊，一下一下。

※

凌晨一點四十六分。

我寫了兩千七百字。《白露》現在四千八百字了。我沒有回頭讀。我不敢。不是怕寫得不好。是怕讀了之後我會發現我在寫自己，而且寫得太準了。

我關了螢幕。沒關筆電。螢幕暗下去的時候書房變暗了。窗外路燈透進來一點橘色的光。打在天花板上。天花板的角落——那塊水漬。在橘色的光裡看起來比白天大一點。也許是光線的角度。也許是真的大了一點。

我看了一下自己的右手。

食指的墨漬。比昨天深了。昨天的黑裡還有一點灰。今天沒有了。邊界比昨天清楚。像是有人重新描了一遍。

我去浴室。開水龍頭。擠了肥皂。搓了。搓了大概兩分鐘。水從手指上流過。泡沫是白的。但手指上的顏色沒有變。黑色。在水流裡面那塊黑色的東西看起來很安靜。像一塊胎記。像一直都在那裡。

我把手擦乾。毛巾上沒有留下黑色的痕。墨漬在皮膚裡。不在表面。

我回到書房。

沙發。兩人座的。右邊是我的位置。左邊——她以前坐的那邊。坐墊的顏色跟右邊不太一樣了。右邊我每天坐，布面被磨得偏暗。左邊——三年沒人坐——布面比較淺，但有一個很淡的凹痕。大概是她留下的。也許是我的想像。布面凹不凹其實看不太出來。但我每次看都覺得那裡凹了一點。

我躺下來。躺在右邊。

左邊空著。

窗外雨聲。水龍頭的滴聲從廚房傳過來——我忘了關。不，我關了。是墊片的問題。滴。大概四秒。滴。

窗台上有一隻死掉的飛蛾。昨天就在了。翅膀碎了一邊。觸角還完整。細的。彎的。在橘色的路燈光裡看起來像兩條頭髮。

我看了一眼。沒有清掉。

牠是什麼時候進來的我不知道。窗戶三年沒開過——基隆的濕氣進來比空氣多，開窗沒有意義。所以牠不是從窗戶進來的。

大概是從門。某一次我進出的時候跟著飛進來，然後找不到出去的路，繞了幾天，停在窗台上，面對著玻璃。

玻璃外面有光。牠大概一直在往那個方向試。

死在窗台上是合理的位置。牠去了牠能去的最遠的地方。

閉上眼。

門外有人。他沒有開門。

不是小說裡的。

是我。三年前。門外有人。我沒有開門。

我翻了一個身。面朝沙發靠背。靠背的布面有一股灰塵的味道。不是髒。是久了。

睡了。大概。不確定什麼時候。
