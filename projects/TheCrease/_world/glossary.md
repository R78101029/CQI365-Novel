# 術語表 (Glossary)

> 《摺痕》全書專用術語，依類別整理。

---

## 物理概念

- **褶式方程 (The Pleat Equation)** — 自我描述的數學物件，同時描述時間維度如何摺疊，以及它本身就是摺疊洩漏出來的資訊。
- **褶疊結構 (Pleat Geometry)**：時間不是被折一次，而是被褶成多層。四個時間點（AD 166, 1947, 2055, 2301）被堆疊在一起，每對之間都有一條褶痕，但強度不同。共六條褶痕。
- **褶痕洩漏**：褶疊結構中，相鄰層之間的資訊/情感滲漏。統一機制，但因褶痕強度不同而表現各異——從高精度數學滲透（墨痕）到純情感體溫（體溫）。不再區分 Type 1/Type 2，而是視為同一現象的不同頻率。
- **六條褶痕**：①墨痕（1947↔2055，最強，精確符號）②裂口（2055↔2301，被撕開，數據灌注）③水漬（166↔1947，模糊共振）④體溫（166↔2301，最弱/最深，純情感）⑤回聲的回聲（166↔2055，交叉褶，碎片化訊號）⑥餘燼（1947↔2301，交叉褶，情緒殘溫）
- **自指性 (Bootstrap)**：褶式方程的解包含了產生它的條件——衛央的座標是陳明哲方程的前提，陳明哲的答案又回溯影響衛央的座標選擇。因果環，不是悖論。蛇咬住自己的尾巴。
- **因果混沌泡 (Causal Chaos Bubble)**：許若昕在②號褶痕（2055↔2301）上執行開摺實驗後產生的傷口。泡是褶痕被強制展開後暴露的層間空間，時間在其中失去方向。2301年覆蓋地球表面30%。泡保存了開摺實驗的原始數據，包括衛央的渾天儀座標（作為校準參數輸入LHC）。
- **高維投影** — 四位主角是同一高維結構在時間軸上的四個投影（非輪迴、非同一靈魂）。
- **時間摺疊** — 時間維度的自然彎摺，使不同時間點在摺痕處相鄰。
- **開摺 (Unfolding)**：在已存在的褶痕上施力，強行放大褶疊結構的過程。許若昕在②號褶痕（2055↔2301）上執行，導致褶痕被撕開，產生因果混沌泡。
- **摺痕 (Crease)** — 時間摺疊產生的痕跡，資訊洩漏的發生處。
- **穿隧效應（時間版）** — 陳明哲的推導——「穿隧」的不是粒子，而是資訊本身穿越了時間維度。
- **四觀測點理論** — 縫工的理論——需要四個分布在摺痕不同位置的意識，同時做出同一個選擇，才能改變人類意識與時間的關係。

## 歷史術語（Thread A — 東漢）

- **黨錮之禍** — 公元166年，宦官集團將儒家知識份子列為「黨人」，進行禁錮、下獄、處死的政治運動。
- **靈台** — 東漢皇家天文台，位於洛陽，負責天象觀測與記錄。
- **渾天儀（渾儀）** — 青銅天文觀測儀器，衛央將236個座標刻在其底座內壁。
- **太史令** — 掌管天文觀測與歷史記錄的官職。
- **清議** — 東漢士人品評時政的風氣，為黨錮之禍的導火線之一。
- **衛寧**：衛央的姊姊，比衛央大三歲。唯一知道衛央女扮男裝進入靈台的人。Thread A 的「等待者」——衛央被處決後，衛寧只知道妹妹沒有來，再也沒有來。

## 歷史術語（Thread B — 1947年台灣）

- **二二八事件** — 1947年2月28日因查緝私菸引發的台灣全島性民眾抗議與後續軍事鎮壓。
- **清鄉** — 二二八事件後國民政府對全島進行的系統性搜捕、拘禁、處決行動。
- **京都帝國大學** — 日治時期台灣學生赴日求學的頂尖學府，陳明哲的母校。
- **奴化份子** — 國民政府對受日本教育的台灣知識份子的歧視性稱呼。
- **鹿港龍山寺** — 陳明哲藏匿渾儀殘件和研究筆記的地點。
- **皇民化** — 日治時期推動台灣人日本化的政策。

## 技術術語（Thread C — 2055年）

- **CERN** — 歐洲核子研究組織，許若昕的工作場所。
- **LHC (Large Hadron Collider)** — 大型強子對撞機，升級後發現粒子衰變異常。
- **維度拓撲研究組** — 許若昕在CERN領導的研究團隊。
- **東亞科技共同體** — 北京主導的區域科技監管組織，台灣重大科研須向其報備。
- **非接觸戰爭（2041-2047）** — 台灣經歷的戰爭——水下無人機、衛星攻擊、經濟封鎖。
- **第一因守護者 (Guardians of the First Cause)** — 宗教極端組織，認為殺死開摺者可讓時間自我修復。
- **以利亞 (Elijah)**：第一因守護者的炸彈執行者。前物理系學生，真心相信殺死開摺者可以讓時間自我修復。Thread C 的「偶然的破壞者」——和小宦官（Thread A）、外省鄰居（Thread B）形成跨線呼應。

## 未來術語（Thread D — 2301年）

- **褶痕修復局** — 負責監測和修補因果混沌泡的政府機構。
- **恆紀** — 人類退守的軌道城市，第八代居民未曾踏足地面。
- **摺痕焦慮症** — 2301年的精神疾病分類，症狀為使用假設性語句（「如果」）。
- **修補協議** — 褶痕修復局的標準作業程序。
- **因果邊界** — 因果混沌泡與線性時間區域的交界面。
- **Henji-7** — 接替縫工監測工作的AI系統。
- **縫工** — 褶痕修復局最後一位技術員的稱號（非本名）。
- **認知校正（Cognitive Correction）**：對「摺痕焦慮症」患者的強制治療手段。本質是選擇性記憶抹除——保留人格和技能，只刪除「危險」的記憶。校正後的人繼續生活，但不再記得自己曾經知道什麼。2301年壓制異見的核心工具，比殺戮更可怕——因為連殉道都不被允許。
- **七號技師**：褶痕修復局前技術員，因公開質疑2055年官方歷史**並試圖接近因果混沌泡**而被認知校正。她走到泡邊緣200公尺處被攔截系統截停，72小時後被送去認知校正。校正後回到修復局繼續工作，不記得泡是什麼，也不記得自己為什麼站在那裡。每天與縫工擦肩而過。她是縫工沉默的原因，也是全書「暴力進化」主題的具體化身。
- **泡接近攔截協議**：恆紀系統在因果混沌泡邊緣200公尺設置的自動攔截機制。接近泡的行為被分類為「摺痕焦慮症急性發作」。縫工花三個月以「例行維護」為名，將攔截範圍逐步縮小到3公尺——一步可跨過的距離。
