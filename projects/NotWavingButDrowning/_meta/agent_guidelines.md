# 《溺墨》寫作鐵律 (Agent Guidelines) v0.3

> 這是《溺墨》專案的最高執行準則。任何生成的章節必須嚴格遵守排版與滲透規則。

---

## 一、排版規範：俄羅斯娃娃嵌套

本專案使用 Markdown 的 Blockquote 語法來區分現實與虛構層次。

- **第 0 層（現實）**：蘇泛的現實世界與第一人稱獨白。使用正常段落。
- **第 1 層（小說）**：蘇泛正在寫的小說。使用 `> `。
- **第 2 層（小說的小說）**：小說裡的作家正在寫的小說。使用 `>> `。
- **以此類推**：每深入一層增加一個 `>` 符號。

**範例：**
```markdown
現實中的蘇泛在打字。

> 這是小說層的內容，描述雨夜。
> 
>> 這是更深層的內容，角色在回憶。
```

---

## 二、情緒物化與痛感累積

嚴禁使用抽象的情緒詞（如「我很難過」）。所有的痛苦必須透過**蘇泛的身體感知**或**環境異變**來呈現：

1. **呼吸與胸腔**：胸口發緊、像被水灌入氣管、肋骨間的重壓。
2. **手指與觸覺**：指節因打字過度而隱隱作痛、乾掉的墨漬像痂、鍵盤黏膩。
3. **墨水的滲透**：墨漬出現在不該出現的地方（額頭、杯緣）、天花板的滴漏。

---

## 三、重複的主題與變奏

以下三個元素必須在每一層嵌套中以不同的方式出現，且痛感必須隨層級遞增：

1. **「關門」**：物理的關門聲、心理的隔絕感。
2. **「我先把這段寫完」**：作為自欺欺人的藉口。
3. **「五分鐘」**：永遠補不回來的、致命的時間差。

---

## 四、語言質地的轉變

- **外層（現實）**：邏輯清晰、冷靜、帶有自我審視的分析感。
- **中層**：流暢的小說敘事，較多細節描寫。
- **內層**：破碎的句子、重複的疊字、詩意化、主詞模糊。

---

## 五、滲透點清單 (The Seeping List)

每章寫作前，必須選擇至少一個滲透點：
- [ ] **氣味**：小說裡燒焦的味道，現實中也聞到了。
- [ ] **聲音**：小說裡的雨聲，蓋過了現實的雨聲。
- [ ] **文字**：小說裡的句子，自動出現在現實的筆記本上。
- [ ] **影像**：鏡子、螢幕反射的臉孔發生位移。

---

## 六、完稿檢查清單

1. [ ] 是否正確使用了嵌套縮排？
2. [ ] 是否有至少一次現實第一人稱的「侵入」？
3. [ ] 是否避開了抽象情緒形容詞？
4. [ ] 墨水的意象是否隨著進度增加？
5. [ ] 結局是否指向「清醒的虛無」而非瘋狂？
