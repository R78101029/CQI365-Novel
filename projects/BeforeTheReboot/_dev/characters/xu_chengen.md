# 許承恩（男二）

| 項目 | 內容 |
|---|---|
| 年齡 | 32（1993 生） |
| 身分 | 宏昌精密執行副總，二代。海外讀完機械工程回來接班 |
| 性格 | 溫和、坦白、有分寸。會說「這個我不懂，妳教我」。生氣時反而說話更慢 |
| 處境 | 父親中風半退休；叔叔許國棟想奪權；被前一家顧問公司騙過一筆錢，被叔叔拿來說嘴 |
| 重生 | 否 |

## 他在書裡的功能

1. **男二，真正的刺激**：他和知夏是對等的、健康的關係。讀者要真的覺得「選他也很好」
2. **榕川線的主角**：他和叔叔的接班戰，接到鼎星與韓崢
3. **陳默的鏡子**：許承恩一開始就懂得尊重她的專業；陳默要花一整本書才學會

## 感情線節奏

| 章 | 事件 |
|---|---|
| 19–20 | 第一次見面。他被騙過，所以先懷疑她。她三天找出不良率問題，他當面道歉 |
| 23–25 | 開始欣賞她。送她回家時遇到沈家的車 |
| 33–34 | 陳默第一次到榕川，看見兩人並肩 |
| 41–45 | 第 45 章身分公開時，他是唯一一個在她宣布「我是夏至數位的林知夏」後帶頭鼓掌的人 |
| 56–57 | 告白：「我不是要妳現在回答。我只是不想等到哪天妳跟別人站在一起，才後悔沒說。」 |
| 58–60 | 知夏認真考慮。她沒有拒絕，也沒有答應 |
| 76–80 | 招標時他堅持程序公平，哪怕知道陳默是為了她來的。**他不打壓情敵，這是他的格** |
| 94 | 他放手。知夏還沒說，他先說：「妳不用跟我交代。妳選什麼，我都覺得妳選得對。」 |
| 99 | 結局的簽約儀式，他是宏昌方代表，祝福 |

## 他不會做的事

- 不變成反派、不黑化、不設局
- 不當工具人：他有自己的接班戰，那條線他自己贏（第 93 章董事會）
- 不在陳默面前炫耀，也不在知夏面前說陳默壞話
