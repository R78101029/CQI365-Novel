## 核心規則 (World Rules)

**所有寫作必須遵守：**

| 規則 | 說明 |
|------|------|
| **高維投影** | 四位主角是同一高維結構在時間軸上的四個投影——不是輪迴、不是同一靈魂。 |
| **褶痕洩漏** | 跨時間線的唯一連結機制。六條褶痕各有不同強度和感官簽名（墨痕/裂口/水漬/體溫/回聲的回聲/餘燼）。統一機制，不同頻率。 |
| **情感殘影不可解釋** | 角色永遠不知道情感殘影來自哪裡。禁止在敘事中解釋。 |
| **Zone 格式嚴格** | 每個 Zone 有自己的切換頻率、段落長度、標題規則。寫作前必須確認所在 Zone。 |
| **語言質地隔離** | 四條時間線各自的敘事聲音嚴格區分，不可互相污染。 |

## 工作流程

1. **Rule of Three**：寫作前必讀 `_CONTEXT.md`（本文件）、`agent_guidelines.md`、及 `outline.md`。
2. **Zone 確認**：寫任何章節前，確認所在 Zone，遵守該 Zone 的格式規則。
3. **情感優先**：物理概念服務情感，不是相反。方程式是道具，不是目的。
4. **殘影查表**：涉及跨線感知的場景，必須查閱 `emotional_residue_tracker.md`。
5. **Update First**：發現設定衝突時，先更新文檔再寫故事。
6. **228 結構意識**：每個時代的暴力不需要惡意——保持結構性。
