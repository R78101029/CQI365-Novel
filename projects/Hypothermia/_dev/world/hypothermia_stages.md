# 失溫醫學分期 × 章節對應（agent 隱形腳本）

> 這份文件給 agent：知道她現在「失溫到哪一階段」，每章的身體跡象應該寫到什麼程度。
> **讀者不會直接讀到醫學分期**。但這個分期是她身體訊號的物理基準——讓 agent 寫得有依據、不憑感覺。

---

## 失溫醫學分期速查（標準臨床定義）

| 分期 | 體溫 (°C) | 典型臨床表現 |
|---|---|---|
| 正常 | 36.5 - 37.5 | 無異常 |
| 輕度（Mild） | 32 - 35 | 寒顫（shivering）、心搏加快、皮膚蒼白、判斷力下降、笨拙 |
| 中度（Moderate） | 28 - 32 | 寒顫停止、口齒不清、肌肉僵硬、心搏減慢、神志混亂 |
| 重度（Severe） | < 28 | 意識喪失、矛盾性脫衣（paradoxical undressing）、心律不整、最終心臟停止 |

## 章節對應與身體跡象書寫指南

> 每章「她」應該表現出的身體跡象——agent 從這裡選用 1-2 個，**不可全部寫**（會說教）。

### Ch 01｜36.0（剛開始下降）

她**不在現場**。男主只看見她留下的物理跡象：
- 那邊枕頭沒壓痕
- 咖啡杯邊的口紅印
- 便條沒日期

### Ch 02｜35.8（輕度初期）

她**還不在**。男主透過電話接觸：
- 阿莉說「她在睡」——可能是真的（輕度失溫會嗜睡）
- 她沒接訊息

### Ch 03｜35.5（輕度·寒顫期）

她回來。**這是全書第一次「她的身體在男主面前」**：
- 她的**手是冷的**（最直接的徵兆，但男主歸因「天氣冷」）
- 她不脫外套
- 她洗澡 40 分鐘（試圖讓自己暖起來）
- 她只吃半碗河粉（食慾下降）

> **agent 鐵律**：「她的手是冷的」這句必須出現，但男主不可解讀為失溫——他只是握了一下、問「妳冷嗎」，她說「沒事」，他就放下了

### Ch 04｜35.2（輕度·判斷力下降）

她睡 14 小時（嗜睡）。她在沙發那一角速寫——**那是她身體找最暖的位置**（沙發那一角是暖氣口邊，但她不會知道也不會被點明）。

她合上速寫本——這是她**判斷力下降**的徵兆（她原本會把素描本帶回工作室，這次她把它留在客廳）。

### Ch 05｜34.8（輕度晚期·接近中度）

她**不在現場**。男主從她留下的物品推斷：
- 她忘了眼鏡（**判斷力下降**的具體證據）
- 她沒便條（**情緒鈍化**——她不再溝通）

### Ch 06｜34.2（輕度晚期）

她在咖啡店。男主看見：
- 她**瘦了**（針織衫袖口空了）
- 她**沒喝咖啡**（咖啡是冰的——agent 注意：兩人都沒喝，這是雙向的）
- 她重複了同一句「我下週六回去拿東西」——**口齒/思考的迴圈**

### Ch 07｜33.5（中度初期·體溫快速下降）

她回家：
- 她瘦了 **4 公斤**（體重計顯示 49.2）
- 她洗澡只洗 **12 分鐘**（不再試圖暖自己——她放棄了）
- 她不擦頭髮就上床（**判斷力嚴重下降**或**放棄**）
- 她說「謝謝」（一句陌生人的話）

### Ch 08｜32.3（中度·寒顫停止）

這是最重要的一章：**她不爭執了**。

中度失溫的決定性徵兆是「寒顫停止」——身體放棄產熱、進入節能模式。在精神層面對應：她放棄爭執、放棄表達、對所有事說「好」。

- 她對「日式咖哩好嗎」「陽明山好嗎」「妳媽生日去吃飯好嗎」都說「好」
- 她不切她媽的生日蛋糕
- 行李變輕了
- 她沒戴婚戒（agent 提一次、不解釋）

> **agent 鐵律**：本章是全書最殘忍的一章。男主問了三個問題（妳生氣嗎/妳怎麼了/妳開心嗎）——她全部說「沒事/沒有/嗯」。男主**選擇相信**——這是這本書的「他殺了她」的時刻。

### Ch 09｜31.5（中度晚期·神志混亂）

她**不在現場**。
本章寫的是男主的失溫（情緒上的）——前兩次他在第十天等到電話，這次第十一天沒有，然後是 30 天、60 天、90 天。

男主的「在背影裡認錯人」是男主自己進入了**神志混亂的對應**——他開始在路上看見她的幻影。

### Ch 10｜30.2（中度晚期·意識朦朧）

男主整章在做考古。他發現的速寫本是她的**意識證據**——她**確實看見了他**。147 張畫是 147 次「我看見你」。

而她最後一張畫**停在他左手手腕**——她沒畫完。
醫學意義（不可寫進文本）：左手腕是她的速寫起點習慣（從輪廓畫到細節）。停在那裡意味著她**從一開始就放棄了那一張**。

### Ch 11｜29.0（重度初期·心律不整）

煮湯的章節。男主煮了 50 次才煮對——這是他用 1 年 8 個月學會「重複」這件事（她過去七年的每一天做的事）。

她已**不在城市**（南投）。

男主開車去工作室、坐了 1 小時、喝了一口湯。湯倒掉。
他穿外套坐在沙發**她那一角**——他第一次坐在她坐的位置。
他**手是冷的**——他終於體驗到她過去一年的體溫。
他**沒去拿毯子**——他不配。

### Ch 12｜28.0（重度·最後階段·心臟停止）

**「她」已經沒了體溫的可能**——她已不在這個故事的物理現實裡。
男主的「重度失溫」對應到一個悖論：他終於學會了，但失溫的人不是書宜了，是他。

- 喬安**的手是冷的**——男主第一次主動辨認另一個人的失溫
- 高中生店員**手在抖**——他第一次主動回應另一個人的不熟
- 一袋蘿蔔他**沒煮**——他知道煮了沒人會嚐到
- 速寫本上他補的那條線——他補完到手錶扣環就停下來

**末章意義**：他用兩年體驗了她過去七年每天經歷的失溫。他活下來、學會了看人。但**「她」這個熱源已經永遠不會回來**——這就是「重度失溫·最後階段·心臟停止」的真正對應：不是她死了，是他和她之間的那個共同生命死了。

> **agent 鐵律**：末章不可出現「冷」「溫度」「失溫」字眼。意象全部由物理動作承擔。最後一句「他把鉛筆放回抽屜。」——這個動作是停在半途的（鉛筆放回去了，但抽屜是開的還是關的、他下一秒要做什麼、不寫）。

## 全書「冷／溫度／失溫」字眼配額

| 章 | 「冷」 | 「溫度」 | 「失溫」 | 對應使用建議 |
|---|---|---|---|---|
| Ch 03 | 1 次 | 0 | 0 | 「她的手是冷的」 |
| Ch 08 | 0 | 1 次 | 0 | 出現在某個無關上下文（如：「天氣預報說今晚溫度會掉到 14 度」）|
| Ch 11 | 1 次 | 0 | 0 | 「手是冷的」（他自己的） |
| 其他 | 0 | 0 | 0 | — |

**全書共 3 次「冷」、1 次「溫度」、0 次「失溫」**。
**書名是書名，正文不出現書名。**

## 「她在搓手」「她在縮」等慣用動作的配額

agent 寫作時容易過度使用「她搓手」這類失溫動作。配額如下：

| 動作 | 全書配額 |
|---|---|
| 搓手 | 3 次（Ch 03, 07, 08） |
| 把外套拉緊／不脫外套 | 4 次（Ch 03, 04, 05, 07） |
| 坐沙發那一角 | 3 次（Ch 04, 08, 11——最後一次是承彥坐） |
| 抱手臂取暖 | 2 次（Ch 06, 08） |

**超過配額就會變成符號學示範。**

## 寫作備忘

1. 失溫是隱喻不是模型。**Agent 不要寫得太準時太對應**——身體跡象要錯位、要漏、要寫一次「她搓手」（讀者只覺得她冷）、要寫一次「她沒搓手但她該搓」（讀者開始發現）
2. 男主**絕對不會看醫學分期**這份文件對應的東西。他只看見「她瘦了」「她不脫外套」「她說好」這些表面
3. 讀者在讀完整本書時應該慢慢拼出「她在失溫」這個圖——**但讀者不會用醫學詞**。讀者會用「她在死」這種詞
4. 這份文件本身**永遠不會出版**。它是 agent 的腳手架
