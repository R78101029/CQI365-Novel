# 語言質地指南｜四季的文字曲線

> 用文字實現哲學的核心技術。
> 四季的文字質地必須有**可以被統計驗證**的差別。
> SPEC.md 第 7 節展開版·寫每章前查對應季節。

---

## 春（第 1-4 章）

| 維度 | 設定 |
|------|------|
| 句長 | 平均每句 **20-30 字** |
| 形容詞密度 | **高**（不過度·但豐富） |
| 律師腦詞彙 | **大量出現**：應當、責任、風險、違規、糾紛、權益、追究、合理、比例、義務、條款、爭議、處置、查證 |
| 「我」字頻率 | **每千字 8-12 次** |
| 段落長度 | **長**（每段 100-200 字） |

### 春天的氣味
- 主角全力運用律師腦
- 句子有結構感、條理感
- 對話帶有「處理事情」的精準
- 形容詞用在物件與環境（不在情感）
- **書寫態度**：彷彿你還在寫合約·不是在寫小說

---

## 夏（第 5-9 章）

| 維度 | 設定 |
|------|------|
| 句長 | 平均每句 **15-25 字**（縮短） |
| 形容詞密度 | **下降**·不再用為了寫好 |
| 律師腦詞彙 | **逐章降低**·夏末（第 9 章）幾乎消失 |
| 「我」字頻率 | **每千字 6-9 次** |
| 段落長度 | **變多樣**（有些 100+·有些 2-3 行） |
| 物件描寫 | **增加**：冷氣、冰箱、熱水壺、窗戶、落葉 |

### 夏天的氣味
- 開始有實際操作的物理性
- 句子變短·像他變得不再多想
- 律師腦詞彙漸少·**第 6 章只剩零星·第 9 章幾乎沒有**
- 段落長短不一·像呼吸節奏不規則
- **書寫態度**：你正在做事·不是在思考

---

## 秋（第 10-14 章）

| 維度 | 設定 |
|------|------|
| 句長 | 平均每句 **12-20 字**（更短） |
| 形容詞密度 | **進一步降低** |
| 律師腦詞彙 | **完全不再用** |
| 「我」字頻率 | **每千字 4-6 次**（明顯下降） |
| 段落長度 | **多數短** |
| 對白比例 | **增加**（尤其第 12 章剝橘子）|
| 句末留白 | **不補足每一個句子該有的資訊** |

### 秋天的氣味
- 句子帶有節奏的呼吸感
- 對白多但不長·常以單詞回應（「啊」「嗯」「是」）
- 句末留白：刻意不寫完·讓讀者自己補
- **書寫態度**：你在聽·不是在說

### 句末留白範例

| 飽寫（禁） | 留白（要） |
|----------|-----------|
| 他把碗放回水槽·覺得有點累。 | 他把碗放回水槽。 |
| 她笑了一下·眼神有點黯淡。 | 她笑了一下。 |
| 雨開始下了·這樣的天氣總是讓人想起什麼。 | 雨開始下了。 |

---

## 冬（第 15-19 章）

| 維度 | 設定 |
|------|------|
| 句長 | 平均每句 **10-18 字**（最短） |
| 形容詞密度 | **極低** |
| 律師腦詞彙 | **幾乎沒有** |
| 「我」字頻率 | **每千字 2-4 次**（極低） |
| 段落長度 | **短**（許多段落只一兩行） |
| 描寫方式 | **單一物件 + 單一動作**：「他削柚子」「貓在門邊」「海是灰色的」 |
| 最後一章 | 接近**俳句**的節奏 |
| 每章篇幅 | **3,000-8,000 字**（冬季允許短章·第 19 章可短至 2,000-3,000 字） |

### 冬天的氣味
- 短句連發·一句一行·不串
- 形容詞接近消失·動詞主導
- 沒有「我覺得」「我發現」
- **書寫態度**：你存在·但不主張

### 第 19 章的俳句節奏範例

```
新客人來電。

四月。一週兩晚。

他翻訂房本。

字寫得歪。

新客人進門。

「您好。」
```

## 「我」字頻率：人工統計流程

> Agent 無法自動控制這個頻率·**每章寫完必須跑**。

### 步驟

1. 跑全章字數:
   ```bash
   node scripts/chapter-stats.mjs --novel=Kenting --verbose
   ```
2. 開該章 .md 檔·**手動數「我」字次數**（用編輯器搜尋計數）
3. 計算頻率：`(我字次數 / 中文字數) × 1000` = 每千字次數
4. 對照本表:

| 季 | 章 | 目標頻率（每千字） |
|----|----|----|
| 春 | 1-4   | 8-12 |
| 夏 | 5-9   | 6-9 |
| 秋 | 10-14 | 4-6 |
| 冬 | 15-19 | 2-4 |

5. **超出區間 → 回章節刪「我」字**·重新計算

### 為何這個指標重要

- 「我」字密度反映**主角作為敘事中心的重量**
- 第三人稱小說裡·「我」字主要出現在對白與引述思想
- 春到冬下降 → **主角在敘事中漸漸退場**
- 對應金剛經「如夢幻泡影」——「我」這個概念本身在淡化

讀者不會明說察覺·但會**身體感覺到**章節節奏的變化。
