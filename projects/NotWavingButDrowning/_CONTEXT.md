## 核心設定 (Core Premise)

### 主角：蘇泛 (Su Fan)
- 35 歲，職業作家，正處於嚴重的精神官能症與創作瓶頸。
- 居住在大雨連綿的基隆老舊宅邸。
- 他開始寫一部關於「失蹤的戀人」的小說，試圖挖掘自己三年前失去記憶的那一晚。

### 滲透機制 (The Seeping)
隨著寫作進度，小說世界會以以下方式滲透進現實：
1. **感官滲透**：現實中聞到小說描述的氣味（如檀香、腐木味）。
2. **文字侵蝕**：主角發現自己寫出的句子並非出自本意，像是角色在奪取筆尖。
3. **物理瓦解**：小說中下雨時，現實書房的天花板會開始滲出墨水般的黑水。
4. **身份取代**：主角在鏡子中看到的臉，逐漸變成小說中那個「被尋找的人」。

## 寫作鐵律 (Narrative Rules)

| 規則 | 說明 |
|------|------|
| **雙層敘事** | 現實與小說的段落必須在排版上明顯區隔（如小說段落使用 Blockquote）。 |
| **禁止直接對白** | 現實中的蘇泛幾乎不與人說話，所有對話發生在小說草稿中。 |
| **情緒物化** | 所有的痛苦與溺水感必須轉化為物理性的描寫（如喉嚨裡的沙、手指的墨漬）。 |
| **漸進式瘋狂** | 前三章保持冷靜觀察，中段開始虛實重疊，末段徹底迷失。 |

## 工作流程

1. **閱讀順序**：本文件 → `agent_guidelines.md` → `outline.md`。
2. **同步檢查**：每寫完一章小說內容，必須檢查對應的「現實滲透點」是否在下一章現實段落中出現。
3. **墨水計量**：文字中的「黑、墨、水、沈」等意象應隨著篇幅線性增加。
