# 日本意外死亡與不動產繼承——法律實務參考

> 本文件為《半成品》寫作用法律背景資料。
> 情境：台灣籍丈夫（陳維新，37歲，自由攝影師）獨自在瀨戶內海鶴見島意外身亡，妻子（林若筠，35歲，建築師）為唯一繼承人。

---

## 一、獨自在日本意外死亡的處理流程

### 1. 發現與通報

- 發現者（島上居民、旅館人員、路人）→ 撥打 110（警察）或 119（消防/救護）
- 小島上可能沒有警察駐在所，需等本島警察搭渡船過來
- 警察到場 → 搜索身上物品找護照（確認身份與國籍）
- 非自然死亡或死因不明 → 警方進行「死体検案」（由監察醫或警察囑託醫師檢驗），必要時司法解剖
- 遺體暫時安置於醫院太平間或警察指定場所（島上沒有太平間，需運到本島醫院）

### 2. 聯絡家屬

- 日本警方透過護照資料 → 聯絡「台北駐大阪經濟文化辦事處」（瀨戶內海屬大阪辦事處轄區）
- 辦事處透過護照上的緊急聯絡人、戶籍資料 → 聯繫台灣家屬
- 辦事處可提供：當地習俗說明、火化或遺體運送費用概算、推介禮儀公司
- 日本警方也可代為介紹當地殯葬業者
- 駐大阪辦事處緊急電話：(81-6) 6227-8623

### 3. 家屬赴日處理

家屬（若筠）需攜帶：
- 自己的護照
- 與死者的關係證明（戶籍謄本等）

到場後需處理：
1. 向當地市役所/區役所申報死亡 → 取得「死亡屆受理證明」「死亡診斷書（死体検案書）謄本」「火葬許可證」
2. 決定遺體處理方式：
   - **在日本火化** → 帶骨灰回台（較常見，費用較低）
   - **遺體運回台灣** → 需當地禮儀社防腐入殮 + 台灣報關行協助，費用高昂
3. 相關文件須經駐日代表處驗證，帶回台灣辦理死亡登記與除戶

### 4. 時間估計

- 家屬赴日後，至少預估停留 **一週以上**
- 若涉及司法解剖，遺體釋出可能需要更長時間

## 二、在日本的不動產繼承

### 1. 法律適用原則

- 依日本《法の適用に関する通則法》第36條，繼承依「被繼承人本國法」→ 適用 **台灣民法**
- 但不動產的 **登記程序** 仍依日本法辦理
- 台灣民法下：配偶為當然繼承人，與第一順位（直系血親卑親屬）共同繼承
- 若無子女，配偶為 **唯一繼承人**，繼承全部遺產

### 2. 繼承流程與時限

| 期限 | 事項 |
|------|------|
| **3 個月內** | 決定繼承方式（概括繼承 / 限定繼承 / 拋棄繼承） |
| **4 個月內** | 代為申報死者最終所得稅（準確定申告） |
| **10 個月內** | 申報並繳納日本遺產稅（日本稅務機關不會主動寄稅單） |
| **3 年內** | 完成不動產繼承登記（2024年4月起義務化） |

### 3. 繼承方式

- **概括繼承**（単純承認）：接受全部財產與債務（最常見，不需特別手續）
- **限定繼承**（限定承認）：以遺產範圍為限清償債務（需向家庭裁判所申述）
- **拋棄繼承**（相続放棄）：完全放棄（需向家庭裁判所申述，3個月內）

### 4. 所需文件（在台灣準備）

- 戶籍謄本（證明夫妻關係 + 無其他繼承人）
- 印鑑證明
- 以上文件需經「日本台灣交流協會」（台北事務所或高雄事務所）認證
- 文件需翻譯成日文並附翻譯者聲明

### 5. 在日本辦理不動產移轉登記

- 向不動產所在地的 **法務局** 申請「相続登記」（繼承登記）
- 通常需委託日本 **司法書士**（類似台灣的地政士/代書）辦理
- 需提交：死亡證明、戶籍謄本（認證後）、不動產登記事項證明書、遺產分割協議書等
- 法務局在本島，不在小島上 → 需反覆搭渡船

### 6. 遺產稅

- 日本遺產稅基礎控除額 = 3,000萬日圓 + 600萬 × 法定繼承人數
- 一人繼承：3,600萬日圓以下免稅
- 瀨戶內海小島上的老房子 + 土地，很可能低於此門檻
- 即使免稅，仍可能需要申報（視金額而定）

## 三、對小說敘事的影響

### 她為什麼會留在島上

1. **法律時間框架自然留人**：3個月內決定繼承方式、調查遺產（房子的權狀、帳戶、是否有負債）、跑法務局——這些手續本身就需要好幾個月
2. **民宿的現實壓力**：已預約的客人、未清的水電瓦斯費、自治會的會費、鄰居代收的包裹
3. **「處理一下」的藉口**：每次都有一件小事需要再留幾天

### 島上的人比她先知道

- 陳維新在島上生活、整修房子、經營民宿——島上居民都認識他
- 他意外死亡時，最先發現的是島民，最先被警察詢問的也是島民
- 若筠到達時，面對的是一群比她更了解她丈夫日本生活的陌生人
- 這個資訊落差是核心張力之一

### 她能修但沒修

- 繼承登記完成後，她在法律上就是這棟房子的所有人
- 身為建築師，她有能力也有權利翻修
- 但她沒有動手——不是因為手續未完成，是因為她還沒決定要不要留下這個半成品
