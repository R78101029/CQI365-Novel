## 緣起

2026-11-23，作者以新劇本取代《第二志願》（文學中篇，規劃封存於 `_dev/archives/second-choice-v0.4/`）。新劇本為都市職場雙重生言情，目標讀者為中國大陸城市題材的網路小說與微短劇讀者。作者參考同類「功勞被冒領、男主後悔」題材的結構——人物關係複雜、多線交叉——但人物與情節全部原創。

## 與作者討論定案的調整（2026-11-23）

| 原劇本 | 調整 | 理由 |
|---|---|---|
| 地點未定（原示例台南、台中） | 虛構中國城市：雲港（科技城）、榕川（製造業城）、北嶺（投資方所在地） | 作者指定；大陸城市場景讀者較多 |
| 女主出身：父親有傳統工廠 | 加入豪門隱藏身分：母親是南嶺集團董事長之女，私奔後斷絕關係 | 作者同意；鐵律是她不靠身分贏 |
| 反派只有蘇晴 | 三層反派：蘇晴（前台）→ 韓崢（中層）→ 梁啟元（深層） | 讓衝突不在中段用完 |
| 支線各自獨立 | 每條支線至少接到兩條別的線（見 `_CONTEXT.md` 交叉圖） | 複雜但好讀 |
| 「合作夥伴」未定義 | 許承恩為感情線男二；高雅蓉為女主事業合夥人 | 作者要男二製造刺激 |
| 重生者只有男女主 | 規則：死時有極深怨或悔者才重生。全書三人：知夏、陳默、蘇晴 | 作者定規則；蘇晴被韓崢出賣、替所有人扛罪，符合「怨」 |
| 前世男女主感情未定義 | 大學戀愛、共同創業、2023 年結婚；前世到死都是夫妻 | 作者要求更深的感情 |
| 第一階段：離職 | 離職＋協議離婚（30 天冷靜期）；離婚協議最後一條「互不相欠」 | 書名的來源；追妻變成追前妻 |
| 懷孕牽絆 | 方案 A：前世她死時懷孕八週，當天才確認、沒來得及說。全書不說破 | 作者選定；今世時間重來，不影響主線 |
| 前世時間：陳默多活三年 | 壓縮在約兩年內：她死後兩個月內公司被掏空、陳默死 | 作者要求；悔悟來得太晚、公司已來不及救 |
| 車禍：意外 | 蘇晴策劃、韓崢的人執行 | 作者指定；第 68 章揭露 |
| 住院三天丈夫沒來 | 蘇晴收起她的手機、對陳默謊稱她在家睡覺；陳默人在外地救融資 | 作者指出感情好的夫妻不合理，需與蘇晴有關 |
| 沈懷山重生（初版建議） | 不重生，改為默默守護的長輩，戲份增加 | 作者認為不需要；重生者越少越清楚 |
| 父親醫療信託匯款（原劇本） | 保留，但知夏發現後質問，要求依合約匯回她本人帳戶 | 避免「為妳好」變成另一種控制 |
| 用前世證據清算蘇晴（原劇本「前世與今生」） | 只用今世合法取得的證據；前世記憶只指出方向 | 現實向 |
