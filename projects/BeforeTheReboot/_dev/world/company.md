## 2025 年 10 月那一夜（全書起點，必須精準）

- 攻擊：勒索軟體加密部分資料庫，同時有人以客戶資料外洩勒索
- CI／CD 被打掛，知夏只能用共用的 `deploy` 帳號手動部署
- 她做的事：隔離受感染節點、從備份重建、重寫閘道認證與流量控管、把服務遷到新叢集
- 雲廠商要停機，她用自己的信用卡付了八十七萬元（付款紀錄與雲廠商收據：抬頭微光，付款人林知夏）
- **蘇晴怎麼冒領**：commit 作者是 `deploy`；知夏住院三天；蘇晴整理「危機處理報告」上董事會；墊付說成「談到延期」。沒人查信用卡紀錄
- **今世的證據（全部合法取得）**：她自己的信用卡帳單與收據、她筆電上的 shell history、她當晚在工作群的部署訊息、程式碼裡的註解（在公司 git 歷史中）

## 程式碼註解（全書最重要的物件）

那一夜，她在防禦層三個地方留了註解。格式是她的習慣：縮寫、時間、一句話。例如：

```
// lzx 03:47  先擋住，明天再漂亮
// lzx 05:12  撐住。天快亮了
// lzx 06:58  好了。去睡覺
```

- 前世陳默在 2028/01 才讀到
- 今世它們在公司 git 歷史裡，作者欄寫 `deploy`，但時間戳和她工作群的訊息、她的 shell history 完全對得上——這是陳默覺醒後找到的第一個證據（第 28 章）
- 第 100 章番外：前世陳默讀到第三行時，辦公室只剩他一個人

## 知夏撤回的優化模組

- 2025 年夏天起**下班後、用自己的筆電**寫的閘道效能優化，存在她私人的 git repo，從未合併進公司程式碼
- 前世她無償交給公司；今世不給
- **法律界線**：勞動合同的智慧財產條款只涵蓋「職務成果」（工作時間、公司資源、職務範圍）。她有 repo 時間戳、全部下班時間、自己的設備、沒用公司帳號。蘇晴會主張是公司財產（第 6–10 章）
- 第 10 章：公司法務評估後放棄主張

## 技術分紅協議與勞動仲裁

- 2022 年書面協議：核心模組帶來的營收按比例季度分紅
- 今世離職時她依約請求結算加班費、墊付款與分紅 → 公司拖延 → 向勞動仲裁委員會申請仲裁 → 庭前調解 → 調解成立（第 11–13 章）
- CFO 方敏在調解時確認了墊付款的付款紀錄——她是第一個知道蘇晴說謊的人，但她選擇只回答被問到的問題

## 鼎星資訊（雲港）

- 今世 2026 年初蘇晴就開始私下接觸韓崢
- 韓崢的手法：收買內部人、掐住對方的債務、讓別人當替罪羊

## 清算的法律程序

| 對象 | 行為 | 今世可取得的證據 | 罪名／責任 | 章 |
|---|---|---|---|---|
| 蘇晴 | 偽造報銷 | 財務系統報銷單、發票與廠商對帳不符 | 職務侵佔（刑）、返還（民） | 51–66 |
| 蘇晴 | 洩漏商業秘密給鼎星 | 公司信箱與雲端硬碟存取紀錄、外接裝置日誌、程式碼倉庫下載紀錄 | 侵犯商業秘密（刑＋民） | 61–66 |
| 蘇晴 | 冒領 2025 年功勞 | 信用卡與收據、shell history、工作群紀錄、程式碼註解 | 不是犯罪，但足以讓董事會與業界看清 | 52–55 |
| 韓崢 | 收買蘇晴、行賄許國棟、取得商業秘密 | 蘇晴的證詞與轉帳紀錄、許國棟的往來紀錄 | 侵犯商業秘密、對非國家工作人員行賄 | 91–93 |
| 梁啟元 | 暗持競爭對手股份、在董事會利益衝突 | 代持協議（蘇晴前世知道它在哪裡）、董事會紀錄 | 違反董事忠實義務（民）；涉及內幕交易則移送 | 94–95 |

> **流程要有時間感**：報案 → 立案偵查 → 刑事拘留 → 審查起訴 → 起訴 → 審判。一章不能走完。蘇晴第 66 章被拘留，第 75 章才到審查起訴、認罪認罰。
