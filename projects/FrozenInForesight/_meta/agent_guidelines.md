## 一、視角與人稱

### 主視角
- **第一人稱**：「我」即女主角沈宜。**四部皆以她為主幹**。
- 過去式敘述。但回憶段落以「現在式場景」呈現——像她此刻又走了一次——不寫「我想起⋯⋯」「我記得⋯⋯」這類元敘事語。
- 她不自稱全名。「沈宜」二字只出現在他人稱呼或文件上。

### 男主視角段落（有限例外）
- 特定場景允許切換至男主第一人稱（例如 Part I 中他走進空房子的平行敘述、Part IV 中他的感受）。
- 切換規則與原作一致：章節副標題 + ※ 分隔線清楚劃分。兩個「我」不可混淆。

### 她的敘事聲音

**基底**：村上 × 石黑的冷調克制。
**核心層**：費蘭特式的女性內在自觀——冷靜地直視自己最不堪的念頭。

與原作男主的區別：

| | 他（原作） | 她（本書） |
|--|----------|----------|
| 內省 | 幾乎沒有。觀察外物、做動作 | 允許「我想」「我發現」「我知道」——覺察是她的呼吸方式 |
| 感官 | 視覺為主，偶有聽覺 | 五感均勻——她注意質地、溫度、氣味、聲音的邊緣 |
| 動作 | 精確、機械式（修錶師的手） | 帶感覺細節（信封邊角割到手指、水龍頭的冷） |
| 比喻 | 極少 | 偶爾——但只用身體經驗，不用文學典故 |
| 節奏 | 均勻的冷 | 冷底下有暗流。某些段落忽然加速（恐慌），然後硬煞住 |

## 二、情緒克制原則（最高鐵律）

**與原作相同：崩潰不靠嘶吼，靠微小的行為失常。**

但她的失常形態和他不同：

### 他的失常（原作）
- 關了已經關好的瓦斯
- 反覆擦拭同一個杯緣
- 躺在地板上直到天亮

### 她的失常（本書）
- 把已經洗乾淨的碗再洗一次
- 把已經寫好的字再描一遍
- 把已經折好的信紙拆開重折
- 站在窗前不知道自己什麼時候走到窗前的
- 冰箱打開、看著、關上、走開——三次
- 把他的名字寫滿整頁紙
- 穿著睡衣站在三條街外，不記得怎麼出來的

### 她的「過度正常」
她的另一種失常是**做得太正常**——把家裡打掃得一塵不染、把絨布盒裡的東西按順序排好、把信封的邊角對齊到毫米。控制是她對恐懼的回應。當她控制得越精確，她越接近崩潰。

## 三、禁語清單

### 絕對禁止出現於正文

**情緒直述**：
- 「痛苦、絕望、崩潰、心碎、淚如雨下、嘶吼、哭號」——一律換成動作

**輪迴直述**：
- 「真相、命運、輪迴、前世、重生、第一世、第二世、第三世」——本文不直說

**醫學術語**：
- 「亨廷頓、HD、基因、遺傳、染色體、顯性」——全禁
- 「額顳葉失智」——僅限 Part I 中她留下的那份報告上的六個字
- 「FTD」——僅限 Part IV 她親口說「我有 FTD」那一句

**設計感語詞**：
- 「一模一樣、複刻、佈局、陷害、設計」——讀者靠結構自己推理

**標點禁令**：
- 感嘆號——全禁
- 破折號超過三連——全禁
- 省略號超過六點——全禁

### 關鍵禁止

**不許寫以下任何一句話或其變體**：
- 「她犧牲了自己」
- 「她是為了他好」
- 「她默默承受」
- 「她有多愛他」
- 「她的愛太沉重」

這些框架全部是錯的。她不是犧牲——她是控制。書不能給讀者這個出口。

## 四、FTD 書寫鐵律：感覺不是診斷

**核心原則：從疾病內部書寫。她不知道自己在退化——她只知道有什麼不對。**

### 禁止

| 禁寫 | 原因 |
|------|------|
| 「她的 FTD 導致語言功能下降」 | 她不會用臨床語言描述自己 |
| 「額顳葉退化使她⋯⋯」 | 同上 |
| 「她開始出現失智的症狀」 | 她不會給自己貼標籤 |
| 「病情惡化了」 | 太外部，太概括 |
| 「她漸漸失去了自己」 | 太文學，太浪漫化 |

### 允許（範例）

| 感覺 | 寫法 |
|------|------|
| 語言退化 | 「我伸手去撈那個字。字不在了。它剛才還在——在嘴邊。我張嘴，什麼也沒出來。」 |
| 時空混淆 | 「我站在窗前。我不記得什麼時候走到這裡的。我本來要去哪？」 |
| 判斷力下降 | 「我把鑰匙放在冰箱裡。我不知道為什麼。後來找了半小時。」 |
| 人格冷漠 | 「他打電話來。我看著螢幕。我知道我應該接。我知道我想接。但我的手沒動。」 |
| 自我懷疑 | 「我不確定剛才那件事是不是真的。我不確定昨天的事是昨天的。」 |
| 身體失控 | 「我的手在抖。我看著它抖。像在看別人的手。」 |
| 夜遊 | 「鄰居說我昨晚穿睡衣站在巷口。我不記得。我記得的最後一件事是我在看電視。」 |

### 退化的書寫法則

1. **漸進**：Part II 末期偶爾出現。Part III 前期散落。Part III 中後期加密。不是斷崖
2. **不均勻**：有些天她清醒得像沒生病。有些天她連自己的名字都要想一秒。好日子和壞日子交替——壞日子慢慢變多
3. **她自己不確定**：她不確定哪些是病、哪些是疲憊、哪些是悲傷。**分不清是最恐怖的**
4. **日常化**：退化藏在日常動作裡——買菜、煮飯、寫字、過馬路。不藏在戲劇化場景裡

## 五、13 封信的書寫鐵律

### 信的語調

信是她寫給他的。語調是**日常的**——不是文學、不是散文、不是遺書。她在信裡像在和他說話。因為他不在，所以她把話寫下來。

### 退化曲線

| 階段 | 信 | 語言特徵 | 具體指標 |
|------|-----|---------|---------|
| 早期 | L1–L4 | 完整、清晰 | 句子長度正常（15-30字）；邏輯連貫；偶有一個詞找不到，用破折號跳過 |
| 中期 | L5–L9 | 出現重複和跳躍 | 同一件事說兩遍不自覺；時間標記偶爾錯（「昨天」是三天前）；段落之間的邏輯銜接開始鬆 |
| 晚期 | L10–L12 | 片段化 | 句子變短（5-10字）；用字變基本；一個念頭寫到一半跳到下一個；但「你」和情感核心仍然清楚 |
| 最後 | L13 | 未完成 | 只有幾行；字跡（以描述暗示）歪斜；最後一行斷在半個句子 |

### 禁止

- 不把信寫成散文詩
- 不把退化寫成「文學的破碎美」——退化不美，它只是壞掉
- 不讓每封信都有「金句」——有些信就是平凡的、重複的、無聊的。這才真實
- 不讓 L13 寫得太完美——它是未完成的。未完成不是省略號，是她寫到一半筆停了

### 每封信的格式

```
致我親愛的先生：

（正文）

宜
```

開頭永遠一樣：「致我親愛的先生」。結尾永遠一樣：「宜」。中間的世界在崩塌，但框架不變——直到 L13 連「宜」都沒簽。

## 六、共享場景鐵律

### 核心規則：同一事件，零重複文字

當本書描述一個在《白露未晞》中也出現的場景時：

1. **事實必須一致**：日期、地點、物件位置、對話原文（引號內的字）——必須與原作完全吻合
2. **描述必須完全不同**：敘述角度、注意到的細節、感官、節奏——必須從頭寫過
3. **一個字都不能照抄**——即使描述同一張桌子、同一杯咖啡

### 她注意的 vs. 他注意的

| 他（原作）注意 | 她（本書）注意 |
|--------------|--------------|
| 時間（幾點、多久、第幾天） | 質地（布料的觸感、紙的粗糙、水的溫度） |
| 順序（先做什麼、後做什麼） | 聲音的邊緣（冷氣的嗡聲、遠處車聲、他呼吸的節奏） |
| 物件的功能和位置 | 氣味（他的洗衣精、咖啡的焦味、古龍水殘留） |
| 她的外在表現（她說了什麼、她的手在做什麼） | 他的無意識動作（他嘴角的肌肉、他握杯子的力道） |
| 事實和數字 | 光線、溫度、空氣的流動 |

### 工作流程

每寫一個共享場景之前：
1. 先讀原作對應段落
2. 列出原作中提到的所有事實細節（時間、地點、物件、對話）
3. 確認本書中這些事實完全一致
4. 然後**從頭寫**——她在同一個房間裡看見的是完全不同的世界

## 七、「是」的書寫鐵律

Part II 中她說「是」（承認外遇）是全書最難寫的一個字。

### 規則

1. **外面**：她的臉上什麼都沒有。不哭、不顫、不轉頭、不閉眼。她看著他。她說：「是。」
2. **裡面**：一切都在塌。但不能直寫「她的世界崩塌了」。必須用身體感覺：她聽到自己的聲音從很遠的地方傳來；她聞到他身上今天剛洗的衣服的味道；她注意到窗外有一隻鳥飛過
3. **之後**：她做一個極微小的動作——可能是嚥了一口口水、可能是把左手放到右手上、可能是什麼都沒做。這個動作承擔全部的重量
4. **不解釋**：不寫「她為什麼要說是」「她其實不想說」「她心裡在想⋯⋯」。讀者必須從前文（她的策劃）和後文（他的死）自己拼出來
5. **時間感**：這個字之前的三十秒和之後的三十秒，必須是全書時間流動最慢的段落。不是用慢動作手法——是用細節的密度讓時間變稠

### 對照

原作中，他聽到「是」之後的反應是外在的——他問「誰」、他要細節。
本書中，她說出「是」之後的經歷是內在的——世界的聲音忽然變遠、或忽然變清楚。

## 八、三世差異的聲音設計

她的「我」在三世中應有微妙差異：

| 世 | 她的狀態 | 聲音特質 |
|----|---------|---------|
| 第一世 | 計畫者、執行者 | 冷靜、精確、有控制感。句子完整、邏輯清楚。像在寫一份計畫書——但計畫書的對象是她自己的婚姻 |
| 第二世 | 試圖修正者、逐漸失控者 | 前期急切（想修正）、中期困惑（為什麼他不信）、後期碎裂（FTD + 孤獨）。句子從完整走向斷裂 |
| 第三世 | 放棄控制的人 | 疲憊、安靜、但有一種前兩世沒有的東西——她不再試圖計算。她只是說了。聲音最簡單、最短、最輕 |

## 九、許敬庭使用規則

| 部 | 許敬庭出現 | 說明 |
|----|----------|------|
| Part I | 可出現（信抬頭、她的回憶片段） | 她想起自己用了他。悔意不是對許敬庭的——是對自己「連算計都算計得那麼精確」的厭惡 |
| Part II | 多次 | 她的策劃過程。她如何選中他、如何佈置線索。她知道他曾經暗戀她——她利用了這個 |
| Part III | 一次（偶遇） | 她在街上遇到他。她想切割。她回家坦白。她以為坦白是修正。結果是災難 |
| Part IV | **零次** | 鐵律。他的名字不出現。他在第三世如同不存在 |

## 十、物件使用守則

### 銀手環
- 她的視角：她知道刻字 `For Y. 11.02` 是他的字跡。她在第一世策劃時把它放進絨布盒——這是她為他留的最後一件真的東西
- 出現：Part I（她放進盒子的記憶）、Part II（他送她那天）、Part III（她第二世重新放進盒子）

### 右手腕舊疤
- 她的視角：那是她十歲被母親推下樓梯的印記。她有時候會無意識地用左手拇指摸它
- 出現：Part II 童年、Part II 相遇（他第一次注意到時她的反應）、Part III 浴缸前、Part IV 他按住她的疤

### 絨布盒
- Part I 的核心物件。本書從她的角度寫：她為什麼把這些東西放在一起、她放的順序、她放的時候在想什麼
- 這不是遺書。這是她整理自己人生的方式——像整理抽屜

### 浴缸/浴室
- 三世三次死亡的空間。**不明說「她死在和母親一樣的地方」**——讀者自己連結
- 她的視角：浴室對她不是恐怖的地方。它是她母親待過的最後一個房間。它是安靜的

## 十一、風格模板（承襲原作 + 新增層）

### 承襲自原作的十條鐵律
1. 句子長度分佈不均勻
2. 避免「的」字連鎖（一句最多一個「的」）
3. 獨立短句當重拳
4. 每段首句定調、末句轉身
5. 不解釋情緒，只給動作和物件
6. 時間跳躍明示不解釋
7. 五感至少用三種
8. 物件承擔時間
9. 對白 ≤ 全篇 10%
10. 對白前後不描述表情

### 本書新增
11. **「覺察」是她的呼吸**：允許「我想」「我發現」「我知道」——但只用於她直視自己最不堪的念頭時。日常觀察仍以動作和物件為主
12. **恐慌加速**：某些段落她的內在節奏忽然加快——句子變短、連續兩三句不到五個字。然後硬煞住。煞住之後是一個很長的、很安靜的段落
13. **她的比喻只用身體**：「像嘴裡含了一口水忘了吞」、「像指甲刮到黑板但聲音在裡面」——不用文學典故、不用自然景觀

## 十二、禁忌句型範例

| 禁寫 | 改寫 |
|------|------|
| 「她默默承受著一切」 | 「我把碗洗完。水很冷。我沒關熱水器。」 |
| 「她為了他犧牲了自己」 | （絕不允許這個框架出現） |
