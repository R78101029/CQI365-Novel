## 紀律 2：寫的時候·三條鐵律

### A. 不引哲學原文·不用哲學詞彙
禁字清單（任一出現 = 重寫該段）:
> 空、無、執著、放下、無為、禪、悟、初心、生命的意義、頓悟、契機、覺察、人生境界

### B. 不寫「他想起 / 他意識到 / 他覺得 / 內心深處 / 某種東西」
這些是 agent 本能。出現一次刪一次。
情緒只能透過**動作**或**物件**呈現·不能直接命名。

### C. 不寫比喻說明情感
> 「他的心像一片枯葉」「他的心情如同那片海」——這種句子毀掉這本書。
比喻可以·但不能用來「翻譯」情緒。

## 紀律 3：禁止的 6 個結構動作

- ❌ 風景描寫當段落開頭（「陽光透過窗戶灑落⋯」）
- ❌ 用感嘆句表達情感
- ❌ 「彷彿 / 似乎 / 彷若」做抒情虛化
- ❌ 「那時他還不知道」全知敘事破口
- ❌ 章末預告下一章
- ❌ 戲劇性巧合（她不是他辦過案子的關係人 / 不是他舊日認識）

## 紀律 5：禁忌人物與物件

| 不寫 | 為何 |
|------|-----|
| 前妻 | **全書不出現**（無閃回、無夢境、無婚姻回憶）·她的痕跡無所不在但她本人不在 |
| 前妻留下民宿的原因 | **永遠不解釋**·這是全書的「第二空白」 |
| 婚姻時期的共同回憶 | 民宿裡的物件全是她離婚後的東西·他不認識·**不要寫「他想起他們⋯」** |
| 律所同事 | 是舊生活剪影·不是角色 |
| 主角刻意修煉 | 不打坐·不讀書·不運動·不寫日記 |
| 主角的「失敗」案件回憶 | 那案子只存在於讀者推測中 |

### 前妻三鐵律（紀律 5 補充·極重要）

1. **不寫婚姻回憶**：不回憶他們怎麼認識、怎麼結婚、怎麼離婚。離婚的原因（工作狂）只透過他現在的行為模式間接顯現。
2. **不解釋遺囑動機**：她為什麼把民宿留給他——**永遠不寫**。不讓主角猜、不讓任何角色討論、不讓讀者得到答案。這是全書的「第二空白」。
3. **物件不觸發共同記憶**：民宿裡的舊月曆、收音機、木桌、貓——全是她離婚後的生活。他不認識。物件只能是物件·不能變成「他們曾經⋯」的入口。

## 紀律 6：寫完後自檢清單

每章寫完·開新對話檢查前·過一次：

- [ ] 任何一條禁字出現？
- [ ] 「我」字頻率算過了嗎？在區間內嗎？
- [ ] 律師腦詞彙超出該季預設？
  - 春：可大量出現
  - 夏：密度降低（夏末幾乎消失）
  - 秋：完全不再用
  - 冬：幾乎沒有
- [ ] 該寫淡的段落寫飽了嗎？檢查：
  - 陽台五分鐘（第 3 章中段）：300-500 字內
  - 第 14 章後半段（她沒來）：極度克制
  - 第 18 章陽台回憶：「他只是記起來」·不加詮釋
- [ ] 章末有沒有不自覺地預告下一章？
- [ ] 有沒有「頓悟時刻」？（頓悟本身就是另一種抓取）
- [ ] 有沒有 agent 慣用的「飽滿層次」筆法侵入？
- [ ] 有沒有出現前妻的閃回、婚姻回憶、或解釋遺囑動機？
- [ ] 前妻的物件有沒有被寫成共同記憶的觸發物？

## 紀律 7：寫完後·問自己這六個問題

1. 像不像療癒系慢生活小說？
2. 像不像中年找回自己的勵志故事？
3. 像不像追憶逝水年華式抒情散文？
4. 像不像禪意小品？
5. 像不像民宿老闆的溫暖日常？
6. 有沒有出現「飽滿但 IRIS 風格」的段落？
7. 像不像前妻留給他的救贖故事？

任何一題答「有點」→ 重寫該段。

---

## 紀律 8：保留「不夠好」的段落

人工校稿時·**保留那些看起來不夠好的段落**——它們可能才是對的。

> 寫得不夠飽滿·沒關係。寫得留白·沒關係。寫得像閒筆·沒關係。
> 這本書的技藝·是克制的技藝·不是豐盛的技藝。
