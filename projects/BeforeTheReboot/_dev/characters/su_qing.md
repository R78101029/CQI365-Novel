# 蘇晴（前台反派）

| 項目 | 內容 |
|---|---|
| 年齡 | 26（1999 生） |
| 身分 | 微光科技產品經理 |
| 出身 | 單親家庭，母親在外地打零工。弟弟蘇陽欠了網貸和賭債 |
| 能力 | 真的很會做 PM：需求整理、簡報、向上管理都是一流。她不懂架構，但懂人 |
| 手法 | 包裝人設（「與陳默共患難的靈魂伴侶」）、資訊落差、情緒勒索（「我那晚也沒睡」）、先哭再說 |
| 重生 | 第 68 章覺醒（怨，暫定）。記憶到 2031/02 |

## 她為什麼這樣

- 2025 年那一夜她其實也在公司，只是做的是打電話安撫客戶。她看到知夏昏倒，看到救護車。隔天陳默問她「那晚是怎麼撐過去的」，她說了第一個謊——**一開始只是沒有糾正**，後來就收不回來了
- 弟弟的債是她的軟肋。2026 年初，韓崢透過一家放貸公司掐住了蘇陽的債務，她開始替韓崢做事
- 她不是天生的壞人，是一路選錯。**讀者應該在第 66–70 章對她有一瞬間的理解，但不原諒**

## 前世

升產品總監（2026）→ 副總（2028）→ 2030 年聯手韓崢掏空微光、指控陳默 → 2030/12 監管調查時，韓崢與梁啟元把責任全推給她 → 2031/02 取保候審期間，雨夜車禍身亡。她到死都在恨韓崢。

## 今世的軌跡

| 階段 | 她在做什麼 |
|---|---|
| 一 | 主張知夏的模組是公司財產；在公司散布「知夏是嫉妒才走」；開始和韓崢接觸 |
| 二 | 攻擊事件答不出架構，第一次在陳默面前失手。她察覺陳默變了，開始防備 |
| 三前段 | 反擊：對陳默情緒勒索；向媒體放料「陳默為前女友打壓員工」；拉攏梁啟元 |
| 三中段 | 審計收網，她想跑。韓崢切割她 |
| 66 | 被刑事拘留 |
| 68 | 韓崢的律師傳話「妳自己扛」。前世重演，她覺醒 |
| 70 | 她要求見林知夏（不是陳默）。兩個重生者第一次面對面 |
| 71–75 | 認罪認罰，成為污點證人，交出韓崢和梁啟元的證據（包括她前世才知道的代持協議位置）。民事賠償，業界除名 |
| 番外之外 | 結局不寫她出獄。只在第 99 章一句帶過她的刑期 |

## 第 70 章：兩個重生者的對話（關鍵場景）

- 蘇晴不道歉，至少不是真心的。她說：「妳早就知道了，對吧。從慶功宴那天妳就知道了。」
- 知夏不承認也不否認
- 蘇晴提出交易：她作證，換知夏幫她說一句話
- 知夏：「妳要說的，去跟檢察官說。」起身離開
- 走到門口，知夏回頭問了一句：「那天晚上，妳為什麼不糾正他？」蘇晴沒有回答。**這是全書唯一一次知夏問「為什麼」**
