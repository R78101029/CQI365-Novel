# 墨沉

地板是濕的。

我醒過來的時候——不是在床上。在沙發上。右邊。跟每天一樣。右腳先落地。

涼的。

不是木地板正常的涼。更重。更沉。像踩在一層什麼東西上面。

我睜開眼。書房。燈沒開——我大概是打字打到睡著的，螢幕還亮著，光照在天花板上，偏藍。窗外是暗的。還在下雨。

我低頭看地板。

黑色的。一層薄薄的液體。覆蓋了整面地板。不多——大概兩毫米深。不是水。顏色太深了。質感太稠了。我的右腳踩在裡面。五個腳趾的印子。很清楚。黑色的液體從腳趾縫裡擠上來。

我把腳抬起來。液體沒有飛濺。只是慢慢地填回我腳印的位置。像一面黑色的鏡子被按了一下，然後恢復了。

我又踩了一次。這次是刻意的。整個腳掌，慢慢放下去。液體在腳掌邊緣被擠開，形成一圈很淺的隆起，然後回來。腳底跟地板之間沒有隔——我能感覺到木頭的紋路，跟平常一樣。液體薄到不構成一層。

我看了看牆。乾的。天花板。也乾的。窗框、門框、踢腳板——全部乾的。黑色的液體只在地板上。沒有流進來的痕跡。沒有漏下來的源頭。它就在那裡。像一直都在。像地板本來就是這個顏色。

我蹲下來，把手指伸進去。

涼的。指腹沾了。我抬起手，液體在指尖聚成一顆，然後落下去，落回地板，沒有聲音。

我把手指在拇指上搓了搓。沒有黏。沒有味道。搓完之後手指上還是有一層，跟指節上那些墨漬的顏色一樣。分不出哪些是新沾的，哪些是本來就在的。

我赤腳踩在上面。站了起來。

涼。但可以忍受。質感比水重一點——腳底離開地面的時候有一點黏，像踩在稀釋的蜂蜜上面。不是噁心的黏。是那種讓你意識到自己在踩著什麼的黏。

椅子的四隻腳在黑色液體裡。椅輪沾了。桌腳也沾了。沙發的底座沒有碰到——沙發有腳，比地板高大概十公分。

我走到書桌前。三步。每一步在黑水裡留一個腳印。腳印維持了大約兩秒就被填平了。

坐下來。

筆電的鍵盤是乾的。螢幕亮著。《白露》的檔案開著。游標在最後一行閃。字數顯示一萬零兩百。

我把手放在鍵盤上。腳泡在黑水裡。

繼續寫。

※

我沒有去查那些液體是什麼。沒有用手指沾起來聞。沒有找抹布擦。沒有打開門看走廊有沒有。

它在那裡。我在這裡。

這不是正常的反應。我知道。正常的人醒來發現地板上有一層黑色液體，應該會驚慌。應該打電話給房東。應該打 119。應該至少去查一下來源。

我沒有。我坐下來繼續寫。

也許是因為我已經在這個書房裡坐了五天了。五天。泡麵碗。涼掉的咖啡。洗不掉的墨漬。天花板的黑色液滴。門外的腳步聲。薰衣草的味道。信。

一件一件來的時候，每一件都只是微小的偏移。偏移累積到一定程度，正常就不是正常了。它變成了基線。新的基線。在這個基線裡，地板上有一層黑水是可以接受的。

我想過一件事：如果現在有人走進這個書房，他會看到什麼。

他會看到一個五天沒洗澡的男人坐在書桌前打字，地板是乾的，桌上有三個泡麵碗，男人的右手有三根手指髒了。他會覺得這個房間需要打掃，這個男人需要睡覺。他不會看到黑水。

或者他會看到。我不知道。這件事沒有辦法測試，因為不會有人走進這個書房。

我打字。腳在黑水裡。黑水在我腳上。我在黑水上面。黑水在我下面。

中間我去了一趟浴室。

站起來的時候黑水從腳踝滑下去。走三步到門口。開門。抬腳跨過門檻。

跨過去的那一瞬間我低頭看。腳底沾著的那一層，在離開黑水之後大概兩秒就沒了。不是滴掉的，也不是被地板吸走的。走廊的地板上乾淨的，沒有濕痕，沒有腳印。

我又回去踩了一次，再跨出來，看第二次。一樣。

我在浴室洗了臉。冷水。抬頭的時候鏡子在那裡，我沒有避開——延遲三秒。我舉手，鏡子裡的手三秒後才舉起來。我沒有等它同步就轉身走了。

回書房。跨過門檻。腳踩進黑水裡的時候有一種被接住的感覺——不是溫的，是密度的問題，水比空氣有支撐。

我坐下來。繼續打字。

這五天我吃的東西：泡麵七包、餅乾兩包、一罐鮪魚。喝的：即溶咖啡、水。我沒有算過熱量，但我知道不夠，因為站起來的時候眼前會黑一下，大概三秒才恢復。這件事從第三天開始。

我沒有處理。處理需要出門，出門要換衣服、下三層樓、走三分鐘。

繼續。

※

>>> 「為什麼你不開門？」

>>> 「因為我在寫。」

>>> 「你在寫什麼？」

>>> 「在寫一個不開門的人。」

>>> 「那個人在寫什麼？」

>>> 「在寫一個問為什麼不開門的人。」

>>> 「那個問的人在做什麼？」

>>> 「她在門外站著。等。」

>>> 「等多久？」

>>> 「五分鐘。」

>>> 「五分鐘夠嗎？」

>>> 「不夠。」

>>> 「那要多久？」

>>>

>>> 沒有回答。因為回答不了。沒有一個時間長度是對的。五分鐘不夠。五小時不夠。五年不夠。問題不在時間的長度。問題在門。門是關著的。無論你在門的這一邊等多久，門的那一邊不會因為你等了就打開。門不是時鐘。門是牆。

>>> 「那你為什麼要寫。」

>>> 「因為我不能開門。」

>>> 「你可以開門。」

>>> 「我可以開門。」

>>> 「那為什麼不開。」

>>> 「因為開了以後就沒有東西可以寫了。」

>>>

>>> 這句話說出來以後有一段安靜。安靜有厚度，可以摸到，像房間裡忽然多了一個東西站在中間。

>>> 「你剛剛說的那句話，你要不要收回。」

>>> 「不要。」

>>> 「你知道那句話是什麼意思嗎。」

>>> 「知道。」

>>> 「說一次。」

>>> 「⋯⋯」

>>> 「說一次。」

>>> 「如果她進來了，我就要處理她。處理她要用掉我在處理句子的那個部分。那個部分只有一個。」

>>> 「所以你選了句子。」

>>> 「我沒有選。我以為兩個都可以要。我以為只要五分鐘。」

>>> 「五分鐘夠嗎。」

>>> 「不夠。」

>>> 「那要多久。」

>>>

>>> 沒有回答。這一次不是回答不了。是因為問題又回到了開頭，而回到開頭的問題不需要回答，只需要重新問一次。

>>>

>>> 「換一個問題。」

>>> 「好。」

>>> 「如果現在有人在門外，你會開嗎。」

>>> 「會。」

>>> 「為什麼。」

>>> 「因為現在門外沒有人。」

>>> 「所以你會開。」

>>> 「所以我會開。」

>>>

>>> 「那三年前呢。」

>>> 「三年前門外有人。」

>>> 「所以你不開。」

>>> 「所以我不開。」

>>>

>>> 「你聽到自己在說什麼嗎。」

>>> 「聽到。」

>>> 「你要不要換一個說法。」

>>> 「不要。換說法不會改變它。」

>>> 「那你至少可以說得好聽一點。你是寫東西的。」

>>> 「我知道怎麼說得好聽。」

>>> 「說一次。」

>>> 「不要。」

>>>

>>> 這一次的安靜比上一次長。

>>> 「你是誰。」

>>> 「你知道我是誰。」

>>> 「我想聽你說。」

>>> 「⋯⋯」

>>> 「說。」

>>> 「你。」

>>> 「哪一個你。」

>>> 「門這一邊的那個。」

我打完這一段。停了。

不確定這段是誰寫的。是我打在鍵盤上的。但聲音不像我。聲音像《白露》裡那個角色——但不是第一層的那個。更深的。第三層。或者更深。

問問題的那個是誰，我也不確定。開始的時候我以為是她。寫到中間我發現不是——她不會這樣問。她從來不逼人。她會問一次，得不到答案就停下來，然後自己想辦法把話題轉開。

會這樣一直問下去的只有一種人。

我已經分不太清楚了。哪些是我寫的。哪些是角色說的。哪些是我在想但沒有打出來、被手指自動打出來的。

繼續。

※

>>>> 門。

>>>> 只有門。門板佔滿了所有的空間。上面的邊緣碰到天花板。下面碰到地板。左右碰到牆。門就是空間本身。

>>>> 木紋。直的。偶爾有一個結。結的中心是暗的。同心的紋路從中心往外擴散。像投石到水裡的漣漪凍住了。

>>>> 油漆剝落的那一塊。離地九十公分。兩公分見方。露出底下的木紋。淡黃色的。她的手指碰過那裡。也許。

>>>> 門上有字。

>>>> 字是他的筆跡。寫著：

>>>> 「再五分鐘。」

>>>> 三個字。筆畫是黑色的。墨水在門板上。墨水在往下流。沿著木紋的溝。慢慢地。一筆一畫地融化。字在解體。「再」的撇劃先流了。然後「五」的橫。然後「分」的八字頭。然後「鐘」的金字旁。

>>>> 流下來的墨在門板中段聚成一條，變粗，加速，然後分岔。分岔的兩支各自往下，其中一支經過那塊剝落的漆，被木紋的粗糙擋了一下，散開，變成一片扇形，然後重新聚合。

>>>> 字沒有了以後，門板上留下一片痕。不是字的形狀。是字流過去的形狀。

>>>> 墨水流到門板的底部。流到門檻。流過門檻。流到地板上。

>>>> 跟地板上的黑水混在一起了。

>>>> 門上又出現了字。

>>>> 同樣的三個字，同樣的位置，同樣的筆跡。剛寫上去的，墨還亮著。

>>>> 開始流。

>>>> 這一次他看著它流完。從第一筆開始鬆動到最後一畫散掉，用了大概四十秒。他數了。四十秒。

>>>> 然後字又出現了。

>>>> 他站在那裡看了七次。第七次的時候他伸手去摸門板上的字。手指碰到的時候字還沒開始流，墨是濕的，指腹沾到一點。他把手指抽回來，看了看。黑的。

>>>> 他在褲子上擦了一下。

>>>> 字開始流了。

>>>> 他想到門的另一邊。這一層裡門就是空間本身，所以門沒有另一邊——但他還是想。想的方式是把手貼在門板上，等一個溫度。

>>>> 門板是涼的。均勻的涼。沒有一塊比較溫，沒有一塊比較冷。如果另一邊有人靠著，木頭會在那個位置變溫，這是他知道的事，因為她靠過。

>>>> 他把手掌從門板的一頭慢慢移到另一頭。左邊到右邊。上面到下面。花了很久。門板佔滿了空間，所以「很久」在這裡是唯一能用的長度單位。

>>>> 全部一樣涼。

>>>> 他蹲下來，摸那塊剝落的漆。指腹在兩公分見方的範圍裡來回。木紋的方向是直的。摸到第七次的時候他發現一件事：這塊剝落的邊緣是新的。

>>>> 漆掉下來的地方，斷面應該會氧化，變黃，變鈍。這一塊沒有。斷面是脆的，白的，剛剛才裂開的樣子。

>>>> 他往後退了一步看整扇門。

>>>> 門是新的。木頭沒有吸過三年的濕氣。漆是白的，不是奶黃的。門把的銅色沒有被磨掉。

>>>> 這扇門是他寫出來的。他寫了幾天，所以它幾天大。

>>>> 那塊剝落的漆是他寫的第一天寫的。所以它是這扇門上最舊的東西——六天。

>>>> 他坐回桌前。

>>>> 三年在這一層不存在。這一層裡最長的時間是六天。她在門外站了五分鐘，那五分鐘也是六天前才被寫出來的。

>>>> 他寫的每一個東西都比它應該有的年紀輕。這件事沒有辦法補救——你不能寫出一個舊的東西，你只能寫出一個關於舊的描述，而描述是今天做的。

>>>> 他把手放在紙上。紙也是新的。

>>>> 只有一樣東西比六天舊。

>>>> 那句話。「我先把這段寫完。」

>>>> 這句話不是他在這一層裡寫出來的。它是被帶進來的——像一個人搬家的時候，行李裡混進了一件不屬於這個房子的東西。

>>>> 這句話有三年。摸起來跟門不一樣。門是脆的、白的、剛裂開的。這句話是鈍的，邊緣磨圓了，被拿出來看過太多次。

>>>> 他把這句話放在桌上，跟紙並排。

>>>> 紙是白的。那句話不是任何顏色。

>>>> 他寫東西的時候會避開它。不是繞路——是他寫的每一句話都在離它更遠的地方落腳，而寫得越多，離得越遠，那句話在桌上的位置就越清楚。

>>>> 一張桌子上，一句三年的話，和一疊六天的紙。

※

>>>>> 五分鐘。

>>>>> 五小時。

>>>>> 五年。

>>>>> 五個他坐在五張桌前。五張不同的桌子——但一模一樣。五盞檯燈。五杯冷掉的咖啡。五扇關著的門。

>>>>> 第一個他在寫的是一個男人坐在桌前。第二個他在寫第一個他。第三個他在寫第二個他在寫第一個他。往下數不完，往上也數不完——第一個他也是被誰寫出來的，那個誰在另一張桌前，另一盞檯燈下面。

>>>>> 五個他在寫五個版本的同一個故事。字不一樣。句子不一樣。段落不一樣。結局一樣。

>>>>> 「他以為只差五分鐘。他關上了門。」

>>>>> 「他以為只差五分鐘。他關上了門。」

>>>>> 「他以為只差五分鐘。他關上了門。」

>>>>> 「他以為只差五分鐘。他關上了門。」

>>>>> 「他以為只差五分鐘。他關上了門。」

>>>>> 五次。一模一樣。一個字不差。

>>>>> 第三個他試過改。他寫「他打開了門」，寫完看著，字沒有變。他等了十秒。二十秒。字還在。他以為成功了。

>>>>> 他站起來要去開門的時候，回頭看了一眼螢幕。

>>>>> 字變了。

>>>>> 他坐回去。這一次他沒有再站起來——不是因為放棄，是因為他發現一件事：字是在他離開桌子的那一刻變的。只要他還坐著，字就維持他寫的樣子。他必須一直坐在那裡，字才不會變回去。

>>>>> 所以他坐著。維持那七個字。

>>>>> 五個他同時抬頭。五張臉。同一張臉。五雙眼睛。同一雙。

>>>>> 他們互相看著。隔了四面牆。或者沒有牆。或者牆就是門。

>>>>> 第五個他張開嘴，要說什麼。其他四個他也張開嘴。同一個時間，同一個角度，同樣的動作。

>>>>> 沒有聲音。五個人同時說同一句話的時候，聲音會互相抵銷。這是他們後來才知道的。他們試了很多次。

>>>>> 第四個他停了。

>>>>> 不是決定停的。是手停了，然後他發現手停了。筆放在紙上，橫著。他把椅子往後推，站起來，走到房間的另一邊，背對著桌子站著。

>>>>> 其他四個他繼續寫。

>>>>> 這是第一次五個人做不一樣的事。

>>>>> 站著的那個等了一下。他以為會有什麼發生——門會開，雨會停，或者至少四個人裡會有一個也站起來。

>>>>> 沒有。

>>>>> 他背對著桌子站了大概兩分鐘。房間裡只有另外四個房間傳來的鍵盤聲，隔著牆或者沒有牆，聽得很清楚。噠噠噠。停。噠噠。

>>>>> 他回到桌前。坐下。拿起筆。

>>>>> 從他停下來的那個字接著寫。中間空出來的那兩分鐘沒有留下任何痕跡——紙上沒有停頓的墨點，句子沒有斷，讀起來像一氣呵成。

>>>>> 第四個他寫完那一段之後，跟其他四個一樣，寫下了同一句話。

>>>>> 「他以為只差五分鐘。他關上了門。」

>>>>> 站起來過，跟沒有站起來過，寫出來的結果一樣。

>>>>> 這是五個人裡唯一一個試過的。他沒有告訴其他四個。

>>>>> 五分鐘。五小時。五年。門還是關著。

※

他打了一行字。我看著那行字。

他不知道我在看。我不知道他就是我。

他的手在鍵盤上。我的手在鍵盤上。同一雙手。三根手指是黑的。食指、中指、無名指。黑色的不是墨水。是字。但也不完全是字。是介於墨和字和皮膚之間的某種東西。

同一張桌。同一杯涼掉的咖啡。同一扇關著的門。

他在打字。我在打字。他打的字出現在他的螢幕上。我打的字出現在我的螢幕上。同一個螢幕。

我往上滑，想看看他前面寫了什麼。滑上去的時候我發現那些字我不記得寫過，但每一句我都知道下一句是什麼。我把游標放在一個句子中間，句子的後半我在腦子裡已經有了，一個字不差。

這種事情有兩種解釋。一種是我寫的，只是忘了。另一種是我沒有寫，但我會這樣寫。

第二種比較難處理，因為它的意思是：寫或不寫沒有差別。那些句子已經在那裡了。我只是把它們謄出來。

他不知道他在小說裡。我不知道我在小說裡嗎。

我的手停了。

鍵盤上最後打的那個鍵是問號。螢幕上多了一個「？」。

我看著那個問號。它佔了一行。一個小小的彎勾。下面一個點。

我沒有刪。

我把手放回鍵盤，打了一行字，測試用的，隨便打的：「地板上有水。」

打完之後我低頭看地板。

黑水。到腳背了。剛才是腳底。

我把那一行刪掉。

再看地板。還是到腳背。刪掉字不會讓水退回去。

※

我把手從鍵盤上拿開。

看自己的手。

右手。五根手指。食指、中指、無名指——黑的。從指節一直延伸到指腹。昨天還只是指節外側。今天蔓延了。小指的側面也開始有了——一小段，像是黑色正在從無名指那邊慢慢爬過來。

我把手湊近螢幕的光。

不是墨水。墨水是均勻的。這個不均勻。有些地方深，有些地方淺。有紋路。

我湊得更近。瞇著眼。

是字。

密密麻麻的字，小到幾乎看不清。印在皮膚上。或者長在皮膚上。字跟皮膚的紋路混在一起——指紋的弧線裡面，每一條弧線都是一行字。

我能辨認幾個：

「他以為只差五分鐘。」

「她站在門外。」

「雨。」

「門。」

「再五分鐘。」

「他關上了——」

每一句都是我寫的。《白露》裡的句子。我的句子。它們從螢幕上搬到了我的皮膚上。不是我抄的。不是我紋的。它們自己在那裡了。

我找了很久，想找到一句不是我寫的。一句我不認得的。如果有一句是別人寫的，那這件事就有另一個解釋，那個解釋我需要。

沒有。每一句都是我的。連標點的用法都是我的——我在該用逗號的地方用句號，這個習慣被人說過，說我的句子太喘。皮膚上的字也在喘。

我看了很久。大概一分鐘。也許兩分鐘。

然後我把手放回鍵盤。

手指的字壓在鍵帽上。F、G、H、J。我打了一個字。空白鍵。Enter。手指離開鍵帽的時候，鍵帽上留了幾個極小的黑色痕跡。不是汗。不是油。是字的殘影。

我用袖子擦了 F 鍵。擦掉了。再打一次，又有。

我把鍵盤翻過來看。底下是塑膠殼，四個防滑墊，其中一個掉了，那個角會晃。三年了。

翻回來的時候有幾顆很小的東西掉出來——餅乾屑，還是別的，看不出來。落在桌上，我用手掃到桌邊，掃進手心，倒進垃圾桶。

垃圾桶在門邊。我沒有站起來，是把手伸過去的，身體從椅子上傾出去，指尖剛好碰到桶口。倒完收回來。

我繼續寫。

地板的黑水漫到我的腳踝了。剛才是腳背。現在是腳踝。大概高了五毫米。

我繼續寫。

※

沙發。我站起來的時候看了一眼。

左邊。她以前坐的那邊。坐墊比右邊高一點。三年沒人坐。布面上有一個淺淺的凹痕。

也許是她留下的。也許是布面老了自然塌的。也許是我想看到凹痕所以看到了。

我沒有坐過去摸。我從來沒有坐過左邊。三年。就像她還在。就像左邊是留給她的。但我不是刻意留的。是坐右邊的習慣先於她離開。她在的時候我坐右邊。她不在了我還是坐右邊。

黑水沒有淹到沙發。沙發有腳，十公分。水在腳邊，離坐墊還很遠。

如果水繼續漲，會先淹到沙發腳，然後是底座，然後是坐墊的下緣。右邊跟左邊會同時被淹到，因為它們一樣高。

我想到這件事的時候人已經站起來了，手還扶著桌沿。

我伸手，把手掌放在左邊的坐墊上。

布面是涼的。三年沒有人坐過的布，比常用的那邊涼一點，因為沒有吸收過體溫。

我的手掌壓下去，坐墊陷了大概一公分，然後回彈。我把手拿開。布面上留下一個手掌的形狀，淺的，過了幾秒就沒了。

凹痕還在原來的位置。我的手印沒有蓋過它，也沒有讓它變深。它跟我的手印是兩個不同的東西——一個在布的表面，一個在布的下面。

我又壓了一次，這次壓在凹痕上，用整個手掌。

放開。回彈。

凹痕還在。

凹痕在那裡。黑水在地板上。字在手指上。

都在。

※

我存了檔。字數。一萬兩千六百。

我不知道幾點了。螢幕右下角的時間——我沒有看。不想看。看了就要計算：幾點睡、幾點醒、寫了幾小時、還能寫多久。我不想算了。

五分鐘。五小時。五年。門還是關著。

我站起來。黑水從腳踝流下來。沿著腳面。流到地板上。匯入那層黑色的液體。看不出差別。

我走到書房門口。門是關著的。我轉門把。打開。

走廊的地板是乾的。

我站在門框裡。一腳在書房——黑水裡。一腳在走廊——乾的地板上。溫差。黑水那邊涼。乾地板那邊不涼。

我低頭看兩隻腳。左腳的腳背上有黑水留下的痕，一條線，剛好在水位的高度。右腳在乾的地板上，腳底離開黑水之後帶出來的那一層已經沒有了——不是擦掉的，是消失的。走廊的地板上沒有腳印。

走廊是暗的。我沒開燈。

第三步。地板響了。

廚房。水龍頭。滴。

我站了一會。

回來。書房。黑水。

門——我想了一下。

沒有關。

這次沒有關。

門開著。走廊的暗從門口灌進來。跟書房的螢幕光混在一起。交界線在地板上。螢幕光是藍白的。走廊是灰黑的。黑水在兩種光之間，看不出顏色了。

黑水到了門檻就停了。門開著，它沒有流出去。它有它自己的邊界，跟門開不開沒有關係。

我坐下來。手放在鍵盤上。手指上的字壓在鍵帽上。

門開著。

我繼續寫。
