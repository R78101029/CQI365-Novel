## 她為什麼這樣

- 2025 年那一夜陳默在外地救融資，她是公司裡唯一的主管，做的是打電話安撫客戶。她看到知夏昏倒，叫了救護車，順手收起了桌上那支沒電的手機。陳默打來問「知夏還好嗎」，她說「在家睡了，她交代你先顧融資」——**這是第一個謊**。她喜歡陳默很久了，那一刻她只是想讓他多依賴自己一點。後來每一個謊都是為了圓這一個，就收不回來了
- 弟弟的債是她的軟肋。2026 年初，韓崢透過一家放貸公司掐住了蘇陽的債務，她開始替韓崢做事
- 她不是天生的壞人，是一路選錯。**讀者應該在第 66–70 章對她有一瞬間的理解，但不原諒**

## 前世

升產品總監（2026），收韓崢的錢、外流原始碼。2027 年秋，她察覺知夏在查日誌、追到她的帳號。**她策劃了那場車禍**：把 11/09 的上線排在凌晨，確保知夏最後離開；把知夏的回家路線與時間交給韓崢的人；欠高利貸的貨車司機馮建國執行。她告訴自己「只是要讓她住院一陣子」。

知夏死後兩個月，她和韓崢帶走核心技術、梁啟元賤賣微光。2028/03 警方依陳默留下的資料重啟調查，韓崢把一切推給她。2028/04，她出逃前一晚，雨夜，被一輛沒開燈的車撞死。她到死都在恨韓崢——也終於知道知夏最後看見的是什麼。

## 今世的軌跡

| 階段 | 她在做什麼 |
|---|---|
| 一 | 主張知夏的模組是公司財產；在公司散布「知夏是嫉妒才走」；開始和韓崢接觸 |
| 二 | 攻擊事件答不出架構，第一次在陳默面前失手。她察覺陳默變了，開始防備 |
| 三前段 | 反擊：對陳默情緒勒索；向媒體放料「陳默為前妻打壓員工」；拉攏梁啟元 |
| 三中段 | 審計收網，她想跑。韓崢切割她 |
| 66 | 被刑事拘留 |
| 68 | 韓崢的律師傳話「妳自己扛」。前世重演，她覺醒——記憶裡有她自己策劃的那場車禍，和她自己的死。**讀者在這一章才知道車禍不是意外** |
| 70 | 她要求見林知夏（不是陳默）。兩個重生者第一次面對面 |
| 71–75 | 認罪認罰，成為污點證人，交出韓崢和梁啟元的證據（包括她前世才知道的代持協議位置）。民事賠償，業界除名 |
| 番外之外 | 結局不寫她出獄。只在第 99 章一句帶過她的刑期 |

## 第 70 章：兩個重生者的對話（關鍵場景）

- 蘇晴不道歉，至少不是真心的。她說：「妳早就知道了，對吧。從慶功宴那天妳就知道了。」
- **她不說車禍的事**。那是她最深的祕密，今世也沒有任何法律意義。讀者知道（第 68 章），知夏不知道——這一場的每一句話都在這層陰影下
- 知夏不承認也不否認
- 蘇晴提出交易：她作證，換知夏幫她說一句話。她亮出籌碼：「妳以為擋妳的只有我？梁啟元手上有鼎星的股份。」（知夏在這一章得知 T4）
- 知夏：「妳要說的，去跟檢察官說。」起身離開
- 走到門口，知夏回頭問了一句：「那天晚上，妳為什麼不糾正他？」蘇晴沒有回答。**這是全書唯一一次知夏問「為什麼」**。知夏問的是 2025 年的那一夜；讀者聽見的是 2027 年的那一夜
