# 墨影

白天出了一趟門。

巷口的便利商店。從公寓門口走過去大概三分鐘。雨小了但沒停，像有人把水龍頭轉到最小還是關不完。我穿了拖鞋，那雙灰色的塑膠拖鞋，鞋底磨平了，踩在濕的柏油上幾乎沒有摩擦。

買了兩包泡麵和一罐即溶咖啡。結帳的時候店員問我要不要袋子。我說好。她掃了條碼，看了我一眼。大概是看到我的拖鞋——濕的，鞋底沾了一片黃色的落葉，貼在那裡，我沒注意到。她把東西裝進袋子。我拿了。走了。

回到公寓樓梯間的時候我低頭看鞋。落葉還在。我用另一隻腳踩了一下，葉子掉了，留了一個溼的輪廓。

樓梯間沒有燈。白天靠窗戶的光。三樓的窗戶裂了一條，用膠帶貼著，膠帶變黃了。我已經看了三年。

※

晚上九點。書房。

打開筆電。《白露》的檔案還在。一千二百字。游標在最後一個句號後面。

我從最後一行看起。「他沒有劃掉這一行。」

我看了那句話。看了大概五秒。然後把游標移到下一行。開始打。

書房的燈還是暖黃的。咖啡杯我洗了——下午的時候洗的，用清水沖了三遍，杯緣的痕淡了但沒有完全消掉。我又泡了一杯。新的即溶咖啡。味道比上一罐淡。

窗外的雨跟昨晚差不多。不大不小。鐵皮屋頂的聲音。我已經聽了三年，不會再注意了——除非它停。它很少停。

我打了兩段。三百字左右。關於《白露》裡那個男人的桌子。他的桌子比我的大。他的房間比我的大。他的窗外不是巷子——是一片田。我給他一片田。雨落在田上的聲音跟落在鐵皮上不一樣。更悶。更遠。

我在給一個虛構的人一個比我好的房間。這件事我意識到了。但沒有改。小說本來就是把自己搬到一個不一樣的房間裡。

※

門外有腳步聲。

我停下來。手指離開鍵盤。停在半空中。

公寓老了。木造地板，三十年以上。熱脹冷縮加上基隆的濕氣，地板會自己發出聲音。白天比較少。晚上比較多。溫差的關係，大概。我住了三年，聽過各種聲音——嘎吱、咔、吱，偶爾像有人走過。大部分時候我不會注意。

但這一次不一樣。

腳步聲是有節奏的。左、右、左、右。不快。像是有人在走廊裡走。從客廳那個方向走過來。越來越近。

停了。

就在門外。

我盯著門。門板底部那塊油漆剝落。門跟地板之間有大概一公分的縫隙。我看那個縫隙。沒有光——走廊的燈沒開。沒有影子——如果有人站在門外，腳應該擋住路燈從客廳窗戶透進來的光。但什麼都沒有。

沒有敲門。

我等了。不是刻意等。是動不了。手指在半空中。鍵盤上最後打的那個鍵是空白鍵。螢幕上多了一個空格。

我數了。心裡數的，不出聲。一、二、三⋯⋯大概到三十的時候，腳步聲又開始了。往走廊那邊。左、右、左、右。越來越遠。越來越輕。然後沒有了。

我把手放回鍵盤。手是冷的。兩隻手都是。我搓了一下。指節的墨漬在兩隻手掌心之間磨了一下。

繼續寫。

※

> 他也聽到了。

> 不是腳步。是別的。比腳步更輕。混在雨聲裡面。如果不注意就會以為是風在門縫裡擠過去的聲音。嘶——嘶——不均勻的。像呼吸。

> 但他知道不是風。風不會那樣呼吸。風不會在呼氣的末端帶一個很小的、碎掉的音——像是想說什麼，但嘴唇沒有張開，聲音就碎在齒縫裡了。

> 他放下筆。

> 看著門。門是木頭的。偏黃的白漆。門板底部有一塊油漆剝了——跟他的門一模一樣。一模一樣的位置。一模一樣的大小。他盯著那塊剝落看了很久。木紋的顏色。淡的。像曬過的骨頭。

> 門底的縫隙裡滲進來一滴水。透明的。沿著磁磚的邊緣往他的方向流。很慢。水的前端弧線在燈光下有一點亮。

> 他沒有站起來。

> 他看著那滴水流到桌腳旁邊。停了。水面上映了他的檯燈，倒過來的，像一個很小的火焰沉在地板裡。

我打到這裡停了。

把手從鍵盤上拿開。放在膝蓋上。螢幕上的字。「他沒有站起來。」

我看了那句話。看了很久。

這是我寫的。這個「他」是我造出來的角色。他坐在一個虛構的房間裡，聽到門外有人在哭，他沒有站起來。

我也沒有。

我把手放回鍵盤。繼續往下打。

※

>> 門後面的世界。

>> 走廊。牆壁的漆是米白色的，靠天花板的位置有一條水漬延伸了大半面牆。雨從窗框的邊緣滲進來，沿著牆面往下流，在踢腳板的位置匯成一條細線。地板是磁磚，白色的，縫隙發黑了。

>> 她站在那裡。

>> 她沒有傘。雨水從她的頭髮流到肩膀。頭髮是濕的，顏色比平常深，貼在臉頰上。額頭上有幾縷。水珠從髮尾滴下來，落在她的鎖骨上，沿著脖子往下。她穿著那件深藍色的絲巾繞在脖子上——溼了，顏色變成更深的藍，貼著皮膚，她沒有解開。

>> 她的手指在門板上。右手。指腹壓著木頭的表面。壓得不重。大概是一個蘋果的重量。她能感覺到門另一邊有人——不是聽到，是感覺到。空氣的振動。或者只是她知道他在。

>> 她想敲。手指彎了。指節收了一半。

>> 沒有敲。

>> 她站了五分鐘。她數了。每次呼吸數一秒。不是刻意數的——是她的身體在計時。呼吸的節奏。吸、吐、吸、吐。到第一百次的時候她把另一隻手也放在門板上。兩隻手。十根手指。都在門板上。

>> 她聽到了裡面的聲音。鍵盤。噠噠噠噠。速度不快。中間有停頓。停了幾秒。又開始。噠噠噠。

>> 他在打字。

>> 她把手從門板上拿下來。手掌上有木頭的紋路壓出的痕。淺的。紅的。她看了一眼。

>> 然後她蹲下來。慢慢地。膝蓋碰到地板。磁磚是冷的。冷從膝蓋骨往上走。她把額頭靠在門板上。

>> 門板的木頭溫度比她的額頭低。她能感覺到溫度的差。大概兩三度。她的體溫在從額頭流進門板。門板在吸收她。

>> 她閉上眼。雨聲。鍵盤聲。她自己的呼吸。三種聲音。跟他在門另一邊聽到的一樣嗎。大概不一樣。他聽到的鍵盤比較大聲。她聽到的雨比較大聲。他們各自聽著自己那一邊的世界。

>> 門沒有開。

我打完第二層的最後一行，手指停在鍵盤上。

Enter。

我沒有按。手指在 Enter 鍵上面。按下去就是新的一行。新的一行意味著故事繼續。她還在門外。他還在門裡面。按了 Enter，她會怎樣？她會站起來嗎？她會走嗎？她會敲門嗎？

我不知道。因為三年前的那個晚上，我沒有打開門去看。

我按了 Enter。然後存了檔。沒有寫下一行。

※

我站起來。去廚房。

煮咖啡。用摩卡壺——她留下的。鋁的。八角形。底座有一點鏽。三年沒有換膠圈，膠圈硬了，蒸氣從邊緣漏。我每次用都漏一點。不影響。咖啡還是會上來。只是比較慢。

水在壺裡加熱。嘶——的聲音。然後咕嚕。咖啡從上壺冒出來。黑的。

我站在流理台前面等。

然後聞到了。

薰衣草。

淡的。但很確定。不是咖啡的味道。不是雨水的味道。不是公寓的黴味。是薰衣草。洗髮精的味道。她用的那種。Yves Rocher。紫色的瓶子。我從大學認識她開始就知道這個味道。

我站在那裡。沒有動。嗅了一下空氣。味道在。確定在。不是想像出來的——想像的味道不會有這種存在感。想像的味道是模糊的。這個是清楚的。有方向。從浴室那邊來的。

我看了浴室方向。浴室的門關著。門底下沒有光。

我走過去。推開門。拉了燈的拉繩。燈亮了。

浴室很小。一個馬桶，一個洗手台，一個淋浴間。洗手台是乾的。蓮蓬頭也是。地板上沒有水漬。鏡子上沒有蒸氣。

沒有人。

味道——還在嗎。我站在浴室門口聞了一下。淡了。再聞。沒有了。

我關了浴室的燈。走回廚房。咖啡煮好了。壺裡的蒸氣聲停了。

我倒了一杯。黑的。沒加糖。

她也不加糖。這個我記得。她喝咖啡的樣子我也記得。她喝的時候會把杯子舉到嘴唇的高度，但不馬上喝——先聞。聞一下。然後才喝。

我喝了一口。沒有聞。

※

回到書房。

坐下來之前我看了一眼書桌右邊的抽屜。

手放在抽屜的把手上。金屬的。涼的。

我拉開了。動作很慢。抽屜的滑軌有一點澀，左邊比右邊重，拉的時候歪了一點。我用兩隻手扶正。

裡面。一個夾鏈袋。透明的。

袋裡是一張紙。A4。折了兩折。紙已經皺了。不是正常的皺——是被水泡過然後晾乾的那種。紙面凹凸不平，像一片微縮的地形圖。邊緣捲起來，有些地方脆了，碰一下會碎。

字跡。藍色墨水。被水溶成淡藍色的暈。有些地方完全看不到原來寫了什麼——只剩一片顏色，深淺不均，像水彩。有些地方能辨認幾個筆畫：一撇、一橫、半個口字旁。拼不出來。

第一行比其他行清楚一點。她大概寫在信紙最上方，門口的雨棚擋了一點，淋到的雨比較少。

「如果你讀到這封信的時候」

我讀了。七個字。後面的被水溶成一片。第二行只能辨認一個「我」和一個看不清的字——也許是「已」，也許是「以」。第三行完全不能讀。

我把夾鏈袋闔上。拉鏈的兩邊對齊。用拇指和食指捏著拉鏈頭，從左往右拉。拉到底。密封的聲音。

放回抽屜。抽屜推回去的時候又歪了。我用兩手扶正。推到底。

門外有人。他沒有開門。

※

凌晨一點四十六分。

我寫了兩千三百字。《白露》現在三千五百字了。我沒有回頭讀。我不敢。不是怕寫得不好。是怕讀了之後我會發現我在寫自己，而且寫得太準了。

我關了螢幕。沒關筆電。螢幕暗下去的時候書房變暗了。窗外路燈透進來一點橘色的光。打在天花板上。天花板的角落——那塊水漬。在橘色的光裡看起來比白天大一點。也許是光線的角度。也許是真的大了一點。

我看了一下自己的右手。

食指的墨漬。比昨天深了。昨天是深灰色。今天是黑色。邊界比昨天清楚。像是有人重新描了一遍。

我去浴室。開水龍頭。擠了肥皂。搓了。搓了大概兩分鐘。水從手指上流過。泡沫是白的。但手指上的顏色沒有變。黑色。在水流裡面那塊黑色的東西看起來很安靜。像一塊胎記。像一直都在那裡。

我把手擦乾。毛巾上沒有留下黑色的痕。墨漬在皮膚裡。不在表面。

我回到書房。

沙發。兩人座的。右邊是我的位置。左邊——她以前坐的那邊。坐墊的顏色跟右邊不太一樣了。右邊我每天坐，布面被磨得偏暗。左邊——三年沒人坐——布面比較淺，但有一個很淡的凹痕。大概是她留下的。也許是我的想像。布面凹不凹其實看不太出來。但我每次看都覺得那裡凹了一點。

我躺下來。躺在右邊。

左邊空著。

窗外雨聲。水龍頭的滴聲從廚房傳過來——我忘了關。不，我關了。是墊片的問題。滴。大概四秒。滴。

窗台上有一隻死掉的飛蛾。昨天就在了。翅膀碎了一邊。觸角還完整。細的。彎的。在橘色的路燈光裡看起來像兩條頭髮。

我看了一眼。沒有清掉。

閉上眼。

門外有人。他沒有開門。

不是小說裡的。

是我。三年前。門外有人。我沒有開門。

我翻了一個身。面朝沙發靠背。靠背的布面有一股灰塵的味道。不是髒。是久了。

睡了。大概。不確定什麼時候。
