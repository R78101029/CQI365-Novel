# 第二志願 — 創作計畫（creative_plan.md）v0.1

---

## 緣起

作者最初構想：一個人生順遂的中年男人，45 歲猝死，重回 18 歲填志願，選了不同的路，在新人生裡追求不同的女孩，卻總忘不了上一世的妻子，最後決定回去找她。

## 評估後的關鍵調整（2026-10-30 與作者討論定案）

| 原構想 | 調整 | 理由 |
|---|---|---|
| 他回頭找她，她剛好單身，重新追求 | 她單身是因為她正要出國，去走前世為他放棄的路 | 原結局太順、沒有代價 |
| 遺憾是「沒選的那條路」 | 真正放棄自己那條路的人是她 | 讓主角的遺憾變成反諷，給全書文學重量 |
| 太太的犧牲未定義 | 三層：放棄出國讀建築碩士、重返職場失敗、從不抱怨 | 作者要求更強烈；作者指定放棄的是建築碩士 |
| 前世主修未定 | 成大建築（夫妻同班），男主前世真的當上建築師；今世改讀交大資工 | 原定化工，2026-10-31 改為建築：成大建築與交大資工分數相近，放在同一張志願卡前兩格較合理；建築業對女性生育後重返的門檻更高，犧牲更具體；她放棄的正是他功成名就的那一行 |
| 男主遺憾是「如果讀資訊」 | 改為「如果走研究、出國」；他以為是自己為家讓出來的，其實他沒申請、她拿到了。今世他真的走研究路線，結尾兩人同日出國 | 2026-11-02 作者選定做法 B。作者在國外大學散步、參加研究會議時的真實感受 |
| 類型未定 | 文學中篇，林雨果風 | 作者決定 |
| 結局 | 停在半途，不交代 | 林雨果風；避免「再續前緣」的浪漫劇 |

## 與既有書目的關係

- **《失溫》**：看不見妻子的男人。本書是看得見、卻沒看清楚的男人。兩本可視為對照
- **《白露未晞》**：輪迴題材。本書避開宿命論，重點在「選擇」
- **《半成品》**：主角同為建築師。本書的建築只是前世背景，正文幾乎不寫建築專業細節，重心在她沒畫完的那條路
- **《失溫》物件區隔**：女主有速寫本，本書以寧不可用速寫本，改用描圖紙、模型、比例尺
