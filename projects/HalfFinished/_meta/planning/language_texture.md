# 語言質地指南｜漸變的文字聲音

> 本書不再使用四季文字曲線。以下是簡化後的語言漸變原則。
> SPEC.md 第 7 節展開版·寫每章前確認該段所在位置。

---

## 核心原則

文字質地從前段到後段**逐漸變化**，不是四段式跳躍，而是漸進式的。

- **前段**（Ch1-5）：建築師腦密集·句子長·段落長·形容詞豐富
- **中段**（Ch6-10）：漸變。建築師腦消退·句子變短·物件描寫增加·對白比例上升
- **後段**（Ch11-13）：克制。句子短·段落短·幾乎沒有建築師詞彙·留白感

這個漸變**不是她的成長弧線**——不是「她學會放鬆」。只是文字本身在變。

---

## 前段（第 1-5 章）

| 維度 | 設定 |
|------|------|
| 句長 | 平均每句 **20-30 字** |
| 形容詞密度 | **高**（不過度·但豐富） |
| 建築師腦詞彙 | **大量出現**：結構、承重、防水、施工、動線、容積率、使照、竣工、設計變更、監造、配筋、裂縫、滲水、樑柱、隔間、RC、鋼筋、模板 |
| 「我」字頻率 | **略高** |
| 段落長度 | **長**（每段 100-200 字） |

### 前段的氣味
- 主角全力運用建築師腦
- 句子有結構感、條理感
- 對話帶有「處理事情」的精準
- 她看一切都是結構問題
- **書寫態度**：彷彿你還在寫施工報告·不是在寫小說

---

## 中段（第 6-10 章）

| 維度 | 設定 |
|------|------|
| 句長 | 平均每句 **15-25 字**（縮短） |
| 形容詞密度 | **下降** |
| 建築師腦詞彙 | **逐章降低**·到 Ch10 幾乎消失 |
| 「我」字頻率 | **略降** |
| 段落長度 | **變多樣**（有些 100+·有些 2-3 行） |
| 物件描寫 | **增加**：風扇、冰箱、熱水壺、紗門、落葉、渡輪汽笛 |
| 對白比例 | **增加**（尤其 Ch10 剝橘子對話） |

### 中段的氣味
- 開始有實際操作的物理性
- 句子變短·像她變得不再多想
- 段落長短不一·像呼吸節奏不規則
- **書寫態度**：你正在做事·不是在思考

---

## 後段（第 11-13 章）

| 維度 | 設定 |
|------|------|
| 句長 | 平均每句 **10-20 字**（短） |
| 形容詞密度 | **極低** |
| 建築師腦詞彙 | **幾乎沒有** |
| 「我」字頻率 | **低** |
| 段落長度 | **短**（許多段落只一兩行） |
| 描寫方式 | **單一物件 + 單一動作**：「她削みかん」「貓在門邊」「海是灰色的」 |
| 句末留白 | **不補足每一個句子該有的資訊** |

### 後段的氣味
- 短句連發·一句一行·不串
- 形容詞接近消失·動詞主導
- 沒有「我覺得」「我發現」
- **書寫態度**：你存在·但不主張

### 句末留白範例

| 飽寫（禁） | 留白（要） |
|----------|-----------|
| 她把碗放回水槽·覺得有點累。 | 她把碗放回水槽。 |
| 她笑了一下·眼神有點黯淡。 | 她笑了一下。 |
| 雨開始下了·這樣的天氣總是讓人想起什麼。 | 雨開始下了。 |

## 「我」字頻率：人工統計流程

> Agent 無法自動控制這個頻率·**每章寫完必須跑**。

### 步驟

1. 跑全章字數:
   ```bash
   node scripts/chapter-stats.mjs --novel=HalfFinished --verbose
   ```
2. 開該章 .md 檔·**手動數「我」字次數**（用編輯器搜尋計數）
3. 計算頻率：`(我字次數 / 中文字數) × 1000` = 每千字次數
4. 確認趨勢：後段某章的密度不應該比前段還高。如果是·回去改

### 為何這個指標重要

- 「我」字密度反映**主角作為敘事中心的重量**
- 第三人稱小說裡·「我」字主要出現在對白與引述思想
- 前段到後段下降 → **主角在敘事中漸漸退場**

讀者不會明說察覺·但會**身體感覺到**章節節奏的變化。

## 語言工具

她全程使用翻譯 app。不設計日語滲透曲線。

- 她不學日語·不買教材·不上課
- 翻譯 app 是她跟日語環境的唯一橋樑
- 偶爾聽懂常聽的詞（「猫」「大丈夫」）是自然的·但不是設計出來的弧線
- 常客是台灣人·她們用中文對話
