# Zone 4 章節規劃 — 皺摺壓縮（Ch 18-22）

> **Zone 4 規則**：每章3-4次時間線切換。每段1000-2000字。全章6000-8000字。目標：各時代的暴力完整顯現，四條時間線同步進入危機。視覺效果：章節長度壓縮，讀者感受「收緊」。

縫工的論文被退回。「選題不符合社會和諧原則。」上司說：「你知道就好，不要寫出來。」她想到七號技師——那個說出來的人。校正後的七號技師此刻正在隔壁辦公室校準儀器，動作精確，表情平靜。

## Ch 19 — 結構暴力

| 項目 | 內容 |
|------|------|
| **線** | B → A → D → C（四人） |
| **排序** | 19 |
| **字數目標** | 7500字 |

### B段（約1800字）

清鄉的機器運作。名單、搜捕、夜間敲門。陳明哲的鄰居——那個害怕的外省人——站在巷口，沒有看他被帶走。

### A段（約1800字）

黨錮的邏輯——不需要證據，只需要名單。衛央的名字現在在名單上了。

### D段（約1800字）

2301年的沉默——沒有人告密，因為不需要。社會禁忌自我執行。縫工的同事們默默離開修復局，沒有人問為什麼。但七號技師沒有離開——她不記得自己為什麼應該離開。

> **「如果」鋪墊 #3**：修復局走廊裡，一個新來的實習技師在閒聊中說了「如果泡停止擴張的話……」。旁邊的人臉色變了。上司立刻過來：「去做一次心理評估。」實習技師被帶走。兩天後回來，不再說那個詞了。縫工在角落看著這一切，一句話沒說。讀者第三次看到禁忌的代價——從社交尷尬（Ch 4）到自我審查（Ch 8）到強制治療（Ch 19），暴力的梯度在升高。

### C段（約1800字）

許若昕發現她的研究經費被凍結。「安全審查」。真正的壓力來自看不見的地方。

### 主題

228結構的完全展現——四個時代，同一種暴力的不同形態。無需個人惡意，制度本身就是暴力。

## Ch 20 — 藏

| 項目 | 內容 |
|------|------|
| **線** | C → B → A → D（四人） |
| **排序** | 20 |
| **字數目標** | 7000字 |

### C段（約1700字）

許若昕將開摺實驗的核心數據加密，分散儲存在多個不相關的學術資料庫中。她知道自己可能活不了多久。

### B段（約1700字）

陳明哲把渾天儀和筆記藏進龍山寺牆壁。林秀英在旁邊遞石灰。他們沒有說話。他的手指觸碰磚塊的質感——粗糙、冷、真實。林秀英的手偶爾碰到他的手指。這是他們最後一次一起做一件事。

> **Ch 20 四段結尾呼應設計**（四人用各自的聲音/質地完成同一個動作——「關上」）：
> - A段結尾（衛央）：工具收好。匣子鎖上。
> - B段結尾（陳明哲）：最後一塊磚推進去。石灰封上了縫隙。手指上有白色的粉。
> - C段結尾（許若昕）：*Upload complete.* 她關掉螢幕。
> - D段結尾（縫工）：程式碼提交。版本號沒有變。沒有人會注意到。

### A段（約1700字）

衛央完成最後的刻劃。工具收好。她知道明天他們就會來。

### D段（約1700字）

縫工把真實的2055研究數據嵌入修復局的基礎監測程式碼。不是可讀文件，而是演算法的一部分。

### 主題

四個人，在不同的時代，做了同一件事——把真理藏給未來。「我不知道誰會看見。但總會有人。」

## Ch 21 — 第一折（衛央之死）

| 項目 | 內容 |
|------|------|
| **線** | A → B → D → C |
| **排序** | 21 |
| **字數目標** | 7500字 |

### A段——衛央之死（約2500字，本章最長段）

- 清晨，靈台外的空地，面朝東方。
- 主審官問「你藏下那些數字，為的是什麼？」
- 她沒有回答。看著天空說：「今天沒有異常閃光。」
- 死亡時感知到：縫工在2301年讀到她的星圖時的「被看見」感。
- 刀刃的冷。

### B段（約1700字）

陳明哲在獄中感到一陣莫名的寒冷。不是溫度的寒冷。像是什麼東西斷了。

### D段（約1700字）

縫工的監測設備記錄到一次微小的褶痕震動——座標位置指向公元169年洛陽。她不知道那意味著什麼。

### C段（約1700字）

許若昕在實驗室突然感到一種「失去」的感覺。她不知道失去了什麼。

### 衛寧的等待（A段尾聲，200字）

> 場景切回 Thread A。不在行刑現場。在衛寧家裡。
> 衛寧在門口坐著。今天是妹妹通常來的日子。
> 她等了一個上午。
> 沒有人來。
