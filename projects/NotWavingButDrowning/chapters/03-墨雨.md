# 墨雨

雨連下了三天。

不是三天沒停。是三天沒有小過。基隆的雨有幾種等級——毛毛的、正常的、不正常的。這三天是不正常的。窗外的聲音從「有人在敲鼓」變成「有人把鼓翻過來用水灌」。鐵皮屋頂的共振從嗡變成轟。我在書房裡坐著，能感覺到空氣在震。

我幾乎沒出過書房。

桌上堆了三個泡麵碗，一個疊一個。最上面那個還有半碗湯，筷子斜插在裡面。中間那個空了，碗裡乾了一層油。最下面那個碗裡的湯已經完全乾了，留了一圈鹹的結晶，灰白色的，像岸邊退潮後的鹽線。

咖啡杯裡的殘液發酸了。我能聞到——一種比正常咖啡味更尖的東西。我把杯子推到桌角。推的時候碰到了那支鈍掉的鉛筆，鉛筆滾了一下，停在便條紙旁邊。便條紙還是空白的。

書房裡的空氣比前兩天悶。窗戶沒開——雨太大了，開了水會飄進來。飄進來的不只是水，是基隆的潮氣，帶著海的鹹和山的黴。我能聞到自己的味道。T恤兩天沒換了。

《白露》的字數——三千五百。我昨晚寫到凌晨兩點。今天從下午六點開始。繼續。

※

我打字的速度變快了。

不是因為靈感。靈感是一個我不太相信的詞。我相信的是慣性——打了三天字，手指的肌肉記住了鍵盤的間距，落指的遲疑變少了。也許這就是所謂的靈感。肌肉的靈感。

但快的原因不只是慣性。是腦子裡的聲音。

雨聲裡面有別的。不是什麼超自然的東西——是記憶。記憶有時候會伏在日常的聲音底下，像水底的石頭，你以為是平的河面，腳踩下去才知道下面有東西。

「再五分鐘就好。」

我自己的聲音。三年前的。隔著一扇門說的。門的那一邊有人在等。門的這一邊我在寫。我說了那句話。然後我繼續寫。

我不確定今晚是真的聽到了還是記憶在播放。大概是記憶。但記憶播放的品質太好了——音量、音色、那句話末尾的氣息聲，都跟三年前一樣。

差別不重要。重要的是：打字的時候如果不夠快，那個聲音就會蓋過我正在寫的句子。

所以我打得快一點。

右手中指也出現了墨漬。比食指的淡一點，大概是淺灰而不是黑。兩根手指並在一起看，像抓了什麼黑色的東西。我沒有去洗。洗了也洗不掉。第一天我還試過。第二天不試了。

天花板角落有一小塊水漬。灰白色的。形狀不規則。不是新的——公寓老了，防水做得不好，三樓尤其。但我以前沒注意到。今天注意到了。大概是因為我打字的時候偶爾會抬頭，看天花板。以前我抬頭看的是窗外。現在窗外只有雨，什麼都看不見，所以我看天花板。

※

> 他坐在桌前。

> 筆在手上。紙在桌上。雨在窗外。她在門外。他全部知道。他知道她在哭。不是嚎的那種。是聲音壓在喉嚨裡，偶爾漏出來一點的那種——像水從閥門沒關緊的水管裡滲出來，一滴一滴的，控制不住但也不會氾濫。

> 他知道她需要他。

> 他的手在紙上。筆在手上。筆尖壓著紙面。墨水在筆尖和紙之間形成一個小小的液面，張力撐著，只要他一動，就會落下，變成字。

> 他說：「我先把這段寫完。」

> 他相信他說的。他真的以為只要寫完這一段——三百字，也許四百字——他就會放下筆，站起來，走到門口。他甚至在腦子裡預演了整個路徑：椅子往後推，站起來，三步到門口，右手伸出去，握住門把，金屬是涼的，轉，門開了，走廊的光進來，她的輪廓在逆光裡，看不清臉，但他知道是她，他走過去——

> 他能感覺到門把的觸感。涼的。能聽到門軸轉動的聲音。能聞到走廊裡的雨水味。每一個細節都那麼清楚。

> 但他沒有站起來。

> 他在紙上寫了第一行。然後第二行。第二行比第一行順。第三行比第二行快。到第四行的時候他的手在動，但他的注意力已經不在門外了。不是忘了。是它被推到了後面。像一個最小化的視窗，圖示在螢幕角落，他知道它在，但他正在處理前景的東西。

> 他以為只要寫完這一段。

> 他沒有站起來。

我停了一下。喝了一口涼掉的水。繼續。

※

>> 門的另一邊。

>> 走廊。牆面是米白色的。靠天花板的位置有一條水漬，暗的，延伸了大半面牆，像一條乾掉的河床被釘在牆上。雨從窗框的角落滲進來——窗框跟牆之間的矽利康老化了，裂了，水從縫隙裡擠出來，沿著牆面往下流。到了踢腳板的位置匯成一條細線，在磁磚的接縫裡流。

>> 她站在門口。

>> 沒有動。她的重量平均分佈在兩隻腳上。鞋子——室內拖鞋，灰色的布面——濕了。不是她從外面進來的時候濕的。是走廊地板上的水浸上來的。拖鞋的布面在吸水。

>> 她的手放在門板上。左手。五根手指。指腹壓著木頭的表面。壓得不重。她能感覺到門板的紋路——直的，偶爾有一個小結，手指滑過去的時候有一個微小的凸起。

>> 她聽到了裡面的聲音。鍵盤。噠噠噠。節奏不均勻。有時候快——連續的噠噠噠噠像一陣短雨。有時候停——三秒，五秒，七秒。然後又開始。

>> 她數了。每一次停頓她都在等。等他站起來。椅子在地板上磨一聲。腳步聲走到門口。門把轉。門開。

>> 一百次呼吸。她等了一百次呼吸。沒有椅子聲。

>> 兩百次。沒有腳步。

>> 三百次。

>> 她把手從門板上拿下來。手掌上有木頭的紋路壓出來的痕。淺的。紅的。她攤開手看了一眼。手指的關節有一點僵——壓得太久了。

>> 她蹲下來。慢慢地。膝蓋先碰到地板。磁磚是冷的。冷從膝蓋骨往上走，走到大腿，走到腰。她把另一隻膝蓋也放下來。跪著。然後雙手撐在地板上。然後把額頭靠在門板上。

>> 門板的木頭比她的額頭涼。她能感覺到兩者之間的溫差。她的熱在往門板裡走。門板在吸她的溫度。

>> 她閉上眼。

>> 鍵盤聲沒有停。

>> 她等了五分鐘。門沒有開。

我打完這一段。呼吸淺了。我意識到自己在打字的時候整個人前傾了，胸口壓在桌沿上。我坐直了一點。深吸一口氣。吸到一半——停了。胸口有東西。不是疼。是壓。像一塊什麼在胸骨後面。

我用手掌壓了一下胸口。硬的。壓不進去。

繼續。

※

>>> 更深處。

>>> 她的額頭在門板上。門板的木紋在她的額頭上壓出了痕。她看不到那個痕。她也不需要看。她知道它在。

>>> 雨聲。門另一邊的鍵盤聲。她自己的呼吸。三種聲音疊在一起。但在這一層裡，三種聲音已經分不開了。雨聲的間隙裡有鍵盤的節奏。鍵盤的停頓裡有她的呼吸。呼吸的尾端有雨的回聲。

>>> 所有聲音都是同一種聲音。所有等待都是同一種等待。

>>> 門。

>>> 門——

>>> 他——她——

>>> 五分——

>>> 寫完——

>>> 再五——

>>> 門——

>>> 文字碎了。主詞不見了。動詞在重複。不是因為寫的人忘了怎麼寫。是因為語言到了某個深度就不再是完整的了。像水壓把容器壓扁了。句子被壓成詞。詞被壓成字。字被壓成筆畫。筆畫被壓成墨。

>>> 「再五分鐘。」

>>> 五分鐘是多久。三百秒。一千八百個心跳。一生裡的一萬分之一。

>>> 不夠用的。

>>> 永遠不夠用。

>>> 五分——門——關——

※

我打到第三層的時候，感覺到什麼東西落在我的右手上。

停下來。看。

右手食指的指節上。一滴。黑色的。液體。

我把手舉起來，讓指節在螢幕光下面看清楚。那一滴大概一粒米大。黑的。比水稠一點。表面有一點反光。

我抬頭看天花板。

天花板角落那塊水漬——灰白色的。乾的。跟白天看到的一樣。天花板其他地方也是乾的。沒有滴水的源頭。沒有裂縫。沒有任何可能漏的地方。

我低頭再看手指。那一滴還在。它沒有流動——停在指節的曲面上，張力撐住了，像一顆非常小的半球。

我用左手食指碰了一下。指腹沾了一點。黑的。我搓了搓。質感——不像水。比水稠。比油清。沒有味道。我湊近聞了一下。什麼都沒有。

我在褲子上擦了一下。牛仔褲的布面上多了一個小黑點。大概直徑三毫米。

我看了天花板最後一眼。

乾的。

我把手放回鍵盤。繼續寫。手指落在鍵帽上的時候，食指那塊墨漬碰到了 F 鍵的表面。我看了一眼。鍵帽上沒有留痕。墨在皮膚裡，不在表面。

※

> 他以為只差五分鐘。他關上了門。

這是我今晚寫的最後一行。

不是計畫好的。不是大綱上安排在這裡的句子。是我的手指自己打出來的。打完之後我看著螢幕上那十四個字，覺得它們佔了太大的空間。好像整個螢幕只剩下這一行。其他的字都退到背景去了。

他以為只差五分鐘。他關上了門。

我在《白露》裡寫了這句話。同一句話，三個不同的版本，散落在三層裡：

第一層寫的是：「他以為只要寫完這一段。他沒有站起來。」

第二層寫的是：「她等了五分鐘。門沒有開。」

第三層寫的是碎片。五分。門。關。

三種說法。一件事。

我存了檔。看了字數。五千八百。今晚寫了兩千三百。三天加起來《白露》有五千八百字了。

我沒有回頭讀。我怕讀了會停。不是怕寫得不好。是怕它太對了。怕我打開第一層的第一段，看到那個「他」坐在桌前的樣子，會看到自己。我不想看到自己。我想看到一個虛構的角色。我想要他跟我不一樣——他的桌子比我大，他的窗外有田，他用紙和筆。他跟我不一樣。

但他關了門。跟我一樣。

※

我站起來。

走到窗邊。窗玻璃上全是水。外面的巷子看不清楚了。路燈的光被雨水散射成一團橘色的暈，像一個失焦的太陽沉在一米以外的地方。

我把額頭靠在窗玻璃上。玻璃是涼的。不像門板那種木頭的涼。是更硬的涼。更沒有溫度的涼。

我在窗玻璃上站了多久——不知道。大概一分鐘。大概三分鐘。

然後我回到桌前。

螢幕亮著。游標在最後一個句號後面閃。

桌面上，泡麵碗旁邊。黃色的油漬從碗邊延伸到桌面。乾了。調味包只撕了一半，另一半還連在包裝上，油從撕口處沿著塑膠往外流了一小段就凝固了。

油漬。黃的。和手指上的墨漬。黑的。在桌面上隔了大約十五公分。兩種東西。兩種顏色。桌面是淺木色的。黃和黑都很明顯。

我用袖子擦了油漬。

墨漬沒擦。

※

胸口還是緊的。

不是心臟的位置。更中間。更深。不在肋骨能碰到的地方。像有什麼東西卡在胸骨後面——不是固體，不是液體，是一種壓力。從裡面往外推，但推不出來。

我用手掌壓了一下胸骨。硬的。壓不進去。

深呼吸。吸到一半——胸口的壓頂住了。吸不滿。我呼出來。慢的。嘴唇微張。氣流從齒縫出去的時候有一點嘶聲。

我站著。雙手垂在身側。左手乾淨的。右手兩根手指是黑的。

窗外的雨沒有要停的意思。

我回到桌前。沒有關筆電。螢幕的光照在我臉上。桌面上那些字——五千八百個字——在螢幕的白色背景上排列著，黑的，小的，像一群不會動的蟲。

游標閃了。

閃了。

我看了一下時間。凌晨一點五十三分。

明天繼續。或者今天。凌晨一點五十三分算今天。

我沒有關螢幕。我離開書房的時候把門關上了。門鎖扣。咔。

走廊是暗的。

第三步，地板響了。第八步，沒響。連下三天雨，木頭吸飽了水，脹起來就不響了。

廚房。水龍頭。滴。四秒。滴。

我站了一會。

然後走回書房。門外。

站在門外。

手沒有碰門把。

大概站了十秒。

然後推開門。進去。坐下。

螢幕還亮著。
